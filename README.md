# 如（ru-language）· 0.2.0 玩具实现

一个能实际运行的原型：中文关键词、保留状态的多行 REPL，以及将 `.ru` 源码编译为原生机器码的 C99 后端。

0.2.0 新增 `空`、二元组 `对`、可变引用数组 `阵`、Unicode 字符串索引 / 切片、对象 / 继承 / 方法、相对路径模块与 `元初` 程序入口。解释器和原生后端实现相同语义；新增算法示例见下文。

上一版 0.1.1 新增按声明顺序匹配的位置实参：`显 (平方 9.9).` 现在输出 `98.01`；原有 `平方 根: 9.9` 仍然可用。完整示例见 `examples/square.ru`，多实参示例见 `examples/positional.ru`。

**本版不是自举编译器。** 编译器和 REPL 使用 Python；原生输出经过 C 编译器编译，执行时不需要 Python、`ru`、原始 `.ru` 文件或生成的 `.c` 文件。生成的程序内没有词法分析器、语法分析器或源码解释器。

## 30 秒开始

Linux / WSL，克隆私有仓库（需要有访问权限）并进入项目目录：

```sh
git clone https://github.com/uppet/ru-language.git
cd ru-language
python3 ru --version
python3 ru repl
```

REPL 中输入：

```text
如> 数值 取 3.
如> 数值 + 4.
7
如> :quit
```

解释执行示例：

```sh
python3 ru run examples/hello.ru
python3 ru run examples/add.ru
python3 ru run examples/square.ru   # 98.01
```

编译并运行独立程序：

```sh
python3 ru build examples/hello.ru -o bin/my-hello --emit-c dist/my-hello.c
./bin/my-hello

python3 ru build examples/add.ru -o bin/my-add
./bin/my-add
```

输出：`你好，世界`。加法示例会询问两个数并显示和。

`ru` 本身也是可执行脚本；可使用 `./ru repl`，或始终使用 `python3 ru`。

## 环境与已验证范围

- 编译器 / REPL：Python **3.10+**，只用标准库，无 pip 依赖
- 原生编译：Clang、GCC 或兼容的 C99 编译器；依次自动查找 `clang`、`gcc`、`cc`
- 可通过 `--cc gcc` 或 `CC=gcc` 指定编译器；参数通过 argv 传递，不经过 shell
- 仓库初始化验证：Linux x86-64、Python 3.12.3、GCC 13.3.0；位置调用更新验证：Linux x86-64、Python 3.12.14、GCC 14.2.0。各次记录见 `VALIDATION.md`
- 仓库只保存源码；`bin/`、`dist/` 由 `make examples` 或 `ru build` 在本机生成。原生程序依赖构建时的目标架构和系统库，应在目标系统重新构建
- Windows：可在已有 WSL 中按上述命令使用。也提供 `ru.cmd`，可通过 `py -3 ru repl` 运行 Python 前端；Windows 原生 Clang/GCC 编译以及 `.exe` **未实测**，不承诺即开即用
- macOS、其他架构和 Python 3.10/3.11 未在本次环境实测

如需研究静态输出，工具链支持时可使用 `--cc "gcc -static"`；静态库、目标平台兼容性及第三方库再分发义务由该工具链决定。默认构建使用动态链接。

## 命令

```sh
python3 ru                         # 等同 repl
python3 ru repl                    # 交互模式
python3 ru run source.ru           # 解释执行
python3 ru check source.ru         # 检查语法、结构和显式函数调用
python3 ru build source.ru -o app  # 原生编译
python3 ru build source.ru -o app --emit-c app.c
python3 ru build source.ru -o app --cc clang
python3 ru generate intent.md      # 意图文档入口；尚未连接 LLM
python3 -m rulang --help           # 模块入口也可用
```

`build` 不会自动运行程序。输出存在时，只有成功编译后才替换它；不能把输出设为源文件自身。默认输出为去掉扩展名的源文件路径。`--emit-c` 会保存一个可独立编译的 C 文件，运行它不需要这个项目的头文件：

```sh
cc -std=c99 -O2 dist/my-hello.c -lm -o another-hello
```

常规错误退出码为 `1`，命令行参数错误为 `2`，取消文件执行为 `130`。错误通常包含文件名、行号；前端和解释器还提供列号。原生运行错误只提供行号。

## 语言约定

这些是本次原型的明确约定，尚非冻结的正式语言规范。调用写法、数值细节和比较运算是为使原型完整可跑所补充的设计。

### 字符、语句和数值

- UTF-8 源码；关键词、名称一般用空白分开。`信@含`、`左+右` 可以紧贴运算符
- 0.2 新增保留字 `空`、`对`、`形`、`象`、`如`、`新`、`外言`、`尽`；旧代码中的同名变量 / 函数需要改名。`阵` 是类型名称，并非词法保留字；`为乐` 这样的完整名称不会因包含关键词 `为` 被拆开
- 简单语句以 `.` 或 `。` 结束；换行只作为空白，块结束关键词后的句点可省略
- 支持 `:` / `：`、`()` / `（）`、`,` / `，`
- 字符串支持 `'…'`、`"…"`、`‘…’`、`“…”`；支持 `\n`、`\r`、`\t`、`\\` 和被转义的引号
- 字符串允许换行，不允许 NUL；源码和标准输入需为有效 UTF-8
- `#` 和 `//` 开始行注释
- 值包括 `句`（不可变字符串）、`数`（IEEE-754 双精度浮点数）、`空`、不可变 `对`、可变引用 `阵`、对象与模块
- 不是大整数 / 十进制定点语言。超过约 15 位有效数字会有精度限制；输出最多 15 位有效数字。不要用于金额或精确整数大数计算
- `1`、`-2.5`、`.5`、`1e3` 可用；尾部句点是语句结束符，因此源码中 `1.` 表示数值 `1` 加终止符
- 拒绝 NaN、Infinity 和非有限运算结果；除以零报错

### 显示、绑定、赋值和转换

```text
显 ‘你好，世界’.

左 取 (读 提示: '输入第一数：') 为 数.
右 取 (读 提示: '输入第二数：') 为 数.
中 取 左 + 右.
显 中.

中 取 中 + 1.
显 中 为 句.
```

`显` 输出一行。`取` 在当前作用域内新建或更新绑定，不固定绑定的类型。`为 数` 和 `为 句` 是显式值转换；转换结合整个左侧表达式，必要时用括号明确范围。

`句` 转 `数` 接受前后 ASCII 空白、正负号、十进制与科学计数法。空串、乱码式数字、`0x10`、`nan` 等报错，不悄悄变成零。`数` 转 `句` 使用与 `显` 相同的格式。

`读` 返回标准输入的一行，去掉结尾换行。`读 提示: '…'` 先显示提示且不换行。真正到达 EOF 时会报错退出，避免没有新输入的循环不断输出；按回车得到的空行仍是合法空串。

### 函数、过程和调用

```text
算 平方 根 为 数：
    得 根 * 根.
法

显 (平方 9.9).
显 (平方 根: 9.9).

作 祭拜 :
    显 ‘叩’.
    显 ‘叩’.
    显 ‘叩’.
    循 9 次
        显 ‘拜’.
    环
为 .

祭拜.
```

- `算` 以 `法` 结束，使用 `得 表达式.` 返回结果；某条实际执行路径没有 `得` 会报错
- `作` 以 `为` 结束，不允许 `得`；在表达式中调用会得到空 `句`。正常单独调用不会额外显示返回值
- 不强制 `算` 纯函数，可以使用 `显`、`读` 等
- 参数写作 `名称 为 数`、`名称 为 句`、`名称 为 阵`、`名称 为 句 阵` 或 `名称 为 自定义形` 等；类型需要匹配，不自动转换
- **位置实参**：`函数名 表达式`。例如 `平方 9.9`；多个位置实参按参数声明顺序匹配，可用空白或逗号分隔，例如 `差 9 4`、`差 9, 4`
- **命名实参**：`函数名 参数名: 表达式`。例如 `平方 根: 9.9`；多个命名实参按名字匹配，可调整顺序，例如 `差 右: 4 左: 9`
- 同一次调用不能混用位置实参与命名实参；两种写法的实际值都按源码从左到右求值，参数个数和类型必须匹配
- 零参数函数 / 过程直接写名字，例如 `祭拜.`；`读` 也是如此
- 每个实参都是尽量向右读取的完整表达式：`平方 2 + 1` 是对 `3` 求平方。要把调用结果参与运算，请写 `(平方 2) + 1`；命名实参规则相同
- 实参中再调用带实参的函数，必须加括号，例如 `差 (平方 3) (平方 根: 2)` 或 `差 左: (平方 3) 右: 2`。`差 甲 乙` 中的 `甲`、`乙` 各是一个实参，不会隐式变成 `差 (甲 乙)`；普通变量和零参函数不需括号
- `+`、`-` 不会在函数名后直接开启位置调用，仍按加减运算解析，以保留 `变量 - 2`、`零参函数 - 2`。第一个负数位置实参写 `平方 (-2)`；后续负数写 `差 2 (-3)` 或 `差 2, -3`。`差 1 -2` 只有一个实参 `1-2`，会提示缺少参数。命名写法 `平方 根: -2` 仍直接可用
- 实参列表属于函数名后面的序列；`差 9 4` 或 `(差 9, 4)` 可用，不采用 `差(9, 4)` 形式的括号实参列表
- 内置 `读` 也接受位置提示：`读 '输入：'` 等价于 `读 提示: '输入：'`，省略提示时仍可直接写 `读`
- 普通函数 / 过程定义在顶层；`形` 内可以定义方法，不支持在函数体中嵌套定义函数。允许前向调用和递归；递归调用深度上限 128
- 源码表达式 / 块的嵌套也有限制（原型上限 128 层），过深时给出诊断，不显示 Python 回溯
- 函数有自己的局部变量，可读取全局变量；函数内 `取` 只更新本地绑定，**不会修改同名全局变量**。条件、循环不新增作用域
- 函数名、过程名、内置 `读` 不能同时作为变量名或参数名

### 条件、循环、成员语法

```text
信 取 '空'.
循
    显 信.
    信 取 (读) 为 句.
    若 信@含 '再见' 则
        破.
    另
        显 信.
    然
环
```

`信@含 '再见'` 和 `信 其 含 '再见'` 完全等价，都是**包含**测试，没有取反含义。

`若 条件 则 … 另 … 然` 的 `另` 可省略。`循 次数 次 … 环` 为计次循环；不写次数就是无限循环；`破.` 退出当前最内层循环。计次表达式只在进入循环时求值一次，必须是 0 到 2^53−1 之间的整数。无限循环由程序自己 `破`，终端中也可以 Ctrl-C 中断。

### 运算

运算顺序从高到低：括号 / 调用 / 索引 / 成员，一元 `+ - 非`，`* / %`，`+ -`，`< <= > >=`，`== !=`，`且`，`或`，`对`，`为 类型`。`对` 是右结合运算；组合复杂表达式时建议显式加括号。

- 数字支持普通算术；`%` 采用浮点余数，符号跟随被除数，例如 `-7 % 3` 是 `-1`
- 两个 `句` 可用 `+` 连接；不会自动把数字转成字符串
- 比较、包含、`非`、`且`、`或` 返回 `数`：真为 `1`，假为 `0`
- 条件中，`0`、空串、`空` 和空阵是假；非空阵、二元组、对象和模块为真
- `且` / `或` 短路求值；例如 `0 且 (1 / 0)` 不会除以零
- 大小比较需要相同类型；字符串按 Unicode 字符顺序比较，不是拼音排序
- 跨类型 `==` 为假，`!=` 为真；二元组按结构比较，数组 / 对象 / 模块按引用身份比较；不支持链式比较的数学简写，请写 `值 > 1 且 值 < 5`

## 0.2 数据结构、对象、模块与入口

以下是原型 0.2 的明确默认规则，不代表已经冻结的正式语言规范。

### 空与对：一条不可变链表

```text
链 取 1 对 2 对 3 对 空.
显 链 其 囫.                # 1，左项
显 (链 其 囵) 其 囫.        # 2，右项的左项
显 (1 对 空) == (1 对 空).  # 1，按结构比较
```

`空` 是独立值，显示为 `空`，与句 `'空'`、数 `0`、空句 `''` 都不相等。`对` 右结合，上面的链等价于 `1 对 (2 对 (3 对 空))`；`囫` / `囵` 只能读取，不能用 `取` 改写。二元组中的数组 / 对象仍保持引用身份，不会深复制。

完整遍历、求和、逆序示例：`examples/linked_pairs.ru`。

### 阵：共享引用、索引与浅切片

```text
数列 取 [3,1,2].
别名 取 数列.
别名[0] 取 9.
数列 其 增 4.
显 数列[0].                 # 9
显 数列 其 量.              # 4
显 数列 其 位 1.            # 1
显 数列[1:3].               # [1, 2]
显 数列 其 段 始:1 终:3.    # [1, 2]
```

- `[]` 新建空阵，`[甲, 乙]` 按源码顺序求值，可混装不同类型
- `值 为 阵` 总是创建**包含这个值的单元素阵**：`空 为 阵` 是 `[空]`，已有阵或对象也只是包装一层，不会展开或复制
- 阵赋值、实参、返回值均共享引用；`其 增 值` 追加一项，并返回同一个阵
- `其 量` 返回长度；`其 位 索引` 与 `[索引]` 等价，均可作为 `取` 左侧。`位` / `增` 的命名实参分别写 `位:索引` / `值:值`
- 标准成员的位置操作数结合得紧：追加和写作 `列 其 增 (1+2)`，复合索引写作 `列 其 位 (位+1)`，复合范围写作 `列 其 段 (始+1) (终-1)`。命名形式如 `列 其 增 值:1+2` 接受完整表达式。普通函数 / 自定义方法仍遵循前述贪婪实参规则
- 名称后紧贴 `[` 表示索引，如 `列[0]`；空白分隔的阵字面量可作位置实参，如 `求和 [1,2]`。复杂场合可写 `求和 ([1,2])` 明确边界
- 索引从 `0` 开始，必须是整数，满足 `0 <= 索引 < 长度`；负数、小数、越界均报错
- `[始:终]` 和 `其 段 始 终` / `其 段 始:始 终:终` 左闭右开，要求 `0 <= 始 <= 终 <= 长度`，不自动截断。方括号中省略始 / 终分别取 `0` / 长度；`[:]` 取全部
- 切片创建新阵，但里面的阵 / 对象仍共享引用，是**浅复制**。本版不支持切片赋值
- 阵的 `==` 检查是否同一实例；两个内容相同的新阵并不相等
- 参数 `列 为 阵` 接受混合阵；`列 为 数 阵` / `列 为 句 阵` 在调用时检查各元素。此注解不把阵变成不可变或永久限定元素类型的容器

原地排序及别名示例：`examples/array_sort.ru`。

### 句：Unicode 码点索引与切片

```text
文 取 '甲😀é乙'.
显 文 其 量.      # 4
显 文[1].         # 😀
显 文[1:3].       # 😀é
显 文[:1].        # 甲
显 文[3:].        # 乙
```

`句` 支持同样的 `量` / `位` / `段` 和方括号读操作，仍然不可变；给字符赋值或追加会报错。位置按照 **Unicode 码点**，不是 UTF-8 字节，也不是视觉字形：组合附加符号、emoji ZWJ 序列可能占多个位置。示例：`examples/unicode_slices.ru`。

### 形、对象、继承和方法

```text
形 计数器:
    值 为 数.
    作 增加 步 为 数:
        其 值 取 其 值+步.
    为
    算 报数:
        得 其 值.
    法
象
形 命名计数器 如 计数器:
    名 为 句.
    算 报数:
        得 其 值+1.
    法
象
甲 取 新 命名计数器 名:'计数' 值:2.
乙 取 甲.
乙 其 增加 3.
显 甲 其 报数.    # 6
```

- `形 名 [如 父形]: … 象` 声明对象类型；字段写作 `字段 为 类型.`，方法使用原有 `算 … 法` / `作 … 为` 语法
- `新 形名 字段名:值 …` 以命名字段初始化；实参按源码顺序求值，继承字段也可初始化。省略字段默认为 `空`，字段均允许 `空`；其他赋值必须符合声明类型
- `对象 其 字段` 读取；`对象 其 字段 取 值.` 修改。对象按引用传递，别名会看到修改
- `对象 其 方法 实参` 支持位置与命名调用；方法里 `其 字段` 简写当前对象字段，裸 `其` 返回自身。方法外使用自身会报错
- 子形继承字段与方法；覆盖方法必须保持参数名字、类型和算 / 作类别。继承方法内部调用其他方法仍按实际对象类型动态分派
- `如 父形` 的父形必须是直接声明或通过 `尽 取 外言` 导入的形名称，不能使用运行时形值别名；普通形值别名可用于 `新` 或重新绑定
- 父形参数接受子形实例；同名字段冲突、不兼容方法覆盖和继承循环报错。不支持多继承
- 原型解析器对标准成员名称有语法约束：`含`、`位`、`段`、`增` 不能作为字段名；同名方法须保持标准参数名 / 数量（`含 句`、`位 位`、`段 始 终`、`增 值`）。`囫`、`囵`、`量` 是零参成员；建议业务方法使用其他名称
- 对象的相等性是引用身份。构造器不隐式执行用户初始化方法

完整别名、继承、动态分派示例：`examples/objects.ru`。学生 / 上进学生、`名` / `龄` / `族`、`报道` 与班级数组示例：`examples/students.ru`。`助人`、`为乐` 不属于内置命令；`为乐` 可以作为普通函数或变量名，但需要自行定义。

### 外言：相对路径模块

```text
数学 取 外言 'modules/math.ru'.
显 数学 其 平方 9.

# 也可把导出名称导入当前模块，但名称冲突会明确报错
尽 取 外言 'modules/math.ru'.
显 (平方 4).
```

`外言` 后必须是本地文件路径字面量，路径相对**写下该导入的文件**。相同规范化路径只初始化一次，返回同一模块实例。模块导出顶层作用域中的定义 / 绑定，函数保留所属模块的全局作用域；模块中的 `元初` 不会因为导入而自动执行。

标准成员名的语法约束也适用于限定访问：例如导出一个带参数的函数 `量` 后，`模块 其 量 参数` 不能作普通方法调用；可改用 `尽 取 外言` 后按原函数名调用，或为模块导出选择其他业务名称。

循环导入会报告错误，不暴露半初始化模块。`尽 取 外言` 只允许出现在模块顶层，不会悄悄覆盖同名定义。没有在线包管理或隐式下载；编译时静态解析并把模块一起编入输出，运行时不读取 `.ru` 源文件。

示例可从任意工作目录通过文件路径运行：

```sh
python3 ru run examples/modules/main.ru
python3 ru build examples/modules/main.ru -o bin/modules --emit-c dist/modules.c
./bin/modules
```

### 元初：参数与进程退出码

```text
显 '先执行顶层'.
算 元初 外参 为 句 阵:
    显 外参 其 量.
    得 0.
法
```

`元初` 可省略；存在时必须是一个 `算`，恰好接收一个 `句 阵` 参数（名字可自定），返回 `0` 到 `255` 的整数作为退出码。`ru run` 与原生程序都先执行主文件顶层，再调用其 `元初`；外参不含程序文件名。小数、范围外数值、字符串或 `空` 返回值报错。REPL 不自动调用入口。

```sh
python3 ru run examples/entry.ru -- 你好 世界
python3 ru build examples/entry.ru -o bin/entry
./bin/entry 你好 世界
```

### 仍然保留的边界

数字仍是 IEEE-754 双精度；本次没有引入任意精度整数、位运算、闭包、异常机制、自举或优化器。`如是我言` 仍只有明确的未配置入口，详见下文。Python 解释器由 Python 的追踪式 GC 管理引用图；原生运行时使用根引用与追踪回收，能回收数组 / 对象之间的不可达循环。可用 `RU_GC_THRESHOLD=1 RU_GC_STATS=1 ./bin/objects` 压测频繁回收并查看退出统计；统计不是完整内存安全审计。不要把这个原型当作生产级执行沙箱。

## REPL

变量、函数会跨提交保留。输入多行函数、条件、循环时，REPL 等待对应结束关键词；简单语句仍需句点。

```text
如> 算 平方 根 为 数:
… 得 根 * 根.
… 法
如> 平方 9.9.
98.01
如> 平方 根: 12.
144
```

单独的表达式在 REPL 会回显；文件模式丢弃表达式结果，应显式使用 `显`。`:reset` 清空变量 / 函数，`:help` 查看提示，`:quit`、`:q`、`:exit` 退出。Ctrl-C 取消当前未结束的输入或执行。

提交发生运行错误时，会恢复提示符，但不会回滚之前已经执行的赋值或输入输出；这不是事务式 REPL。管道输入不显示提示符。`读` 使用同一个标准输入流，会消费下一行输入。

## 「如是我言」入口

`examples/wish.md` 示范了自由 Markdown 文档，以 `如是我言` 结尾。Org 或其他文本也可以作为意图文档输入。`generate` 以及文件运行 / 编译入口会识别这个结束标记。

**本次只实现入口检测与清楚的未配置错误，没有实现 LLM 生成。** 没有选定提供方、模型、凭据或数据发送授权，因此不会调用任何远程服务，也不会将文档发送到外部、假造生成结果或自动执行生成代码。

之后接入时，应单独完成：选择提供方与传输授权 → 生成 `.ru` → 解析 / 检查 → 让使用者审阅 → 再决定运行。当前没有可用的 `--model`、API key 或在线生成参数。

```text

rulang/interpreter.py     REPL / run 的参考解释器
rulang/compiler.py        AST → C99 直接代码生成
rulang/runtime.h          动态值、集合 / 对象 / 模块、内存管理、作用域、I/O
rulang/cli.py              CLI、REPL、编译器调用、意图入口
rulang/modules.py          本地相对路径加载、规范化缓存与循环检测

tests/test_ru.py           0.1 兼容性与 CLI 回归测试
tests/test_extensions.py   0.2 双后端数据结构、对象、模块、入口回归
tests/test_modules_cli.py  模块加载、错误来源与 CLI 安全检查
.github/workflows/ci.yml   Linux 上多版本 Python 回归测试与示例构建
```

原生后端把表达式和控制流直接翻译成 C 语句 / C 函数；每个值的类型仍在运行时表示和检查，这是动态值模型，不是静态类型推断。集合、对象和模块使用统一的运行时值表示，赋值 / 调用 / 返回保留引用语义。

目前没有闭包、异常处理、优化器、包管理或自举。`check` 不是完整静态类型分析：例如未绑定变量、数值转换、实际参数类型仍可能在运行时报错。编译过程检查整个程序，因此即使某个分支不执行，其中无效的显式函数调用也会阻止编译。
