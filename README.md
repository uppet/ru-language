# 如 · 用中文写程序

如（Ru）是一门使用中文关键词的编程语言。你可以用它做计算、整理文字、写小工具，也可以在配套的如书里画图、做互动小作品。

先用五行代码，种三行星星：

```ru
星星 取 '⭐'.
循 3 次
    显 星星.
    星星 取 星星 + '⭐'.
环.
```

运行后会看到：

```text
⭐
⭐⭐
⭐⭐⭐
```

`取` 记住一个值，`显` 把它显示出来，`循 … 次` 重复做一件事。
把 `3` 改成 `5`，或者把星星换成你喜欢的文字，再看看结果。

如有自己的语法：中文名称、标点和调用方式都有明确规则。跟着小例子动手，就能一点点认识它。

## 第一步：在如书里试一试

第一次来，推荐从**如书**开始。它是运行在你电脑上的网页笔记本：上面写代码，下面看结果，旁边还能记下自己的想法。

1. 按[安装与启动](docs/stable-entry.md#取得同一套工具链)准备好如书。
2. 打开终端给出的完整本机地址，选择「空白如书」。
3. 把上面的代码放进代码格，点击「运行」或按 Shift + Enter。

普通编辑和运行可离线使用，不需要账号或 API key。

一次改一点，运行看看。看到意料之外的结果，也可以先记下来，下一次再找原因。

## 第二步：给程序一点本领

接下来走[入门小路](docs/first-steps.md)。从显示一句话开始，依次学会记住数值、重复、判断，再把几步计算装进一个函数。

例如，让程序帮你记一件小事：

```ru
温度 取 30.
若 温度 >= 28 则
    显 '出门记得带水。'.
另
    显 '出去走走吧。'.
然.
```

把温度改成 `20`，看看另一句话什么时候出现。

不必先背完整语法。先写出能运行的小程序，再带着问题查资料。

## 第三步：做一个自己的小作品

学完基础后，挑一个你感兴趣的方向：

- **整理一份名单**：拆开文字、替换词语、处理一组数据，从[实用库的小例子](docs/practical-libraries.md)开始。
- **画一幅图，让它动起来**：在如书里画柱状图，再试鼠标和键盘互动，从[如观的第一幅图](docs/ruguan-guide.md#从一幅柱状图开始)开始。
- **解一道小题**：读入数字、算出答案，从[如竞的成对求和](docs/contest-library.md#练习一成对求和直到文件结束)开始。

如书起始页也有「基础入门」「文本处理」「如竞题解」「如观互动」模板。选一个打开，读读代码，再决定运行。

做出一点成果，记得点击「保存」下载书本。重新打开会保留文字、代码和历史输出；要继续计算，需要重新运行代码。

## 想用熟悉的编辑器？

也可以把代码保存为 UTF-8 的 `first.ru`，在仓库目录运行：

```sh
python3 ru run first.ru
```

想一句一句试，用交互终端：

```sh
python3 ru repl
```

- VS Code 可搭配独立的[如言扩展](https://github.com/uppet/ru-vscode)，配置方法见[编辑器说明](docs/stable-entry.md#编辑器)。
- Emacs 用户可以使用仓库自带的[ru-lang-mode](emacs/README.md)。

图形小作品继续放在如书里运行。其他运行方式和平台说明见[安装与执行目标](docs/stable-entry.md)。

## 如还在成长

这是一个能实际运行的语言原型，语法和工具仍在演进。小实验、学习和交流都很欢迎；重要用途请先核对能力与限制。

只运行你信任的代码。如书和普通本地执行都有真实的文件访问权限，不能当作运行陌生程序的安全沙箱。
