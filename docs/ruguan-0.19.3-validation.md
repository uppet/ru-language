## 本批契约

- 新增普通画布值成员 `经过秒`／`间隔秒`，均为零参、只读数值，创建初值 0，不新增保留字。
- 每个有效回调开始采样宿主单调钟一次；同回调内读取冻结，回调后沿用快照。经过秒从画布创建起算，包含显式暂停与隐藏页真实间隔。
- 帧间隔取相邻实际帧开始时间之差，首帧和停后恢复首帧为 0；输入回调为 0 且不改变上一帧基准。重复继续或运行中替换每帧回调不重置；帧内停后继续保持当前快照并将下一帧间隔归零。
- 标签页恢复保留真实 gap，不截断、不补帧，不将帧序号／目标 FPS 冒充真实秒数。原一参每帧回调不变。程序可显式限制自己的模拟步长，原始接口不受影响。
- Python 使用私有宿主单调钟，browser-js Worker 使用私有 `performance.now()/1000`。时钟须为非负有限且不回拨；失效时给出不含底层异常内容的友好错误。新画布创建前先验证时钟，失败不部分替换原图。
- HTTP／IPC／Worker 保留身份验证；两运行时在采样前验证事件，拒绝旧画布、未启用事件及注入时间字段。getter 不暴露宿主对象／函数；异常事件不推进快照。
- 时间不进入绘图样式栈或静态历史协议。原 Python 实时时间／行数／内存、外层看门狗和 JS 步数／Worker 超时预算保持，不使用冻结快照作预算钟。
- 同步唯一规范、四种提示词、如书／Emacs 成员提示和同源互动星港示例。文字测量仍未提供。

## 真实 Chrome 验收

在同一冻结树的云端 Linux Chromium，使用实际如书 Run／Save 按钮、原生鼠标和键盘验证 Python 与 browser-js。界面显示如／规范 0.19.3、如书 0.8.3；运行前后生产文件清单与摘要逐字相同。

- 两后端共记录 245 个真实帧（Python 176、JS 69），初始 frame／elapsed／delta 均为 0，同回调重复读取完全一致、数值有限非负，旧帧序号参数保持。分别验证首帧和暂停后首帧间隔为 0，所有鼠标／键盘输入回调间隔为 0。
- 241 个后续帧差检查通过（Python 174、JS 67）：间隔等于当前经过秒减上个帧回调经过秒，输入不推进帧基准。两端各完成一次重复继续与一次运行中重绑，均不重置间隔；实测最大帧 gap 为 2.00620282300224 秒和 1.5 秒，未截断。没有比较两端原始时刻或承诺固定 FPS。
- 同源星港示例在两端实际鼠标开始、Space 暂停、r 继续并抵达 100%；720 × 500 画布各含 46 条绘图命令，准备／抵达截图视觉检查正常。显式暂停约 23／26 秒后仍仅约 7%／6% 进度，而经过秒包含整段暂停，验证示例自己的暂停补偿。未另跑第二轮完整旅程。
- 真实无限帧回调均由原有预算报错并停止；新代码格恢复运行，打印新画布 frame／elapsed／delta 均为 0，恢复静态 scene 两端相同（忽略生成的 canvas_id）。不把该检查说成独立测定 1 秒墙钟限额。
- 4／4 个实际 Save 下载的时序／示例快照，在真实浏览器中解析、序列化往返与历史渲染通过，保留全部绘图命令和原有 7 个 scene 字段。历史状态停止且无 handlers；对四个画布原生点击及按键仍为 0 次回调。此为组件级历史验收，未运行完整应用 Open／filechooser 流程，也未运行 Node／Playwright 可选测试 launcher。
