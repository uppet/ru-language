# 包系统首版设计与验收计划

基线：公开 wip `0fd73a7a1d32c3627d12e9e28a46d50984d0c7d7`，树 `0e7bd2f0d664e25cb95936d8feed495662cf4e25`。仅向 wip 提交；保留 0.21.7 句点书写检查与 0.21.8 原生分析优化。以下为分阶段设计；各阶段落地后再以测试与版本说明确认其实现状态。

## A：语言与本地包

- 可选顶层一次 `吾 言 工程 其 力学.` 声明。`吾`、`言` 不新增全局保留字；只有完整声明上下文识别。声明只提供模块身份，不执行、不导出变量。
- `外言 工程 其 力学` 是静态模块名，完整 `其` 链属于名字。`外言 'file.ru'`、固定标准库名、赋值别名和 `尽取` 保持兼容。具名导入不求值名称。
- `集录.ru` 是一个静态典字面量和可选终止句点；字段为字符串，容器只能含字面量，禁止执行、名称求值、函数、导入。字段 `名`（一个合法 identifier）、`版`（三段版本）、`需如言`（版本约束）、`源码根`（默认 `src`）、`公开`（模块名列表或显式路径典）、`依赖`（alias 到单一来源描述典）。拒绝重复／未知字段、错误类型，保留文件／行／列。
- 清单公开列表写包内相对模块名，例如 `['力学', '流体/管道']`，映射到源码根下相同层级的 `.ru` 文件；包根用 `'.'`，映射 `<包名>.ru`。显式典 `{'力学': 'src/力学.ru'}` 的路径相对集录根，不重复拼接源码根；不提供公开重命名。同一文件不能声明为多个公开名。有声明时严格核作者正式名，省略时按清单／相对路径推导。
- 包唯一正式根是 `名`；消费者 alias 仅选择包实例，须替换为作者根名后核声明。自身可使用正式根名。alias 不得与自身根、固定标准库／随附名冲突。
- 跨包导入必须是已声明依赖的公开入口。字符串文件导入保留，但包内不得越过边界读取未声明或私有文件；真实路径和符号链接一起核查。无清单脚本保留旧路径导入，进入有清单包仍核其公开入口。
- 具名与路径导入按规范真实路径统一实例，保留一次初始化、共享状态／形身份、失败缓存与循环错误。不支持循环初始化。

## B：显式依赖获取

- `ru deps sync [目录]` 读取集录，解析依赖并生成 `集锁.json` 与缓存；run/check/build 永不隐式联网。缺少远程锁或缓存时提示明确同步命令。
- 依赖来源互斥：`路径`；`Git`（HTTPS 或 SSH，`引用`、`子目录`）；`目录`（HTTPS registry）加 `包` 与 `版`。路径相对含依赖的清单。无来源 fallback。
- 版本支持三段 exact 与空格分隔比较区间（`>=1.0.0 <2.0.0`）；不支持的语法明确报错。相同真实来源包一图一个版本；冲突拒绝，不悄悄多版本。
- Git 锁完整 commit；目录下载锁版本与 SHA-256。路径标记可变、不宣称可复现。锁含真实来源，不包含凭据。
- 安全下载：只允许受支持协议；限制 archive 大小／条目／解压总量；拒绝绝对路径、穿越、链接、重复覆盖；校验后原子缓存，不运行 hook 或安装脚本。

## C：公共目录本地原型

- 本地只读目录协议提供搜索、介绍、版本、依赖和下载元数据；本地 fixture 驱动客户端契约测试。
- 仅本地发布命令验证包、归档与不可变版本，生成静态目录；无公共部署、账号、凭据或网络写入口。将来认证与授权必须缺省拒绝，不能把只读原型误称线上注册中心。

## 验收顺序

1. 先提交该设计和新语法／静态清单回归（红）；再实现并跑解析、模块图及三端正反例。
2. 覆盖 alias 与 canonical 声明、公开／私有／未声明依赖、跨路径和符号链接逃逸、重复／失败／循环、旧脚本／标准库，三端裁剪和完整运行时。
3. CLI 单元与本地网络 fixture：版本冲突、锁过期、Git ref/子目录、hash 不符、恶意 tar/zip、缺缓存离线诊断、无隐式联网、原子失败和静态发布不可变。
4. 如书两后端、生成两个提示词的全部 target、Emacs 与独立 VS Code 影响清单；真实未运行平台明确记录。

## 发布前锁恢复修订：format 2

初次独立冻结的 format 1 虽核验内容身份，但每次同步会重解分支／范围，并把本机工程／缓存绝对位置写入锁，不能满足跨机器按同一锁恢复的合同。该版本尚未发布；保留其测试与安全证据，在第二独立候选修订，不把该限制仅留作文档警告。

- `deps sync` 无锁时解析；有锁时恢复精确选择，不重选且不改锁字节。`--locked` 额外要求锁存在；`--update` 才明确重新解析并原子写锁，两选项互斥。旧格式、损坏或清单不符均不自动降级为升级。
- format 2 采用 owners／packages／edges。root 固定；本地包通过经验证的声明 owner＋alias 定位，运行时真实路径去重；远程及内嵌包通过来源派生 cache key＋安全包内相对位置定位。锁不保存自动展开的工程／缓存绝对位置。
- 相对 path 跟随所属声明及工作树布局搬迁；显式宿主绝对 path 保留用户原描述并标不可搬迁，不尝试改盘符或猜测替代位置。Windows 跨盘不强行 relpath；异平台盘符不误当相对。远程归档内仍拒绝绝对及越界 path。
- 缓存位置取当前 `RU_PACKAGE_CACHE`／API 参数。命中完整缓存不联网；缺失／损坏只恢复锁定完整 Git commit 或 registry exact version，下载与原锁摘要、树摘要、集录身份及依赖重核。无法取回原版本明确失败，不跟随移动分支或新版替换。
- 路径依赖仍为 mutable；严格恢复检查集录／版本／依赖未变，不声称锁定普通本地源码。format 1 在获取前拒绝，仅显式 `--update` 可重建，提示可能改变选择。
- 先提交红回归，再实现；新增搬迁工程＋换空缓存＋传递本地／远程依赖＋三端离线产品，branch/range 固定与显式 update、损坏／伪造 locator、绝对路径／跨盘、安全缓存修复、失败不动旧锁等反例。新的生产 hash 重新独立安全审查并跑完整冻结回归。
