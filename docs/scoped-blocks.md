# 0.11.0：作用域块与赋值符号

`段: … 落.` 和语句位置的 `{ … }` 表示同一种独立词法作用域。它们可交错嵌套，也支持 `段：…落。`、`｛…｝`。`段` 后必须有冒号，`落` 后必须有句点；右花括号后统一写句点，语法仍兼容省略。空块可以写 `段: 落.` 或 `{}.`。

## 隔离临时名字

```ru
标题 := '订单'.
段:
    标题 取 标题 + '摘要'.
    { 临时 := 3. 显 临时. }.
    显 标题.                 批. 订单摘要
落.
显 标题.                     批. 订单
```

每次进入块均创建新子环境。直接在块中写 `取` 或 `:=`，都只建立／更新该块的局部名字，不覆盖外部同名绑定；赋值右侧读取仍向外查找。块内的 `若`、`循` 和 `试` 自身不创建环境，继续写块局部。`救` 仍创建自己的子环境；另一个显式块也创建自己的环境。阵、典、对象的内容修改仍对共享它们的代码可见。

## 循环中的独立闭包

```ru
回调们 := [].
序 := 0.
循 3 次
    {
        快照 := 序.
        回调们 其 增 (算: 得 快照. 法).
    }.
    序 := 序 + 1.
环.
显 回调们[0]().              批. 0
显 回调们[1]().              批. 1
显 回调们[2]().              批. 2
```

闭包共享它实际捕获的绑定，离开块后仍能读取和更新该块环境。同次进入创建的多个闭包共享状态，不同次进入的环境独立。函数内 `取` / `:=` 沿用原规则：当前调用局部优先，否则更新最近已有的非模块捕获绑定，其中现在也包括块绑定；都没有才创建函数局部。块内直接赋值始终局部，不能借块直接改外层绑定。

有名 `算` / `作` 可以直接写在显式块中，在每次进入块时提升，支持前向调用、自递归和相互递归。它们不会向块外导出名字；要保存闭包，可将函数值加入外部共享阵／典或从外层函数返回。普通赋值不提升，不能读取尚未建立的捕获变量。

## 保持原来的控制流

块不创建函数或循环边界。`得` 返回最近的算，`完` 结束最近的作，`破` 退出当前调用中的最近循环，`续` 跳过该循环本轮并进入下一轮，`卒` 可由外部救恢复。仅在原先合法的上下文中可以使用这些语句，块不会使顶层 `得` / `完` / `破` / `续` 变合法。

`形` 与 `尽取 外言` 仍只能写在模块顶层；模块直接包含的块，其内部也不是顶层。普通 `工具 := 外言 '工具.ru'.` 可以在块内建立局部模块值。离开块不撤销副作用，也不是资源自动关闭或事务机制。

## 典与块按位置区分

- 等待语句时，`{` 总是开块；裸 `{}` 是空块
- 赋值右侧、`显` / `得` 后、实参和容器元素等表达式位置，`{目: 相}` 仍构造典，`{}` 仍是空典
- 独立典表达式语句使用分组：`({'键': 1}).` 或 `({}).`；也可用文字形式 `典: 成.`
- 表达式花括号里不能写语句；`段: … 落.` 不是表达式，不能放在赋值右侧

这是相对 0.10.1 的唯一花括号位置迁移：之前裸 `{'键': 1}.` 是典表达式语句，现在需要分组。普通 `表 取 {'键': 1}.`、`显 {}.` 和嵌套典无需改写。

`段`、`落` 没有全局保留。`段 取 1.`、`落 := 2.`、`其 段 始:0 终:2`、参数／成员／长名称保持可用。只有等待语句时完整 `段` 后跟冒号才开块，且当前中文块正文等待语句时完整 `落` 后跟句点才关块；`落 取 2.` 不会误关块。标记之间可以有空白或注释。字符串和注释里的伪结构没有作用。

## `:=` 与 `取` 完全等价

```ru
甲 := 1.
甲 取 甲 + 1.
列 := [0].
列[0] ：= 甲.
工具 := 外言 '工具.ru'.
```

名称、对象可写成员、阵索引及其他既有可写目标均支持同一赋值语义；`:=` 不新增典的索引赋值。必须使用连续的 `:=` 或 `：=`，不接受 `: =`、`： =` 或全角等号 `＝`。它不是赋值表达式，不能写 `显 (甲 := 1).`。`尽取 外言` 是独立导入语句，`尽取` 须连写，不使用 `取` 或 `:=` 赋值符；典条目、命名参数和块头仍用单独冒号。
