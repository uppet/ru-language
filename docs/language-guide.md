## 基本写法

### 字符、语句和数值

- UTF-8 源码；关键词、名称一般用空白分开。`信@含`、`左+右` 可以紧贴运算符
- 关键词按完整名称识别；`为乐` 这样的名称不会因包含 `为` 被拆开。`阵` 是类型名称，不是词法保留字；完整保留字表见[语言规范](../rulang/language-spec.md)
- 完整语句统一以 `.` 或 `。` 结束，包括命名算／作、形、若、循、试／救和语句花括号块；换行只作为空白。旧源码省略块末句点仍可运行，普通检查／编译提示，`--strict-style` 检查失败；匿名算／作、典、阵等表达式不额外加点
- 支持 `:` / `：`、`()` / `（）`、`,` / `，`
- 字符串支持 `'…'`、`"…"`、`‘…’`、`“…”`；支持 `\n`、`\r`、`\t`、`\\` 和被转义的引号
- 字符串允许换行，不允许 NUL；源码和标准输入需为有效 UTF-8
- `#`、`//`、`批.` / `批。` 开始行注释，可跟在代码后；`解.` / `解。` 到首个 `释.` / `释。` 为非嵌套块注释。字与标点必须紧邻，字符串内不生效，`批评` / `解释` 等完整名称不被拆开；注释标点不替代前一语句的句点。未闭块在 REPL 中待续，文件中报错
- 值包括 `句`（不可变字符串）、`数`（IEEE-754 双精度浮点数）、`事实`（`真`／`假`）、`空`、不可变 `对`、可变引用 `阵`与`典`、函数值、对象与模块
- 不是大整数 / 十进制定点语言。超过约 15 位有效数字会有精度限制；输出最多 15 位有效数字。不要用于金额或精确整数大数计算
- `1`、`-2.5`、`.5`、`1e3` 可用；尾部句点是语句结束符，因此源码中 `1.` 表示数值 `1` 加终止符
- 拒绝 NaN、Infinity 和非有限运算结果；除以零报错

### 显示、绑定、赋值和转换

```text
显 ‘你好，世界’.

左 取 (读 提示: '输入第一数：') 为 数.
右 取 (读 提示: '输入第二数：') 为 数.
中 取 左 + 右.
显 中.

中 取 中 + 1.
显 中 为 句.
```

`显` 输出一行。`取` 新建或更新绑定，不固定绑定的类型；函数内可更新最近已有的非模块捕获绑定，详见本页闭包规则。`为 数` 和 `为 句` 是显式值转换；转换结合整个左侧表达式，必要时用括号明确范围。

`句` 转 `数` 接受前后 ASCII 空白、正负号、十进制与科学计数法。空串、乱码式数字、`0x10`、`nan` 等报错，不悄悄变成零。`数` 转 `句` 使用与 `显` 相同的格式。

`读` 返回标准输入的一行，去掉结尾换行。`读 提示: '…'` 先显示提示且不换行。真正到达 EOF 时会报错退出，避免没有新输入的循环不断输出；按回车得到的空行仍是合法空串。

### 函数、过程和调用

```text
算 平方 根 为 数：
    得 根 * 根.
法

显 (平方 9.9).
显 (平方 根: 9.9).

作 祭拜 :
    显 ‘叩’.
    显 ‘叩’.
    显 ‘叩’.
    循 9 次
        显 ‘拜’.
    环
为 .

祭拜.
```

- `算` 以 `法` 结束，使用 `得 表达式.` 返回结果；某条实际执行路径没有 `得` 会报错
- `作` 以 `为` 结束，不允许 `得`；自然结束或执行 `完.` / `完。` 都返回 `空`。`完` 不携表达式，仅退出当前过程，可用于条件、循环、试 / 救及过程方法、匿名过程内；不能在顶层或 `算` 内使用，也不能从嵌套 `算` 退出外层 `作`。`完` 不关闭语法块，后续 `为` 仍必需。正常单独调用不会额外显示返回值
- 不强制 `算` 纯函数，可以使用 `显`、`读` 等
- 参数可只写 `名称`，接受任何运行时值（包括 `空`）；也可写作 `名称 为 数`、`名称 为 句`、`名称 为 阵`、`名称 为 句 阵` 或 `名称 为 自定义形` 等；显式类型需要匹配，不自动转换。一个声明可混用两者，使用空白或逗号分隔；所有实参仍必需
- **位置实参**：`函数名 表达式`。例如 `平方 9.9`；多个位置实参按参数声明顺序匹配，可用空白或逗号分隔，例如 `差 9 4`、`差 9, 4`
- **命名实参**：`函数名 参数名: 表达式`。例如 `平方 根: 9.9`；多个命名实参按名字匹配，可调整顺序，例如 `差 右: 4 左: 9`
- 同一次调用不能混用位置实参与命名实参；两种写法的实际值都按源码从左到右求值，参数个数和类型必须匹配
- 直接声明的零参数函数 / 过程保留裸名称调用，例如 `祭拜.`；`读` 也是如此。保存到变量或参数中的函数值不会因裸名称自动执行，无参数时用 `回调()`
- 每个实参都是尽量向右读取的完整表达式：`平方 2 + 1` 是对 `3` 求平方。要把调用结果参与运算，请写 `(平方 2) + 1`；命名实参规则相同
- 实参中再调用带实参的函数，必须加括号，例如 `差 (平方 3) (平方 根: 2)` 或 `差 左: (平方 3) 右: 2`。`差 甲 乙` 中的 `甲`、`乙` 各是一个实参，不会隐式变成 `差 (甲 乙)`；普通变量和零参函数不需括号
- `+`、`-` 不会在函数名后直接开启位置调用，仍按加减运算解析，以保留 `变量 - 2`、`零参函数 - 2`。第一个负数位置实参写 `平方 (-2)`；后续负数写 `差 2 (-3)` 或 `差 2, -3`。`差 1 -2` 只有一个实参 `1-2`，会提示缺少参数。命名写法 `平方 根: -2` 仍直接可用
- 实参列表属于函数名后面的序列；`差 9 4` 或 `(差 9, 4)` 可用，不采用 `差(9, 4)` 形式的括号实参列表
- 内置 `读` 也接受位置提示：`读 '输入：'` 等价于 `读 提示: '输入：'`，省略提示时仍可直接写 `读`
- 函数 / 过程可直接定义在模块、函数 / 方法、救或显式作用域块的正文中，形内可定义方法；条件、循环、受保护的试正文不能直接声明。定义在所属作用域进入时预先登记，支持前向调用和递归；调用深度上限 128
- 源码表达式 / 块的嵌套也有限制（原型上限 128 层），过深时给出诊断，不显示 Python 回溯
- 函数按词法环境读取变量。函数内 `取` 更新当前局部或最近已有的捕获函数 / 救 / 显式作用域块绑定，否则新建局部；**不会修改同名模块全局绑定**。参数始终局部，直接救正文的 `取` 仍只写救的子作用域；直接显式块正文的 `取` / `:=` 只写当前块局部。条件、循环、试本身不新增作用域，显式块每次进入都新建环境
- 直接声明的函数名、过程名、内置 `读` 不能同时作为变量名或参数名

### 函数值与词法闭包

```ru
算 造计数 起点 为 数:
    数值 取 起点.
    算 增加 步 为 数:
        数值 取 数值+步.
        得 数值.
    法.
    得 算 增加.
法.
甲 取 造计数 0.
乙 取 造计数 10.
显 (甲 2). # 2
显 (甲 3). # 5
显 (乙 1). # 11
```

`算 增加` 取得函数本身，不调用它；过程引用使用 `作 名`。即使工厂已返回，闭包仍保留外层环境。一次工厂调用里产生的闭包共享捕获绑定，不同调用分别保存自己的状态。函数值可以放入阵、对、字段，也可传参和返回；参数 `回调 为 算` / `回调 为 作` 分别检查种类，真正调用时继续检查参数签名。

保存的零参函数值写 `回调()`；裸 `回调` 只读取该值。带参调用仍写 `回调 3` 或 `回调 参数名:3`，不新增 `回调(甲,乙)` 风格参数列表。索引得到的回调可写 `回调们[0] 3` 或 `回调们[0]()`，对象的函数值字段可写 `对象 其 回调 3`。

用户方法引用写 `算 对象 其 方法` 或 `作 对象 其 方法`，以后调用仍绑定同一对象；模块函数引用写 `算 模块 其 函数`。同一闭包的别名共享身份，分别取得的绑定方法引用是不同函数值。内置 `读`、集合成员和 I/O 方法暂不支持取引用。

直接救正文的变量绑定不向外泄露；救内定义的闭包能保留该救环境。方法内闭包也可保留自身及方法局部。捕获采用词法作用域，不使用调用者的局部变量；函数中的 `取` 不更新模块全局。完整约束和求值边界见唯一规范第 4.5、6.4 节。

[`examples/closures.ru`](../examples/closures.ru) 同时演示共享计数状态、两个独立工厂实例，以及每次调用生成器执行一次 `新`，再用已有的 `循` 和 `其 增` 得到独立对象阵。未新增数组填充语法。

### 匿名函数与过程字面量

在表达式中省略函数名，参数直接写 `名称` 或 `名称 为 类型`，可混用，冒号必需：

```ru
平方 取 算 值 为 数:
    得 值 * 值.
法.
问候 取 作 名 为 句:
    显 ('你好，' + 名).
为.
报到 取 作:
    显 '到了'.
为.
显 (平方 4).       # 16
问候 '小如'.      # 你好，小如
报到().           # 到了
```

`算 … 法` 和 `作 … 为` 本身产生函数值；结束词后的句点结束外层赋值、返回或表达式语句。作为阵元素或实参时，结束词后直接接外层逗号、括号或后续实参，不在字面量内部额外加句点。正文中的简单语句仍各有句点。

```ru
算 应用 回调 为 算 值 为 数:
    得 回调 值.
法.
显 (应用 (算 值 为 数: 得 值 * 值. 法) 5). # 25
显 ((算 值 为 数: 得 值 + 1. 法) 4).      # 5
算 造计数 初值 为 数:
    当前 取 初值.
    得 算 步 为 数:
        当前 取 当前 + 步.
        得 当前.
    法.
法.
计数 取 造计数 10.
显 (计数 2). # 12
显 (计数 3). # 15
```

- 零参写 `算: … 法` 或 `作: … 为`；无箭头语法，也不用圆括号包参数声明
- `算 名` / `作 名` 仍是有名引用，`算 名 为 句` 仍可转换引用的显示值；完整参数头后的冒号才区分匿名字面量，例如表达式中的 `算 值:` 是一个无类型参数的匿名算；`算 (表达式)` / `作 (表达式)` 仍按原有引用目标规则解析，不是括号参数表
- 字面量按表达式执行，每次求值创建新函数值；保存到同一变量的别名保留身份。正文只在调用时执行，不会像有名声明一样提升
- 捕获共享词法绑定，外层返回后仍存活；同次工厂调用的闭包共享状态，不同工厂调用相互独立。更新捕获、模块全局保护、自身和救作用域与有名闭包一致
- 匿名正文可有嵌套声明、匿名字面量和控制流；字面量也可出现在条件、循环或试正文的表达式中。有名声明的位置限制保持不变
- 匿名 `算` 仍须实际执行 `得`，匿名 `作` 不能 `得`，可用 `完.` 提前返回 `空`；参数数量、名字、类型和循环 `破` 的调用边界沿用原规则
- 保存后的调用沿用空白 / 命名实参；立即带参调用用 `(算 参数 为 类型: … 法) 实参` 分组函数值，零参用 `(算: … 法)()`

完整的赋值、传参、返回与共享状态示例见 [`examples/anonymous.ru`](../examples/anonymous.ru)，规范见第 4.6、6.4 节。

### 条件、循环、成员语法

```text
信 取 '空'.
循
    显 信.
    信 取 (读) 为 句.
    若 信@含 '再见' 则
        破.
    另
        显 信.
    然
环
```

`信@含 '再见'` 和 `信 其 含 '再见'` 完全等价，都是**包含**测试，没有取反含义。

`若 条件 则 … 另 … 然` 的 `另` 可省略。0.23.0 可在末尾 `另` 之前添加多个 `另若 条件 则`，整条链只用一个 `然.`；按顺序只执行首个命中分支，之后的条件不再求值。`另若` 须连写，`另 若` 仍是嵌套，各自需要 `然`；完整旧名称 `另若` 需要改名，`另若值` 等长名称不受影响。完整例子见 [`examples/elif.ru`](../examples/elif.ru)。`循 次数 次 … 环` 为计次循环；不写次数就是无限循环；`破.` 退出当前最内层循环；`续.` 跳过本轮剩余正文、继续下一轮，计次循环仍正常推进。两者不能跨越函数或回调边界，循环外使用会报错；`完.` 则结束当前作，不是继续循环。计次表达式只在进入循环时求值一次，必须是 0 到 2^53−1 之间的整数。无限循环由程序自己 `破`，终端中也可以 Ctrl-C 中断。

### 运算

运算顺序从高到低：括号 / 调用 / 索引 / 成员，一元 `+ - 非`，`* / %`，`+ -`，`< <= > >=`，`== !=`，`且`，`或`，`对`，`为 类型`。`对` 是右结合运算；组合复杂表达式时建议显式加括号。

- 数字支持普通算术；`%` 采用浮点余数，符号跟随被除数，例如 `-7 % 3` 是 `-1`
- 两个 `句` 可用 `+` 连接；不会自动把数字转成字符串
- 比较、包含、`非`、`且`、`或` 返回 `事实`：`真` 或 `假`
- 条件中，只有 `空` 和 `假` 为假；0、空串、空阵、空典与其他值都为真
- `且` / `或` 短路求值；例如 `假 且 (1 / 0)` 不会除以零
- 大小比较需要相同类型；字符串按 Unicode 字符顺序比较，不是拼音排序
- 跨类型 `==` 为假，`!=` 为真；二元组按结构比较，数组 / 典 / 函数值 / 模块按引用身份比较，对象可用同协议；不支持链式比较的数学简写，请写 `值 > 1 且 值 < 5`

## 数据结构、对象、模块与入口

### 空与对：一条不可变链表

```text
链 取 1 对 2 对 3 对 空.
显 链 其 囫.                # 1，左项
显 (链 其 囵) 其 囫.        # 2，右项的左项
显 (1 对 空) == (1 对 空).  # 真，按结构比较
```

`空` 是独立值，显示为 `空`，与句 `'空'`、数 `0`、空句 `''` 都不相等。`对` 右结合，上面的链等价于 `1 对 (2 对 (3 对 空))`；`囫` / `囵` 只能读取，不能用 `取` 改写。二元组中的数组 / 对象仍保持引用身份，不会深复制。

完整遍历、求和、逆序示例：`examples/linked_pairs.ru`。

### 阵：共享引用、索引与浅切片

`[甲, 乙]` 创建一个阵，也可以把阵放进另一个阵。下列示例说明共享引用与切片的区别。

```text
数列 取 [3,1,2].
别名 取 数列.
别名[0] 取 9.
数列 其 增 4.
显 数列[0].                 # 9
显 数列 其 量.              # 4
显 数列 其 位 1.            # 1
显 数列[1:3].               # [1, 2]
显 数列 其 段 始:1 终:3.    # [1, 2]
```

- `[]` 新建空阵，`[甲, 乙]` 按源码顺序求值，可混装不同类型
- `值 为 阵` 总是创建**包含这个值的单元素阵**：`空 为 阵` 是 `[空]`，已有阵或对象也只是包装一层，不会展开或复制
- 阵赋值、实参、返回值均共享引用；`其 增 值` 追加一项，并返回同一个阵
- `其 量` 返回长度；`其 位 索引` 与 `[索引]` 等价，均可作为 `取` 左侧。`位` / `增` 的命名实参分别写 `位:索引` / `值:值`
- 标准成员统一使用普通实参语法：`列 其 增 1+2` 追加3；若要对成员结果加2，写 `(列 其 位 0)+2`。命名实参和位置实参不能混用，嵌套调用用括号明确边界
- 名称后紧贴 `[` 表示索引，如 `列[0]`；空白分隔的阵字面量可作位置实参，如 `求和 [1,2]`。复杂场合可写 `求和 ([1,2])` 明确边界
- 索引从 `0` 开始，必须是整数，满足 `0 <= 索引 < 长度`；负数、小数、越界均报错
- `[始:终]` 和 `其 段 始 终` / `其 段 始:始 终:终` 左闭右开，要求 `0 <= 始 <= 终 <= 长度`，不自动截断。方括号中省略始 / 终分别取 `0` / 长度；`[:]` 取全部
- 切片创建新阵，但里面的阵 / 对象仍共享引用，是**浅复制**。本版不支持切片赋值
- 阵的 `==` 检查是否同一实例；两个内容相同的新阵并不相等
- 参数 `列 为 阵` 接受混合阵；`列 为 数 阵` / `列 为 句 阵` 在调用时检查各元素。此注解不把阵变成不可变或永久限定元素类型的容器

原地排序及别名示例：[array_sort.ru](../examples/array_sort.ru)。返回新阵的排序、另成和逐位遍历见[阵指南](array-sort-map.md)。

### 句：Unicode 码点索引与切片

```text
文 取 '甲😀é乙'.
显 文 其 量.      # 4
显 文[1].         # 😀
显 文[1:3].       # 😀é
显 文[:1].        # 甲
显 文[3:].        # 乙
```

`句` 支持同样的 `量` / `位` / `段` 和方括号读操作，仍然不可变；给字符赋值或追加会报错。位置按照 **Unicode 码点**，不是 UTF-8 字节，也不是视觉字形：组合附加符号、emoji ZWJ 序列可能占多个位置。示例：`examples/unicode_slices.ru`。

### 典的符号字面量

典的每个条目由**目（key）**与**相（value）**组成：目用于查找，相是该目对应的值。`目`、`相` 是教学术语，不是新增关键字；`值` 仍是语言的通用概念。典的成员命名实参统一使用 `目:`、`相:`：`查 目:`、`增 目: 相:`、`除 目:`；不再接受旧名 `键:`、`值:`。位置实参不变；遍历改为 `逐目 回调:`，回调内部参数名由用户自定。

`表 取 {'上': 0, '下': 2}.` 与 `表 取 典: '上' 对 0. '下' 对 2. 成.` 等价，两种写法可共存、互相嵌套。空典可写 `{}`；允许换行、尾逗号和全角 `｛｝`、`：`、`，`。目和相都是表达式，`{目: 相}` 会读取变量 `目`，不会自动把它变成字符串。表达式位置的花括号构造典，外层语句仍以句点结束；0.11.0 起语句位置的花括号是作用域块，裸 `{}` 是空块。要单独求值空典写 `({}).`。

条目内带参数调用和带字段参数的 `新` 构造应加括号，与阵元素相同：`{(f 1): (g 值:2), 'x': 3}`。括号内 `值:` 是命名实参，括号外冒号分隔典的目与相；括号也防止调用继续吞掉条目逗号。典的键类型、同／印、源码求值顺序、重复覆盖和共享引用规则不变。见[符号典示例](../examples/map_symbol_literals.ru)和[完整规范 7.6](../rulang/language-spec.md#76-典可变哈希映射)。

### 典的方括号读取

`戏['心']` 与 `戏 其 查 '心'` 等价，缺失键返回 `空`。支持典原有数、句、事实与合法同／印形键，不按阵的数值索引检查；阵／句行为保持不变。此简写只读取，典的更新继续用 `其 增`，不支持 `典值[键] 取 值.` 或典切片。见 [`examples/map_index_read.ru`](../examples/map_index_read.ru)。

### 形、对象、继承和方法

```text
形 计数器:
    值 为 数.
    作 增加 步 为 数:
        其 值 取 其 值+步.
    为
    算 报数:
        得 其 值.
    法
象
形 命名计数器 如 计数器:
    名 为 句.
    算 报数:
        得 其 值+1.
    法
象
甲 取 新 命名计数器 名:'计数' 值:2.
乙 取 甲.
乙 其 增加 3.
显 甲 其 报数.    # 6
```

- `形 名 [如 父形]: … 象` 声明对象类型；字段写作 `字段 为 类型.`，方法使用原有 `算 … 法` / `作 … 为` 语法
- `新 形名 字段名:值 …` 以命名字段初始化；实参按源码顺序求值，继承字段也可初始化。省略字段默认为 `空`，字段均允许 `空`；其他赋值必须符合声明类型
- `对象 其 字段` 读取；`对象 其 字段 取 值.` 修改。对象按引用传递，别名会看到修改
- `对象 其 方法 实参` 支持位置与命名调用；方法里 `其 字段` 简写当前对象字段，裸 `其` 返回自身。方法外使用自身会报错
- 子形继承字段与方法；覆盖方法必须保持参数名字、类型和算 / 作类别；无类型只能匹配无类型，不能在覆写时增加或去掉显式注解；类型在各自声明模块中解析，比较形身份及阵的元素类型，而不是仅比较名称文字。继承方法内部调用其他方法仍按实际对象类型动态分派
- 形名称只用于类型注解、`新`、`如` 和合法导入，不是普通值；`别名 取 学生.`、`显 学生.`、返回或传递形本身均不合法。内置形名称也不能存作普通值
- `如 父形` 的父形必须是直接声明或通过 `尽取 外言` 导入的用户形名称；跨模块构造用 `尽取` 导入形或调用返回实例的工厂，不支持 `新 模块 其 类型`
- 方法参数类型在形解析时绑定身份；字段 / 方法注解引用的导入形须已由 `尽取` 导入，本地直接形声明仍可前向引用。REPL 重定义同名形产生新身份，旧方法保留原签名身份；普通函数注解在调用时按声明模块解析
- 父形参数接受子形实例；同名字段冲突、不兼容方法覆盖和继承循环报错。不支持多继承
- 成员名字不全局固定签名；对象可有含、位、段、增、量等字段或方法，按实际声明绑定参数。阵增一参、典增两参并存
- 同一具体形有 `算 同 另一` 时按其事实结果比较；无同则按引用身份，不同具体形直接不相等。形键还必须提供返回安全整数的零参算印。构造器不隐式执行用户初始化方法

0.6.x 形别名代码需要改为直接使用形名称。例如 `别名 取 学生. 甲 取 新 别名.` 改为 `甲 取 新 学生.`；跨模块的 `别名 取 模块 其 学生.` 改为 `尽取 外言 'students.ru'.` 后使用 `学生`。若需要保存或传递构造行为，使用返回实例的函数：

```ru
形 学生: 名 为 句. 象.
算 造学生 名 为 句: 得 新 学生 名:名. 法.
工厂 取 算 造学生.
甲 取 工厂 '小明'.
乙 取 甲.
显 乙 其 名.
```

完整实例别名、继承、动态分派示例：`examples/objects.ru`。学生 / 上进学生、`名` / `龄` / `族`、`报道` 与班级数组示例：`examples/students.ru`。`助人`、`为乐` 不属于内置命令；`为乐` 可以作为普通函数或变量名，但需要自行定义。

### 外言：相对路径模块与标准库

```text
数学 取 外言 'modules/math.ru'.
显 数学 其 平方 9.

# 也可把导出名称导入当前模块，但名称冲突会明确报错
尽取 外言 'modules/math.ru'.
显 (平方 4).
```

`外言` 接受字符串字面量，自 0.22.0 起也接受静态模块名，例如 `外言 工程 其 力学`；整个其链属于名字，不求值。具名模块由静态集录声明依赖和公开入口，见[包系统](packages.md)。普通本地路径相对**写下该导入的文件**；`如:竞`、`如:观`、`如:文本`、`如:数学`、`如:随机`、`如:密` 解析到随工具链发布的标准库。精确名称 `如见` 解析到独立目录的随附三方 Win32 库，现阶段不属于语言标准，没有 `如:见` 别名；它和如:密都受原生能力边界约束。以 `如:` 开头的名称保留给标准库，未知名称报错，不会退回当前目录寻找同名文件；旧精确名称 `如竞`、`如观`、`如:竞赛` 给出迁移错误，不作为别名或本地路径使用。相同规范化路径只初始化一次，返回同一模块实例。模块导出顶层作用域中的定义 / 绑定，函数保留所属模块的全局作用域；模块中的 `元初` 不会因为导入而自动执行。

模块限定访问使用普通成员实参语法，导出量等同名函数时按实际声明调用。

全量导入统一写作 `尽取 外言 '如:数学'.`。`尽取` 是完整关键字，`外言` 保持不变。旧 `尽 取 外言` 已停用并给出迁移提示；单字 `尽` 仍保留用于诊断。没有 `进取` 或 `言` 别名，`尽取值` 等长名称仍是普通名称。详见[全量导入迁移说明](import-all-migration.md)。

循环导入会报告错误，不暴露半初始化模块。`尽取 外言` 只允许出现在模块顶层，不会悄悄覆盖同名定义。包依赖通过 `ru deps sync` 显式获取，没有隐式下载或默认公共包目录；见[包与具名模块](packages.md)。编译时静态解析并把模块一起编入输出，运行时不读取 `.ru` 源文件。

示例可从任意工作目录通过文件路径运行：

```sh
python3 ru run examples/modules/main.ru
python3 ru build examples/modules/main.ru -o bin/modules --emit-c dist/modules.c
./bin/modules
```

### 元初：参数与进程退出码

```text
显 '先执行顶层'.
算 元初 外参 为 句 阵:
    显 外参 其 量.
    得 0.
法
```

`元初` 可省略；存在时必须是一个 `算`，恰好接收一个 `句 阵` 参数（名字可自定），返回 `0` 到 `255` 的整数作为退出码。`ru run` 与原生程序都先执行主文件顶层，再调用其 `元初`；外参不含程序文件名。小数、范围外数值、字符串或 `空` 返回值报错。REPL 不自动调用入口。


### 仍然保留的边界

数字仍是 IEEE-754 双精度；没有任意精度整数、位运算、自举或优化器。显式 `卒` 可由 `救` 处理，一般运行错误仍按原有方式报错。运行时与回收实现见[开发指南](development.md)。不要把这个原型当作生产级执行沙箱。

## 文件、目录与可检查的 I/O

`件`、`录`、`件作成果` 是内置形；`读取`、`显出`、`错误` 分别是标准输入、标准输出、标准错误对象。它们使用已有 `其` / `@` 成员调用语法。`读`、`显` 便捷写法保持兼容。

```text
文档 取 新 件 路径: '笔记.txt'.
成果 取 文档 其 读.
若 成果 其 结果 == '成功' 则
    显 成果 其 值.
另
    显 成果 其 错误信息.
然

# 写会截断原文件；追加:1 才追加。请检查每次返回的成果。
写入 取 文档 其 写 内容: '你好\n'.
追加成果 取 文档 其 写 内容: '再会\n' 追加: 1.
存在 取 文档 其 在.
目录 取 新 录 路径: '.'.
清单 取 目录 其 列.
# 删除操作为 文档 其 除，只在确实需要时调用。
```

每次真实 I/O 返回 `件作成果`，具有三个成员：

- `结果`：`'成功'` 或 `'失败'`
- `值`：成功时的有效载荷；失败时为 `空`
- `错误信息`：成功时为空句，失败时为原因。错误文字可随操作系统变化，不应靠完整文字判断逻辑

`件作成果` 的字段可按普通对象规则修改；`值` 可持有任何如值。通常应直接检查操作返回的原始结果，而非改写其状态。

操作约定：

- `新 件` 默认 `路径:''`，`新 录` 默认 `路径:'.'`；构造只创建值，不接触文件系统。相对路径相对于进程工作目录
- 件的 `读` 一次读取完整 UTF-8 文本，空文件成功返回空句。暂不支持二进制、NUL、无效 UTF-8；文本保留原有换行
- 件的 `写 内容:句 追加:数` 默认 `追加:0`，截断 / 创建文件；`追加:1` 为追加，不自动添加换行。成功的 `值` 为 `空`
- 件的 `在` 成功返回事实 `真` 或 `假`。路径指向普通文件为 `真`，不存在或指向目录等非普通文件为 `假`；权限等检查失败仍是失败成果
- 件的 `除` 删除该文件，成功返回 `空`；不存在或尝试删除目录返回失败
- 录的 `列` 非递归、按名称排序，返回由 `件` 组成的阵，各项 `其 路径` 可继续读取。只列普通文件，不列子目录
- 文件读、写、存在判断以及目录列举中的文件判断跟随符号链接；删除符号链接只删除链接本身。列举不是原子快照；已消失的项和悬空链接略过，其余扫描、检查或关闭错误返回失败，不把部分结果冒充成功
- 文件每次操作独立打开并关闭；读取、短写、刷新与关闭错误都要检查。写入失败可能已经改变文件的一部分，不提供事务、回滚、持久化 `fsync` 或原子替换保证
- 程序使用当前进程的文件权限；不会修改权限。I/O 接口不是访问沙箱；本轮原生 I/O 在 Linux / POSIX 上验证，Windows 原生分支未实测

标准流：

```text
循
    一行 取 读取 其 读.
    若 一行 其 结果 != '成功' 则
        卒 一行 其 错误信息.
    然
    若 一行 其 值 == 空 则 破. 然
    输出 取 显出 其 写 内容: (一行 其 值) + '\n'.
    若 输出 其 结果 != '成功' 则 卒 输出 其 错误信息. 然
环
```

`读取 其 读` 每次读取一行，去掉行尾 LF / CRLF；EOF 为成功且 `值 == 空`，空行为成功且 `值 == ''`。`显出 其 写 内容:句` / `错误 其 写 内容:句` 不加换行，返回前刷新，成功值为空；它们不关闭标准流。传统 `读` 仍在 EOF 报错，传统 `显` 仍输出一整行。

## 卒与恢复

```text
算 检查 值 为 数:
    若 值 < 0 则 卒 '值不能为负数'. 然
    得 值.
法

试
    显 (检查 (-1)).
救 原因
    显 '已处理：' + 原因.
终
显 '继续'.
```

- `卒 表达式.` 要求表达式为 `句`，将原因传到最近动态生效的 `试`，包括被调用函数、方法与模块内的 `卒`
- `试 … 救 原因 … 终` 必须带 `救` 和原因名称；正常路径跳过救的正文
- 试的正文与外部共用作用域；救的正文有子作用域。原因名称和救中 `取` 的本地绑定不会覆盖或泄露到外部；修改已有阵 / 对象的内容仍然共享
- 恢复后从 `终` 后继续，不恢复卒位置；救中再次卒向外层试传播，不被自己捕获。允许嵌套、函数返回与循环 `破`
- 没有匹配救时，命令以非零状态结束并在 stderr 报告原因和源位置；REPL 报告后继续接收下一段输入
- 已经完成的变量变更与 I/O 不会回滚。模块初始化卒后会保留其环境，使已经对外共享的对象仍可用；再次导入会重抛缓存的原始原因与位置，不自动重做初始化副作用。重新启动程序或 REPL `:reset` 才清空这项状态
- 普通 I/O 失败只是成果，需由程序决定是否卒；除零、类型错误、未定义名称等一般运行错误暂不属于救的捕获范围
- 新保留字为 `试`、`救`、`卒`；`终` 是上下文结束词，原有 `其 段 始:0 终:2` 保持可用。尚无 finally / 自动资源管理语法
- 原生后端显式传递 panic 并逐层清理临时根、局部环境与调用状态，仍输出独立 C99 程序

示例见 `examples/checked_io.ru`、`examples/recovery.ru`；`ru-lang-mode` 同步支持新块的高亮、缩进与跳转。

## 作用域块与赋值符号

```ru
名字 := '外部'.
段：
    名字 取 '块内'。
    { 临时 ：= 42. 显 临时. }.
    显 名字。      批. 块内
落。
显 名字.          批. 外部
表 := {'键': 1}.  批. 表达式位置仍是典
```

`段:` / `落.` 的冒号和结束句点必需；等价花括号块统一写结束句点，语法仍兼容省略。`段`、`落` 不全局保留，`其 段` 切片及长名称不变，块中 `落 取 值.` 不会关闭块。显式块内的名称绑定局部遮蔽外部；条件、循环和试沿用该块，救仍有自己的环境。每次进入块均创建新环境，闭包保留该次环境，适合在循环中保存独立回调。有名函数在块入口提升；`得`、`完`、`破`、`续` 沿用外层函数／过程／循环，形和 `尽取 外言` 仍限模块顶层。

`:=` / `：=` 只在赋值语句中等价于 `取`，支持名称、可写成员和索引，也支持 `模块 := 外言 '模块.ru'.`。符号必须连续，不能写 `: =` 或全角等号；赋值不能嵌入表达式。`尽取 外言` 是独立导入语句，`尽取` 须连写，不能改成 `尽 :=` 或 `尽取 :=`。完整边界与迁移说明见[作用域块指南](scoped-blocks.md)。
