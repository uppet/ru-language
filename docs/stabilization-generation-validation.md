最终真实云桌面 Chromium 154.0.8037.57（Debian 13）验收通过，使用本机模拟 Responses 服务，没有真实模型请求。85 个运行文件逐一与冻结指纹相符，清单 SHA-256 为 `a24a5d32017f8013e75bb1d057843fa5c61ca8fa84ab9dfe89dead472bd4f502`。

- Python 与 browser-js 均以原生鼠标操作拖出画布后释放、按住键后移焦、真实 Ctrl+Tab 切换标签页，确认按下／松开平衡；停止画布及下载后重新打开的历史画布无回调。重新打开测试书本等待所需确认后进行，没有绕过上传权限。
- 生成预检区分浏览器禁止的终端／本地外言能力与 Python 结构检查；有效图形生成不自动运行，显式运行后两端交互正常。非法浏览器源码的可点击诊断定位到第 2 行；编辑／取消后的迟到结果没有覆盖新源码。
- 实际等待阶段、成功模型文本／提取源码、错误围栏、HTTP 429、无效输出与超时可见；UI 及下载 JSON 的凭据／认证／URL／密码字段脱敏。36,000 中文字符输出在三页显示完整，下载保持完整内容；复制返回完整合法 JSON。
