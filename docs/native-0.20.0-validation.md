## 明确边界

产品首版只支持本地 Windows x64 Python。原生默认关闭，如书不能开启，`generate --run` 不授予能力，C／Node／浏览器后端拒绝原生依赖。如见当前只提供一组基础 Win32 绑定及单主窗口／多按钮切片，不宣称完成整个 Win32 API。

FFI 是受信任进程能力，不是沙箱。错误 ABI、原生代码或错误生命周期仍可能崩溃／破坏进程。关闭库不主动卸载 DLL；进程累计最多 1024 个回调占位，每个回调最多保持 128 个不同的返回资源。未通过真实 Windows 验证之前，不能据本记录宣布 Windows 功能已验收。
