# 阵：排序与另成

## 返回新阵，保留元素引用

`阵 其 排序` 与 `阵 其 另成 算法:回调` 是普通成员调用，不需导入。两个成员在 Python、C、Node.js 与如书 browser-js 上遵循相同契约，名称不是保留字。

| 成员 | 参数 | 结果 |
| --- | --- | --- |
| 排序 | 可选 `先于:`，须为恰有两个参数的算 | 稳定排序后的新阵 |
| 另成 | 必需 `算法:`，须为恰有一个参数的算 | 从左到右将每项的返回值收集成新阵 |

两者先取得输入的浅元素快照，始终返回新阵，空阵与单项阵也不会返回原阵本身；操作本身不修改原阵。对象、内层阵、典与闭包保留引用，不深复制。回调修改原阵的长度或次序，不改变这次处理的快照元素集合；共享元素的修改仍可见。回调副作用不回滚，显式 `卒` 向外传播，可由外层 `救` 恢复；普通参数、类型与返回值错误不可救。

排序省略 `先于:` 时，整阵须属于以下一种情况：全为有限数，按数值升序；全为句，按 Unicode 码点字典序；或全为同一个形身份的对象，由其自有或继承的单参数 `算 先于 另一` 比较。父形与子形不是同一形身份，同名但不同声明的形也不是。事实、空、混合种类、非有限数及不支持默认排序的元素报错。默认对象排序不要求定义 `同`；不修改 `<`、`>`、`==` 等现有运算符的规则。

显式 `先于:` 优先于默认规则，可为其他元素提供顺序；每次调用传入左、右两个元素。无论显式算还是形的 `先于` 方法，都必须返回精确的事实 `真` 或 `假`，不能返回数0/1、三路数值、空或其他真值。真表示左项先于右项；双方都不先于对方即为同序，保持输入次序。比较算法应只判断先后，不修改参与排序的数据，也不依赖比较次数或调用顺序；须形成一致的严格弱序。实现不检测或回滚比较中的副作用；回调自行造成的修改仍会生效。调用次数、先后与排序算法细节不作跨后端保证。空阵可能不比较，单项阵也可能不比较，但显式回调的算种类与参数个数仍先验证，默认规则仍验证所有现有元素。

另成只接受恰有一个参数的 `算`，不接受 `作`；即使输入为空，也验证回调种类及参数个数。它按快照次序对每项调用一次，只有元素参数，没有隐式位置参数。每个结果占新阵的一项，包括空和返回的阵，不筛选、不展开。返回原对象仍共享引用；想要新对象，须在算法中显式 `新`。

# 排序和另成均返回新阵；只复制引用，不深复制元素。

显 自然数 其 排序.                 # [1, 1, 2, 3]
显 自然数.                        # [3, 1, 2, 1]

# [3, 2, 1, 1]；显式先于是二参算，返回事实，不是三路数值比较器。

### 带位置或目的遍历：逐位与逐目

`阵 其 逐位 回调:…` 先取浅元素快照，再按原位置从0开始依次调用二参算或作，两个位置实参为（位、值）。不受回调改变原阵长度、次序影响；位置属于初始快照。`典 其 逐目 回调:…` 沿用旧典列的浅条目快照，两个位置实参为（目、相），遍历顺序不保证。两者均忽略回调返回值，包括假与空；整体完成返回空。空容器也检查回调为二参算或作。回调中的 `完` 只结束当前作，下一项继续；不能用 `破` 跳出回调外的遍历。显式卒正常传播，既有副作用不回滚。共享元素仍是原引用。

典的旧 `其 列` 已移除并给出迁移错误，没有兼容别名；改写为 `其 逐目`，命名参数仍为 `回调:`。目录的 `其 列` 不变；自定义对象的同名方法仍按其声明。

```ru
水果 取 ['梨','桃'].
水果 其 逐位 回调:(作 位, 值:
    显 位.
    显 值.
为).
# 输出0、梨、1、桃。追加/删改水果不改变本轮快照位置。
成绩 取 {'甲': 90, '乙': 80}.
成绩 其 逐目 回调:(作 目, 相:
    显 目.
    显 相.
为).
# 每个条目访问一次；甲、乙先后不保证。
```
