# 0.10.0：事实、典与成员调用迁移

这是破坏性语言更新。旧程序请先运行测试，尤其检查条件、比较结果、参数类型和成员实参边界。

## 事实

- 新类型 `事实`，字面量 `真`、`假`。二者不属于数；假与空是两个不同值
- 只有空和假为假。0、负零、空句、空阵、空典都为真
- 相等、大小比较、标准句的含、非、且、或返回事实。且/或仍短路且返回事实，不返回操作数
- `值 为 事实` 显式取得真值；`真 为 数` 不支持。要把判断计为 0/1，请写分支
- `件 其 在` 的成功成果中，值改为事实。`件 其 写` 的追加输入选项仍为数 0/1，以保持该既有选项协议；排序比较器也仍必须返回有限数，不能返回事实
- 比较输出从 1/0 变为真/假。原来接受数的参数不会自动接受事实

```ru
显 假 == 空.       # 假
显 真 == 1.        # 假
显 0 为 事实.      # 真
显 假 且 (1/0).    # 假，右侧不求值
```

旧 `若 数值 则` 若原意是“非零”，改为 `若 数值 != 0 则`。旧空容器判断改为显式量比较；旧空句判断改为 `句 != ''`。`真`、`假`、`典`、`成` 为新保留字，旧同名绑定/参数/方法须改名。

## 典

```ru
表 取 典: ‘上’ 对 0. ‘下’ 对 2. 成.
别名 取 表.
表 其 增 ‘中’ 1.
显 别名 其 查 ‘中’.     # 1
显 别名[‘中’].          # 1，同一查找规则
显 别名[‘缺失’].        # 空
显 表 其 除 ‘下’.       # 真
显 表 其 量.            # 2
表 其 列 作 键 值: 显 键. 显 值. 为.
```

- 文字形式每项句点结束，典以成结束；空典为 `典:成`
- 等价符号形式为 `{'上': 0, '下': 2}`，空典 `{}`，允许尾逗号、换行、嵌套及全角 `｛｝`、`：`、`，`。两种形式可混用；花括号不是作用域块，外层语句仍需句点
- 符号键和值均为表达式，`{键: 值}` 读取名称 `键`，不是字符串 `'键'`。条目内带参数调用／带字段实参构造须括号分组，例如 `{(f 1): (g 值:2), 'x': 3}`，避免调用消费条目逗号或把冒号视为命名实参；命名实参规则不变
- 按源码顺序先求键后求值，完成本项插入再求下一项；重复键后值覆盖，保留原键对象
- 查缺失返回空，不区别存有空。增返回原典，除返回事实，列忽略算/作回调结果并返回空
- 列使用开始时的浅条目快照；回调可修改原典，完仅结束当前作回调，卒按正常规则传播
- 典可变且别名共享；对象/阵/典值保留引用。枚举顺序不保证
- 使用哈希索引；键支持数、句、事实，以及实现同/印的形实例。0/-0同键，真/1和假/0不同键
- 不支持空、对、阵、典、函数或模块键；读取可用 `表[键]`，不支持方括号赋值、切片或额外的含成员

形键例与完整规则见[语言规范 7.6](../rulang/language-spec.md#76-典可变哈希映射)。同须是一参算并返回事实；印须是零参算并返回 ±(2^53−1) 内的有限整数数值。同的参数类型可省略。相等键必须有相同印；碰撞再检查同。缺少协议不以身份兜底。键字段或方法改变后索引是否仍有效由作者负责，运行时不冻结或重建；在同/印中修改当前正在查找的典会报错。

普通对象比较：相同具体形有同则调用左侧同；不同具体形不相等；无同保留原身份相等。继承不让两个不同具体形成为相等候选。

## 普通成员实参语法

成员名不再全局固定签名：阵的增一参，典的增两参；用户对象和模块上的同名方法按实际声明接收参数。字段也可以使用含、位、段、增等普通名称。

`列 其 增 1+2` 现在追加 3。原 `列 其 位 0+2` 如果想先取第 0 项再加 2，须写 `(列 其 位 0)+2`。嵌套调用实参加括号，如 `'甲' 其 含 (回 '甲')`。位置/命名实参不可混用，全部实参仍必需。

## 三后端与工具

解释器、独立 C99、独立 Node.js 输出共用语义。如书、Emacs、VS Code 的语法与提示同步；生成请求仍发送整份当前语言规范，编译期不会执行同/印或用户代码。
