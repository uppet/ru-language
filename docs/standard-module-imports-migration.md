# 标准模块导入名迁移

标准模块统一使用 `如:` 前缀。产品／功能名称仍叫如观、如竞；如书的标题、模板名称和绘图 API 不变。

- 如观：旧导入 `如观` 改为 `如:观`
- 如竞：旧导入 `如竞` 或更早的 `如:竞赛` 改为 `如:竞`
- 文本、数学、随机：继续使用 `如:文本`、`如:数学`、`如:随机`

当前写法：

```ru
观 取 外言 '如:观'.
竞 取 外言 '如:竞'.
```

如观画布需要如书宿主；上面的导入示意不意味着普通 CLI／C／Node.js 目标支持画布。标准模块仍以随工具链发布的普通 `.ru` 源码实现，不需要联网安装。

## 修改已有程序和书本

旧精确导入名会明确报迁移错误，不保留兼容别名，不回退到当前目录的同名文件。请只修改源码中 `外言` 后的模块名称字符串；无需修改产品标题、变量名、`__如观`／`__如竞` 内部名称或方法名。

仓库现行示例和新建模板已使用新名称。用户保存的 `.rushu.json` 书本、自己的 `.ru` 文件以及历史输出不会自动改写，也不会因打开、保存或迁移而自动执行。先备份并修改相关代码格，再自行审阅、选择运行。历史变更记录与旧验证报告保留当时记录。

若要导入恰好叫如观或如竞的本地文件，请明确写本地路径，如 `外言 './如观'` 或 `外言 './如竞.ru'`。以 `如:` 开头的名称保留给标准模块，未知标准名仍报错。

## 生成与执行目标

真实生成请求与 `ru rushu-prompt`／`ru ruguan-prompt` 离线导出仍从同一份随附语言规范组装提示；规范中的当前导入与可运行例已更新。导出默认面向如书 Python，只有代码格显式勾选「JS 加速」才使用 browser-js；改导入名不会改变目标、会话或保护边界。
