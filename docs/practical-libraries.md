# 实用标准库：文本、数学、随机与阵（0.12）

先学三个小例子。模块需要导入，阵的成员直接使用。`如竞` 保留更名前的全部公开函数接口。

## 1. 整理名字和分数

```ru
文 取 外言 '如:文本'.
名单 取 文 其 拆分 '小明,小红,小青' ','.
显 名单[1].                         # 小红
显 文 其 去空白 '  你好  '.           # 你好
显 文 其 替换 '小明喜欢苹果' '苹果' '梨'.
显 文 其 定点 3.5 2.                 # 3.50（句）
```

| 算 | 必需参数 | 结果与边界 |
| --- | --- | --- |
| 拆分 | 文为句、隔为句 | 按字面分隔句，返回新句阵，保留空项；隔不可为空 |
| 替换 | 文为句、旧为句、新文为句 | 从左到右替换全部不重叠匹配；旧不可为空，新文可为空 |
| 去空白 | 文为句 | 仅去掉首尾ASCII空白，中间不动 |
| 定点 | 值为数、位数为数 | 固定小数位的句；位数须为0到15的整数 |

拆分 `'a,,b,'` 按 `','` 得到四项，其中两项是空句；拆分空文得到一个空句，不是空阵。需要按空白拆词或逐码点拆开，继续使用 `如竞` 的拆词／字列。

替换不扫描新插入的内容：把 `'a'` 中的 `'a'` 换成 `'aa'` 只得到 `'aa'`，不会无限重复。无正则表达式、Unicode规范化或忽略大小写行为。命名实参用 `新文:`，不能用语言保留字 `新`。

去空白只处理空格、Tab、LF、CR、VT、FF，与既有拆词和句转数一致。全角空格与不换行空格保留；它不删中间空白。

定点按实际 binary64 数值取最近值，恰好半单位时远离零：1.25保留一位为 `'1.3'`，-1.25为 `'-1.3'`。小数位不足补零，零位不带小数点，不用科学记数法。负零符号保留，例如 -0保留两位为 `'-0.00'`。

注意：如的数不是精确十进制。2.675在binary64中略小于这个十进制值，所以保留两位为 `'2.67'`。定点改变显示，不让金额计算变得精确；原有 `为 句` 仍用最多15位有效数字的简洁显示。

## 2. 操作阵：删、弹、查

```ru
玩具 取 ['球','车','船'].
显 玩具 其 查 '车'.                 # 1，从0开始
显 玩具 其 删 位:1.                 # 车，原阵变成 ['球','船']
显 玩具 其 弹.                      # 船，原阵变成 ['球']
显 玩具 其 查 '车'.                 # 空，未找到
```

| 成员 | 必需参数 | 返回与修改 |
| --- | --- | --- |
| 删 | 位为数 | 原地删除指定位置，返回原元素，其后项左移 |
| 弹 | 无 | 原地移出最后项，返回原元素 |
| 查 | 值，任意种类 | 第一个相等项的零起点位置；未找到返回空 |

删的位须为合法非负整数，不能负索引；空阵弹出、越界删除、错误参数均报普通运行错误，不能由救捕获。要安全弹出，先看量。移出空元素会正常返回空；它不表示删除失败。

阵的别名共享修改；移出的对象、阵和典仍是原来的引用，没有深复制。查不修改阵，比较使用原有 `==`／形的同协议，不把0当作假，也不把内容相同的两个独立阵当成相等。

查在开始时取得浅元素快照，从左到右比较，元素作为同的左方。相等方法若修改原阵，扫描仍用开始时快照，返回位置也是快照位置，未必还对应修改后的原阵。共享元素本身的修改仍可见；卒照常传播、既有副作用不回滚。查的时间通常为O(n)，快照另占O(n)引用空间。

典的 `查 目:` 按键返回值；阵的 `查 值:` 按元素返回位置。接收者不同，参数和结果含义不同。典使用 `目:`／`相:` 命名参数，不引入新保留字。

阵还提供返回新阵的 `排序` 与 `另成`：见 [排序与另成](array-sort-map.md)。排序默认用于同类有限数、句或同一形身份的先于协议；另成使用一参算，逐项保留其返回值。

## 3. 算数与取整

```ru
数学 取 外言 '如:数学'.
显 数学 其 平方根 81.               # 9
显 数学 其 幂 2 5.                  # 32
显 数学 其 取整 (-1.8).              # -1，向零
显 数学 其 向下取整 (-1.8).          # -2
显 数学 其 向上取整 (-1.8).          # -1
显 数学 其 四舍五入 (-1.5).          # -2，负半单位也远离0
```

数学导出十五个普通算与一个数值常量 `圆周率`（3.141592653589793，π 的最近 binary64 表示）。旧五项 `取整 值`、`小 左 右`、`大 左 右`、`绝对 值`、`整除 左 右` 与如竞库同名接口行为相同，这些函数也继续由 `如竞` 导出。这里是新的普通函数入口，不承诺两处函数引用身份相等。同时尽取两个模块会因重名报错；应使用模块别名。

新增：

- 平方根 值：值须非负；负零合法且保留
- 幂 底数 指数：实数幂；负底数要求整数指数；零不能取负指数；0的0次幂按空乘积约定为1
- 向下取整 值：不大于值的最大整数
- 向上取整 值：不小于值的最小整数
- 四舍五入 值：最近整数，恰好半单位远离0
- 正弦 弧度、余弦 弧度：弧度制的正弦和余弦，直接调用宿主数学函数
- 角度转弧度 角度：角度乘以 `圆周率 / 180`（180 度为 π 弧度）
- 弧度转角度 弧度：弧度乘以 `180 / 圆周率`；结果溢出报错
- 方向角 纵 横：即 `atan2(纵, 横)`，返回从正横轴到向量 `(横, 纵)` 的方向，范围为 [-π, π] 弧度；数学坐标中逆时针为正，画布纵轴向下时视觉上顺时针为正

三角函数不隐式转换角度。例：`数学 其 正弦 (数学 其 角度转弧度 90)` 得 1；轨道坐标可写 `横心 + 半径 * (数学 其 余弦 弧度)` 与 `纵心 + 半径 * (数学 其 正弦 弧度)`。圆周率可用 `数学 其 圆周率` 读取，也支持尽取。普通算支持命名参数与算引用；正弦、余弦的参数名明确为 `弧度`，不能写 `角度:90`。

正弦和两种转换保留负零；余弦的正负零输入均得 1。方向角遵循宿主 signed-zero 规则：`方向角 (-0) 1` 为 -0；正负零纵分量配正零横分量分别得正负零，配负零横分量分别得正负 π。不要把方向角的 `(0, 0)` 结果当作几何上唯一的方向。转换先形成有限比例再相乘，避免大角度中间乘 π 溢出。

所有参数均为数，事实不算数。数学函数返回数，定点返回句。取整类操作保留舍入为零时的原负号；数仍为有限binary64，没有整数新类型、复数或大整数。域错误、除零及非有限结果均为普通运行错误，极小结果可以下溢为零。

三后端保持相同接口、域与范围规则；定点、取整和随机序列按明确算法验收。幂、正弦、余弦、方向角等宿主数学函数的末尾舍入位可能因平台数学库不同而不同，不能用它们承诺跨平台逐位相等，或把有限精度结果当作符号代数答案。

## 4. 用固定种子重现骰子与洗牌

```ru
随 取 外言 '如:随机'.
源 取 随 其 造源 种子:42.
显 源 其 整数 下:1 上:6.            # 两端都包含
纸牌 取 ['甲','乙','丙','丁'].
打乱后 取 源 其 洗牌 纸牌.
显 纸牌.                            # 原阵不改
显 打乱后.
```

造源是普通算，必需参数种子为0到4294967295的整数。每次调用创建独立状态；同种子、同调用顺序在三个后端得到相同序列。别名共享同一个源并共同推进。独立状态不表示不同种子在统计上独立。

随机源只提供两个成员：

- 整数 下 上：闭区间整数。两个端点都须为安全整数，范围为正负9007199254740991以内；候选数目 `上-下+1` 不超过4294967296。单点直接返回，不消耗随机状态；结果为零时为正零。
- 洗牌 列：返回新的浅复制阵。原阵不改，内层对象仍共享。空阵与单项阵也返回新阵，且不消耗状态；阵长不能超过4294967296。

所有参数先验证；无效参数报错且不抽取随机数。程序错误不是可救的卒。随机源没有公开状态字段、重设种子方法或公开形名；重新开始请造一个新源。普通造源可取算引用，随机源成员与其他内置成员一样不能直接取引用，需用闭包包装。

算法固定为PCG32 XSH-RR，序列选择54，采用两步种子初始化、64位模运算及32位输出；区间通过拒绝采样去掉取余映射偏差。洗牌从末项向前做Fisher–Yates交换，每轮抽取包含两端的0到当前位置。拒绝重抽可能消耗多个底层输出；插入不同的随机调用会改变随后序列。

种子42的完整32位范围首六项为：2707161783、2068313097、3122475824、2211639955、3215226955、3421331566。没有自动时钟种子，没有隐式全局源。此库是可复现的非加密伪随机，不可用于密码、验证码、令牌或安全抽签。参考算法与许可见[第三方说明](third-party-notices.md)。
