# 如UI 指南

如UI 是随编译器分发的第三方界面库（`rulang/thirdparty/如UI/如UI.ru`），为「如观」画布提供声明式控件与自动排版。语言规范零改动——所有控件都是普通 Ru 函数与 `形`，经「如见」分发渠道获得，遵循「如书」模式。

## 一分钟上手

```bash
ru build examples/ruui-counter.ru --target ui
# 产出 counter-app.html，浏览器打开即可点击交互
```

`--target ui` 编译为**单文件自包含网页**：内嵌浏览器 JS 运行时、2D 画布宿主（渲染如观命令流）、rAF 帧循环与鼠标事件转发。无需服务器、无需外部资源。

## 架构

- **排版**：`形 应用` 持有部件树与 `图`（命中格表）；每帧 `_布` 递归量尺寸、定位、绘制，控件回调内只改状态。
- **渲染**：绘制调用走如观画布（2D 命令流），由宿主按 30 fps 帧循环驱动 `_帧` 重绘。
- **事件**：宿主把 `mouse_down/move/up` 转给 `画布 其 按下/移动/松开`，库内做命中测试后调控件回调。
- **双后端**：同一源码经 Python 解释器与浏览器 JS 运行时产出逐命令一致的命令流（`tests/test_ruui.py` 逐命令比对）。

## 已验证的写法约束（踩坑实录）

这些全部经探针/双后端测试实证，写如UI 代码时逐条遵守：

1. **数组实参前有位置实参时，数组要加括号**：邻接调用中 `滚 96 [...]` 的 `[` 会被解析为对数字 `96` 的索引访问（报「期待『]』，却遇到『，』」）。必须写 `(滚 96 ([...]))`。
2. **数组内调用加括号**：`列 [(文 ...), (钮 ...)]` 中每个调用都要括号。
3. **负数裸实参用 `(0 - 1)`**：`-1` 在实参位置不是字面量。
4. **声明字段无默认值**：`形 应用` 的字段（`号`、`提表` 等）声明后须在 `跑` 内初始化（`我 其 号 取 0.`），否则首次算术得 `空 + 1` 的运行错误。
5. **模块级函数只能裸调用**：`文/钮/滑/选/列/行/叠/滚/充/占/间` 不属于 `形` 实例成员，`其 _文宽` 会报「未知成员」；在 `形` 方法内用局部绑定：先 `画布 取 (其 图)[0].`，再 `现 取 (画布 其 经过秒).`。
6. **学生（用户）回调里用 `机 其 …`，不用 `我 其 …`**：`我` 只在库方法体内由 `我 取 其.` 绑定为学生部件；应用级闭包里写 `我 其 页 …` 无此绑定。库自身方法内部则必须 `我 取 其.`。
7. **语句-若作闭包体以「然」收尾**：`(作: 若 … 则 得 …. 另 得 …. 然)`；以「法」收尾会报「此处需要表达式，却遇到『法』」。

## 事件与帧

- 帧回调：`画布 其 每帧 (作 帧: 我 其 _帧 帧. 为)。` 在 `跑` 内注册；宿主按画布 fps（默认 30）用 rAF 驱动。
- `跑` 自动完成：初始化字段 → 注册每帧 → 注册鼠标事件 → 启动帧循环。用户无需手写。
- 如观事件语义照常适用：`frame` 仅含 `{"type"}`；鼠标事件 `button` 为 0–2 的整数。

## 测试

- `tests/test_ruui.py`：双后端逐命令比对（计数器、测验、滚动、滑杆、非法事件拒绝、提示与切页），8 例。
- `tests/test_ruui_app.py`：`--target ui` 产物级冒烟——Node + DOM 桩运行整页，模拟点击加一按钮并推进帧时钟，断言重绘值为 1；另断言页面自包含（单 script、无外部 src/link）。
