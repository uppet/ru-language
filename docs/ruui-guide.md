# 如UI 指南

如UI 是随编译器分发的第三方界面库（`rulang/thirdparty/如UI/如UI.ru`），为「如观」画布提供声明式控件与自动排版。语言规范零改动——所有控件都是普通 Ru 函数与 `形`，经「如见」分发渠道获得，遵循「如书」模式。

## 一分钟上手

```bash
ru build examples/ruui-counter.ru --target ui
# 产出 counter-app.html，浏览器打开即可点击交互
```

`--target ui` 编译为**单文件自包含网页**：内嵌浏览器 JS 运行时、2D 画布宿主（渲染如观命令流）、rAF 帧循环与鼠标事件转发。无需服务器、无需外部资源。

## 架构

- **排版**：`形 应用` 持有部件树与 `图`（命中格表）；每帧 `_布` 递归量尺寸、定位、绘制，控件回调内只改状态。
- **渲染**：绘制调用走如观画布（2D 命令流），由宿主按 30 fps 帧循环驱动 `_帧` 重绘。
- **事件**：宿主把 `mouse_down/move/up` 转给 `画布 其 按下/移动/松开`，库内做命中测试后调控件回调。
- **双后端**：同一源码经 Python 解释器与浏览器 JS 运行时产出逐命令一致的命令流（`tests/test_ruui.py` 逐命令比对）。

横向均分示例（三柱等宽、两钮等宽）：

```ru
(行 [
    (充 (块 '#ff5a5a' (红[0]))),
    (充 (块 '#40c060' (绿[0]))),
    (充 (块 '#3f8cff' (蓝[0])))
]).
(行 [
    (充 (钮 '切到暗色' (作: 演示 其 设色 暗题. 为))),
    (充 (钮 '归零' (作: 为)))
]).
```

`充` 的计量：行内先排自然宽子件，剩余宽度由全部 `充` 子件均分；列内同理分纵向余量。只有一个 `充` 子件时即「填满剩余」。完整可运行示例见 `examples/ruui-mixer.ru`（滑杆调色 + 预设 + 均分行 + 主题切换）。

## 配色

配色典 `亮题`／`暗题` 各含十二键：`底 字 钮底 钮字 暗底 选底 滑轨 滑钮 提底 提字 占位 光标`。

- 整套切换：`演示 其 设色 暗题.`／`演示 其 设色 亮题.`，下一帧全局生效。
- 局部改色：传只含想改键的典，如 `演示 其 设色 (典: '钮底' 对 '#c0392b' . 成).`，其余键保留现值。
- 应用创建后默认 `亮题`；`演示 其 运行` 之前或任意回调里调用均可。

## 滚动区交互

- 滚动区内**按下即挂起**：移动超过 4 点判为拖拽（滚动内容，位移按内容高钳位），原地松开才算点按、触发命中控件。
- 滚动区外的 钮／选／滑 按下立即响应，行为不变。
- 滚动区内的滑杆只支持**点按设值**（拖动让位给滚动）。
- 滚动位移存于应用内、跨帧保持；`演示 其 页` 换页时清零。

最小骨架：

```ru
# 运行：ru build app.ru --target ui（或 rulang run，如书 Python 会话）
尽取 外言 '如UI'.

演示 取 新 应用 宽: 360 高: 640 构: (算:
    得 列 [
        (文 '标题'),
        (钮 '点我' (作: 演示 其 提示 'clicked'. 为))
    ].
法).
演示 其 运行.
```

## 已验证的写法约束（踩坑实录）

这些全部经探针/双后端测试实证，写如UI 代码时逐条遵守：

1. **数组实参前有位置实参时，数组要加括号**：邻接调用中 `滚 96 [...]` 的 `[` 会被解析为对数字 `96` 的索引访问（报「期待『]』，却遇到『，』」）。必须写 `(滚 96 ([...]))`。
2. **数组内调用加括号**：`列 [(文 ...), (钮 ...)]` 中每个调用都要括号。
3. **负数裸实参用 `(0 - 1)`**：`-1` 在实参位置不是字面量。
4. **声明字段无默认值**：`形 应用` 的字段（`号`、`提表` 等）声明后须在 `运行` 内初始化（`我 其 号 取 0.`），否则首次算术得 `空 + 1` 的运行错误。
5. **模块级函数只能裸调用**：`文/钮/滑/选/列/行/叠/滚/充/占/间` 不属于 `形` 实例成员，`其 _文宽` 会报「未知成员」；在 `形` 方法内用局部绑定：先 `画布 取 (其 图)[0].`，再 `现 取 (画布 其 经过秒).`。
6. **学生（用户）回调里用 `演示 其 …`，不用 `我 其 …`**：`我` 只在库方法体内由 `我 取 其.` 绑定为学生部件；应用级闭包里写 `我 其 页 …` 无此绑定。库自身方法内部则必须 `我 取 其.`。
7. **语句-若作闭包体以「然」收尾**：`(作: 若 … 则 得 …. 另 得 …. 然)`；以「法」收尾会报「此处需要表达式，却遇到『法』」。
8. **`X 非 空` 是调用不是比较**：`非` 是前缀一元算子，`记 非 空` 会被解析成「以 `非 空` 为实参调用 `记`」，运行时得「值不是算／作」。判空一律写 `记 != 空`（`!=` 才是中缀比较运算符）。
9. **受控部件的状态必须每帧回传**：`选`／`滑` 不自带选中态，页是每帧重建的普通过程。`位`／`值` 实参必须传应用的格里值（如 `(选 项 (选值[0]) ...)`），回调里写回格里；写死字面量会让高亮／滑钮每帧跳回初始位置。
10. **`颜色` 四通道要整数**：滑杆产出小数，配 `如:观` 的 `颜色` 前须 `数学 其 取整`，否则首帧即「红须为范围内整数」每帧崩。
11. **列表多子项必须逗号分隔**：`得 列 [(图载 ...), (文 果[0])].`——逗号缺了只报笼统的「需要 ]」。
12. **索引表达式作实参加括号**：`(文 (果 其 位 0))` 不写括号会被解析成别的结合（比较亦然：`(源 其 位 0) == '/'`）。

## 资源协议（图载／件载／件目）

`图载`／`件载` 走「如观」宿主资源协议：控件把请求命令写进帧流，宿主装载后回送就绪事件，库回调用户代码并触发一帧重绘。

- **`演示 其 件目 基`**：设定资产基目录（`空` 表示源即直发路径）。源一律为相对路径；拒绝空串、绝对路径与 `..` 逃逸（越出件目即错）。
- **`(图载 源 宽 回调)`**：请求图像，显示宽固定、高按图像比例。回调签名 `(作 宽 为 数 高 为 数 错 为 句: … 为)`——失败时宽／高为 0、`错` 为错误消息（如 `读不到文件`、`图像超过配额`）。装载中零占位（不占位、不预留尺寸）。宿主自动从文件头识别 PNG／JPEG／GIF／BMP；Pillow 可用时校验更严。
- **`(件载 源 回调 式)`**：读任意资产。`式 '文'` 回调 `(文 为 句: …)`；`式 'base64'` 回调 `(底64 为 句: …)`；失败走 错 句（与 图载 相同签名）。
- **结果去重**：同一源＋式的重复就绪被忽略；`图载` 换源自动释放旧句柄重载。想强制重读用 `(重载 件)`。
- **切页**：`演示 其 页` 只换构不清资源；旧页图载行在下一帧布完后由「索集 diff」统一释放（与新页请求同帧），任何动态移除图载的路径都自动回收。
- **就绪补帧**：装载完成／失败时，宿主视同推进一帧——无需等下一拍 rAF 画面就更新（Python 宿主无 rAF，靠此补帧）；就绪回调自身不恢复不重发旧装帧。
- **输入重发契约**：输入事件（鼠标／键盘）回调未绘制时，宿主恢复并重发上一帧完整场景（phase-2 既有契约，用于忽略输入后宿主状态同步）。
- **静默噪音**：未绑定回调的、未知句柄的、重复的就绪事件一律忽略；同一句柄的终结就绪只送达一次。
- **限额**：装载句柄 ≤64，图像边 ≤4096、文件 ≤64 MiB、像素 ≤4096²，文本 ≤8 MiB，单帧 ≤256 KiB。超限即 `图像超过配额`／`读不到文件` 等错误，绝不半装载。

## 文入协议（文入／多行）

`文入` 走「如观」文本输入协议：库把 `text_focus`／`text_blur`／`text_update` 命令写进帧流（宿主据此维护隐藏的 IME 输入框），宿主把编辑事件回送库。

- **`(文入 值 占位 遇改)`**：受控输入框。`值` 为当前串、`占位` 为灰色提示文（值为空且未聚焦时显示）、`遇改` 回调以新串调用。点按聚焦（焦点框用 `暗底` 色、光标竖线 20 帧闪烁）；点按框外／`回车`（单行）／`跳格`／`逃脱` 失焦提交——**失焦或提交时若内容自上次回调后有变，先补调一次 `遇改`**。
- **`(多行 件)`**：修饰 `文入` 为多行；`回车` 插入换行，`上`／`下` 按行列移动光标（单行模式自然不动）。
- **编辑键**（附录 A 键名，宿主只送这 12 个，其余键静默丢弃）：`退格 删除 左 右 上 下 家 终 回车 空格 跳格 逃脱`。
- **剪贴**：宿主回送整串 `剪贴` 事件；单行模式剥换行，多行原样插入。
- **输入法组合**：`组开始`→`组更新`（带组合串与组合光标，画布内以下划线草稿显示）→`组结束`（定字上屏，恰好一次 `遇改`）。组合期间编辑键与字符一律忽略；组合串不同步宿主。
- **宿主命令**：`入焦点 横 纵 宽 高 文 标`（聚焦，带框与全串光标）、`入失焦`、`入更新 文 标`（选区留位恒空）。
- **v1 边界**：不做点击定位光标（光标始终在编辑末尾／由编辑键移动）、不做候选窗锚点（3c）、`跳格` ＝失焦提交而非焦点转移。控件从布局消失（换页、条件渲染）时下一帧自动失焦提交。
- **限额**：剪贴 ≤4096 字、组合串 ≤256、文入串 ≤8 MiB；越界事件宿主拒绝（报「无效如观文入…」）。
- **浏览器 IME 桥（3c）**：`--target ui` 产物宿主内置隐藏 input 承载系统 IME。`text_focus` 把 input 定位到控件几何（画布逻辑坐标按显示比例换算，候选窗就近弹出）、`text_update` 同步内容与光标（码点→UTF-16 索引换算）、`text_blur` 交出焦点。input 侧：keydown 白名单→`键按下`；beforeinput 的 `insertText`→`字符`（多字走`剪贴`）、粘贴→`剪贴`、换行→`回车`、删除类→`退格`／`删除`；composition*→`组开始`／`组更新`／`组结束`；不支持 beforeinput 的引擎按差异兜底翻译。组合期间按键全归 IME；input 不拦截指针，焦点切换全由如观命令决定。

## 测文协议（字度／测文）

文本宽度不再用库内近似常数：控件一律走如观画布的只读成员 `演示 其 测文 串`（当前字号下该串的像素宽）与 `演示 其 字度`（`{全,半,行}` 三个号的倍数）。文入光标、宽度钳位、换行断点因此与真实字体对齐。

- **三档来源**：宿主实测钩（`textMeasurer` 回调，按串+字号返回像素宽）＞ 注入字度表（`textMetrics`）＞ 内置缺省 `{全:1.0, 半:0.56, 行:1.5}`。缺省与库早期近似逐位一致，未注入的宿主行为不变。
- **回退算法**：无实测钩时逐码点量宽——码点 <「一」(U+4E00) 记半角，其余全角，各乘字度再乘号。
- **宿主接入**：Python 宿主设 `GraphicsHost.text_metrics`／`text_measurer`；浏览器端 `createRuntime(host)` 的 `host.textMetrics`／`host.textMeasurer` 选项。`--target ui` 产物启动时用显示上下文 `measureText` 实测（16px 测「字」得全角、「a」得半角，actualBoundingBox 得行高），实测不可用时回退缺省。
- **校验**：字度三数各为 0.1–10 有限数（画布创建时拒绝，报「如观字度…」）；测文串 ≤4096 码点；实测钩返回值须为 0–10⁷ 有限数，否则「如观测文宿主返回无效宽度」。recorder 不支持两成员（资源诚实同则）。
- **词表不动**：20 词不变，测文协议是画布成员而非新词。行高／衬距仍为库常量 1.5／0.6 号（垂直节拍，3d 候选）。

## 触屏与缩放（触下／触移／触松／改尺寸）

如观画布事件，如UI 应用自动接线，词表不变（画布层成员）：

- **触屏多点**：`触下`／`触移`／`触松`（参 号／横／纵）。协议一等公民（事件带指针号），控件语义只跟**主指针**（首个按下者）：其余指针记录不转发；主指针抬起后提升剩余最早者，且从未转发过按下的指针不补发松开（不会凭空触发控件）。捏合缩放是后续候选。
- **窗口缩放回路**：宿主发 `改尺寸`（参 宽／高）事件 → 应用更新字段、`画布 其 尺寸 宽 高`（画布可写成员，recorder 禁用）并立即重排重绘。`构` 每帧重布局，所以缩放后布局自动按新宽高分。
- 指针号 0–100000、宽高 1–100000；双端 parity 见 `tests/test_ruui_touch_resize.py`。

## 宿主服务协议（服务请／服务回／服务告）

如UI 的存盘等宿主能力走如观画布的服务通道，不触碰标准库 IO（编译器零改动）：

- **入通道**：画布原生成员 `服务请`（号／服务／操作／径／文／旗 六参）；用户代码一般不直接调，经库门面转发。
- **出通道**：`服务回`（号 成 值 误）逐请求回执——每个服务请宿主必须应答，成败皆回；`服务告`（表＝空格连接的服务名表）能力广告，每画布至多投递一次，未注册按噪音忽略。
- **Python 宿主**：GraphicsHost 服务队列在 flush 内同帧应答；档根＝程序目录，路径越件目拒绝（沿用 `件目` 语义）。
- **浏览器宿主**：`createRuntime(host)` 的 `host.services()`（服务名表）与 `host.handleService(canvas_id, request)`（执行请求、以 `host.emit` 回 `service_response`）。无桥的纯浏览器里 `能` 恒假、服务请在下一拍事件自动回失败——同「测文三档」的能力诚实先例。
- **如UI 门面**：`档 取 (机 其 服务 '档').`；`档 其 写 径 文 (作 果 误: …)`；`档 其 添写 径 文 (作 果 误: …)`；`档 其 列 径 (作 果 名表 误: …)`（名表＝文件名字符串数组，空目录为空表）。读档复用 `件载`。
- **网服务**：`网 取 (机 其 服务 '网').`；`网 其 拉 网址 (作 果 值 误: …)`（GET，两参）；`网 其 投 网址 内容 旗 (作 果 值 误: …)`（POST，四参；旗真则 Content-Type 为 application/json，否则 text/plain；UTF-8）。回执值＝响应体文本；错误原文回传（`网 HTTP <code>`、`网 只识 http/https`、`网 不识此操作：<动作>`、`网 取文失败` 及 DNS／CORS 原文），≤512 字节。Python 宿主以 urllib 实现（10 秒超时，体 ≥8 MiB 拒）；浏览器宿主有 fetch 时由运行时本地拦截执行（10 秒 AbortController 超时），桌面壳（WebKitGTK／WebView2／WKWebView）零改动获得网能力——浏览器 CORS 由页面所在源决定，失败原文如实回传，不做隐式代理。无 fetch 且桥不识 `网` 时按能力诚实自动回失败。
- **配额预检**：库先拒 路径 >128 字、文 >2,000,000 字（UTF-8 约 ≤8 MiB）的请求，本地回失败不进宿主。
- **示例／测试**：`examples/ruui-notepad.ru`；`tests/test_ruui_services.py`；`tests/test_ruui_net.py`。

## 桌面目标（--target desktop）

`ru build 程序.ru --target desktop` 产出可双击分发目录：

- `index.html`：自包含页面（桌面胶仅当壳注入了 `window.ruDesktop` 时激活）。
- `run-webkitgtk.py`：Linux 原生 WebKitGTK 壳（仅需系统 PyGObject + WebKitGTK GI；`--smoke` 可无人值守烟测）。
- `run-pywebview.py`：跨平台壳（Windows WebView2／macOS WKWebView／Linux WebKitGTK，`pip install pywebview`）。
- 档服务（写/添写/列）落到分发目录（程序目录语义，件目越界拒绝）。

壳的职责两件：**开窗嵌 WebView**、**实现通道的服务端**（文档起始注入
`window.ruDesktop`；`request(json)` 出壳异步执行，壳回调
`window.__ruServiceResponse` 送回回执）。窗口缩放走 `改尺寸` 回路、
触屏走 `touch_*` 通道，都在页胶里，与壳无关。

诚实定位：壳里跑的仍是 JS 运行时——启动暖 WebView（百毫秒级）、内存
WebView 量级（百 MB 级）、Linux 需系统 WebKitGTK。WebKitGTK 路径在本
仓库开发机真机核验；WebView2/WKWebView 与 WebKitGTK 同构但未经真机
核验。这不是原生壳，原生壳看计划 D2 SDL2。

## 事件与帧

- 帧回调：`画布 其 每帧 (作 帧: 我 其 _帧 帧. 为)。` 在 `运行` 内注册；宿主按画布 fps（默认 30）用 rAF 驱动。
- `运行` 自动完成：初始化字段 → 注册每帧 → 注册鼠标事件 → 启动帧循环。用户无需手写。
- 如观事件语义照常适用：`frame` 仅含 `{"type"}`；鼠标事件 `button` 为 0–2 的整数。
- 如观事件语义照常适用：`frame` 仅含 `{"type"}`；鼠标事件 `button` 为 0–2 的整数；文入事件（`键按下 字符 剪贴 组开始 组更新 组结束`）参数见「文入协议」节。
- **输入事件未改场景则重发**：回调没画任何东西时，宿主恢复并重发上一帧完整场景（phase-2 既有契约；忽略输入后宿主仍持最新画面）。
- **就绪事件视同帧推进**：见「资源协议」节。
