# 如UI 指南

如UI 是随编译器分发的第三方界面库（`rulang/thirdparty/如UI/如UI.ru`），为「如观」画布提供声明式控件与自动排版。语言规范零改动——所有控件都是普通 Ru 函数与 `形`，经「如见」分发渠道获得，遵循「如书」模式。

## 一分钟上手

```bash
ru build examples/ruui-counter.ru --target ui
# 产出 counter-app.html，浏览器打开即可点击交互
```

`--target ui` 编译为**单文件自包含网页**：内嵌浏览器 JS 运行时、2D 画布宿主（渲染如观命令流）、rAF 帧循环与鼠标事件转发。无需服务器、无需外部资源。

## 架构

- **排版**：`形 应用` 持有部件树与 `图`（命中格表）；每帧 `_布` 递归量尺寸、定位、绘制，控件回调内只改状态。
- **渲染**：绘制调用走如观画布（2D 命令流），由宿主按 30 fps 帧循环驱动 `_帧` 重绘。
- **事件**：宿主把 `mouse_down/move/up` 转给 `画布 其 按下/移动/松开`，库内做命中测试后调控件回调。
- **双后端**：同一源码经 Python 解释器与浏览器 JS 运行时产出逐命令一致的命令流（`tests/test_ruui.py` 逐命令比对）。

横向均分示例（三柱等宽、两钮等宽）：

```ru
(行 [
    (充 (块 '#ff5a5a' (红[0]))),
    (充 (块 '#40c060' (绿[0]))),
    (充 (块 '#3f8cff' (蓝[0])))
]).
(行 [
    (充 (钮 '切到暗色' (作: 机 其 设色 暗题. 为))),
    (充 (钮 '归零' (作: 为)))
]).
```

`充` 的计量：行内先排自然宽子件，剩余宽度由全部 `充` 子件均分；列内同理分纵向余量。只有一个 `充` 子件时即「填满剩余」。完整可运行示例见 `examples/ruui-mixer.ru`（滑杆调色 + 预设 + 均分行 + 主题切换）。

## 配色

配色典 `亮题`／`暗题` 各含十二键：`底 字 钮底 钮字 暗底 选底 滑轨 滑钮 提底 提字 占位 光标`。

- 整套切换：`机 其 设色 暗题.`／`机 其 设色 亮题.`，下一帧全局生效。
- 局部改色：传只含想改键的典，如 `机 其 设色 (典: '钮底' 对 '#c0392b' . 成).`，其余键保留现值。
- 应用创建后默认 `亮题`；`机 其 跑` 之前或任意回调里调用均可。

## 滚动区交互

- 滚动区内**按下即挂起**：移动超过 4 点判为拖拽（滚动内容，位移按内容高钳位），原地松开才算点按、触发命中控件。
- 滚动区外的 钮／选／滑 按下立即响应，行为不变。
- 滚动区内的滑杆只支持**点按设值**（拖动让位给滚动）。
- 滚动位移存于应用内、跨帧保持；`机 其 页` 换页时清零。

最小骨架：

```ru
# 运行：ru build app.ru --target ui（或 rulang run，如书 Python 会话）
尽取 外言 '如UI'.

机 取 新 应用 宽: 360 高: 640 构: (算:
    得 列 [
        (文 '标题'),
        (钮 '点我' (作: 机 其 提示 'clicked'. 为))
    ].
法).
机 其 跑.
```

## 已验证的写法约束（踩坑实录）

这些全部经探针/双后端测试实证，写如UI 代码时逐条遵守：

1. **数组实参前有位置实参时，数组要加括号**：邻接调用中 `滚 96 [...]` 的 `[` 会被解析为对数字 `96` 的索引访问（报「期待『]』，却遇到『，』」）。必须写 `(滚 96 ([...]))`。
2. **数组内调用加括号**：`列 [(文 ...), (钮 ...)]` 中每个调用都要括号。
3. **负数裸实参用 `(0 - 1)`**：`-1` 在实参位置不是字面量。
4. **声明字段无默认值**：`形 应用` 的字段（`号`、`提表` 等）声明后须在 `跑` 内初始化（`我 其 号 取 0.`），否则首次算术得 `空 + 1` 的运行错误。
5. **模块级函数只能裸调用**：`文/钮/滑/选/列/行/叠/滚/充/占/间` 不属于 `形` 实例成员，`其 _文宽` 会报「未知成员」；在 `形` 方法内用局部绑定：先 `画布 取 (其 图)[0].`，再 `现 取 (画布 其 经过秒).`。
6. **学生（用户）回调里用 `机 其 …`，不用 `我 其 …`**：`我` 只在库方法体内由 `我 取 其.` 绑定为学生部件；应用级闭包里写 `我 其 页 …` 无此绑定。库自身方法内部则必须 `我 取 其.`。
7. **语句-若作闭包体以「然」收尾**：`(作: 若 … 则 得 …. 另 得 …. 然)`；以「法」收尾会报「此处需要表达式，却遇到『法』」。
8. **`X 非 空` 是调用不是比较**：`非` 是前缀一元算子，`记 非 空` 会被解析成「以 `非 空` 为实参调用 `记`」，运行时得「值不是算／作」。判空一律写 `记 != 空`（`!=` 才是中缀比较运算符）。
10. **列表多子项必须逗号分隔**：`得 列 [(图载 ...), (文 果[0])].`——逗号缺了只报笼统的「需要 ]」。
11. **索引表达式作实参加括号**：`(文 (果 其 位 0))` 不写括号会被解析成别的结合（比较亦然：`(源 其 位 0) == '/'`）。

## 资源协议（图载／件载／件目）

`图载`／`件载` 走「如观」宿主资源协议：控件把请求命令写进帧流，宿主装载后回送就绪事件，库回调用户代码并触发一帧重绘。

- **`机 其 件目 基`**：设定资产基目录（`空` 表示源即直发路径）。源一律为相对路径；拒绝空串、绝对路径与 `..` 逃逸（越出件目即错）。
- **`(图载 源 宽 回调)`**：请求图像，显示宽固定、高按图像比例。回调签名 `(作 宽 为 数 高 为 数 错 为 句: … 为)`——失败时宽／高为 0、`错` 为错误消息（如 `读不到文件`、`图像超过配额`）。装载中零占位（不占位、不预留尺寸）。宿主自动从文件头识别 PNG／JPEG／GIF／BMP；Pillow 可用时校验更严。
- **`(件载 源 回调 式)`**：读任意资产。`式 '文'` 回调 `(文 为 句: …)`；`式 'base64'` 回调 `(底64 为 句: …)`；失败走 错 句（与 图载 相同签名）。
- **结果去重**：同一源＋式的重复就绪被忽略；`图载` 换源自动释放旧句柄重载。想强制重读用 `(重载 件)`。
- **切页**：`机 其 页` 只换构不清资源；旧页图载行在下一帧布完后由「索集 diff」统一释放（与新页请求同帧），任何动态移除图载的路径都自动回收。
- **就绪补帧**：装载完成／失败时，宿主视同推进一帧——无需等下一拍 rAF 画面就更新（Python 宿主无 rAF，靠此补帧）；就绪回调自身不恢复不重发旧装帧。
- **输入重发契约**：输入事件（鼠标／键盘）回调未绘制时，宿主恢复并重发上一帧完整场景（phase-2 既有契约，用于忽略输入后宿主状态同步）。
- **静默噪音**：未绑定回调的、未知句柄的、重复的就绪事件一律忽略；同一句柄的终结就绪只送达一次。
- **限额**：装载句柄 ≤64，图像边 ≤4096、文件 ≤64 MiB、像素 ≤4096²，文本 ≤8 MiB，单帧 ≤256 KiB。超限即 `图像超过配额`／`读不到文件` 等错误，绝不半装载。

## 文入协议（文入／多行）

`文入` 走「如观」文本输入协议：库把 `text_focus`／`text_blur`／`text_update` 命令写进帧流（宿主据此维护隐藏的 IME 输入框），宿主把编辑事件回送库。

- **`(文入 值 占位 遇改)`**：受控输入框。`值` 为当前串、`占位` 为灰色提示文（值为空且未聚焦时显示）、`遇改` 回调以新串调用。点按聚焦（焦点框用 `暗底` 色、光标竖线 20 帧闪烁）；点按框外／`回车`（单行）／`跳格`／`逃脱` 失焦提交——**失焦或提交时若内容自上次回调后有变，先补调一次 `遇改`**。
- **`(多行 件)`**：修饰 `文入` 为多行；`回车` 插入换行，`上`／`下` 按行列移动光标（单行模式自然不动）。
- **编辑键**（附录 A 键名，宿主只送这 12 个，其余键静默丢弃）：`退格 删除 左 右 上 下 家 终 回车 空格 跳格 逃脱`。
- **剪贴**：宿主回送整串 `剪贴` 事件；单行模式剥换行，多行原样插入。
- **输入法组合**：`组开始`→`组更新`（带组合串与组合光标，画布内以下划线草稿显示）→`组结束`（定字上屏，恰好一次 `遇改`）。组合期间编辑键与字符一律忽略；组合串不同步宿主。
- **宿主命令**：`入焦点 横 纵 宽 高 文 标`（聚焦，带框与全串光标）、`入失焦`、`入更新 文 标`（选区留位恒空）。
- **v1 边界**：不做点击定位光标（光标始终在编辑末尾／由编辑键移动）、不做候选窗锚点（3c）、`跳格` ＝失焦提交而非焦点转移。控件从布局消失（换页、条件渲染）时下一帧自动失焦提交。
- **限额**：剪贴 ≤4096 字、组合串 ≤256、文入串 ≤8 MiB；越界事件宿主拒绝（报「无效如观文入…」）。
- **浏览器 IME 桥（3c）**：`--target ui` 产物宿主内置隐藏 input 承载系统 IME。`text_focus` 把 input 定位到控件几何（画布逻辑坐标按显示比例换算，候选窗就近弹出）、`text_update` 同步内容与光标（码点→UTF-16 索引换算）、`text_blur` 交出焦点。input 侧：keydown 白名单→`键按下`；beforeinput 的 `insertText`→`字符`（多字走`剪贴`）、粘贴→`剪贴`、换行→`回车`、删除类→`退格`／`删除`；composition*→`组开始`／`组更新`／`组结束`；不支持 beforeinput 的引擎按差异兜底翻译。组合期间按键全归 IME；input 不拦截指针，焦点切换全由如观命令决定。

## 事件与帧

- 帧回调：`画布 其 每帧 (作 帧: 我 其 _帧 帧. 为)。` 在 `跑` 内注册；宿主按画布 fps（默认 30）用 rAF 驱动。
- `跑` 自动完成：初始化字段 → 注册每帧 → 注册鼠标事件 → 启动帧循环。用户无需手写。
- 如观事件语义照常适用：`frame` 仅含 `{"type"}`；鼠标事件 `button` 为 0–2 的整数。
- 如观事件语义照常适用：`frame` 仅含 `{"type"}`；鼠标事件 `button` 为 0–2 的整数；文入事件（`键按下 字符 剪贴 组开始 组更新 组结束`）参数见「文入协议」节。
- **输入事件未改场景则重发**：回调没画任何东西时，宿主恢复并重发上一帧完整场景（phase-2 既有契约；忽略输入后宿主仍持最新画面）。
- **就绪事件视同帧推进**：见「资源协议」节。
