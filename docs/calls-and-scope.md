# 调用与作用域速查

本页描述如 0.11.1 已实现规则，不增加语法。初学统一使用 `取` 与 `段: … 落.`；`:=` / `：=` 与 `取` 等价，语句位置的 `{ … }` 与文字块等价。完整权威定义见[规范第 6 节](../rulang/language-spec.md#6-绑定作用域函数与控制流)。

## 调用：括号围住一次求值

- 零参函数值用 `回调()` 调用；只有变量名时不能假定会自动调用。
- 带参数调用可以全位置或全命名；不要在一次调用里混合两者。
- 外层运算、容器元素、嵌套调用中的带参数调用，推荐写 `(函数 实参)`，防止吞掉后续参数或逗号。
- `(平方 2)` 是把如式调用整体括起来，不是新增 Python 式的 `平方(2)` 调用规则。

```ru
算 加 左 右: 得 左 + 右. 法.
算 平方 值: 得 值 * 值. 法.
显 (加 2 3).
显 (加 左: 2 右: 3).
显 (平方 (加 2 3)).
显 (平方 2) + 3.
回调 取 算: 得 8. 法.
显 回调().
```

```output
5
5
25
7
8
```

## 赋值：三种地方，三条规则

1. **模块正文**：建立或更新本模块绑定。条件、循环、试正文自身不建立新作用域，沿用所在环境。
2. **函数／过程／方法正文**：先写当前局部已有的绑定；否则更新最近已有的非模块捕获绑定（外层函数、救、显式块）；再没有就在当前函数新建局部。同名模块全局不属于更新目标。参数属于当前调用局部；普通赋值不提升，不能更新尚未建立的外层绑定。
3. **显式块与救的直接正文**：只写当前块／救局部，遮蔽外部同名绑定；右侧读取仍可向外查找。在其中创建的闭包遵循上一条，能够更新捕获的块／救绑定。

```ru
值 取 1.
若 真 则 值 取 2. 然.
显 值.
段:
    值 取 值 + 10.
    若 真 则 值 取 值 + 1. 然.
    显 值.
落.
显 值.
试:
    卒 '示例'.
救 原因:
    值 取 99.
    显 值.
终.
显 值.
```

```output
2
13
2
99
2
```

每次进入显式块都建立新环境。闭包可以使其中的绑定继续存活；离开块不会回滚对象修改。函数的局部与捕获例子见[练习 4—6](getting-started.md#4-函数不改同名全局)。

## 改内容与换绑定分开看

```ru
形 盒:
    值 为 数.
象.
甲 取 新 盒 值: 1.
段:
    乙 取 甲.
    乙 其 值 取 2.
    甲 取 新 盒 值: 9.
    显 甲 其 值.
落.
显 甲 其 值.
```

```output
9
2
```

`乙 其 值 取 2` 修改共享对象；`甲 取 新 盒 …` 只换当前块内的绑定。阵元素、典的增／除也修改共享内容；这不等于修改外部名称绑定。

## 两条运行提醒

- 只有 `空` 与 `假` 为假；`0`、`''`、`[]` 和空典都为真。`且`、`或` 返回事实，不返回原操作数。
- 保存文件不保存运行状态。如书输出是可保存的历史快照，重新打开不恢复变量或闭包，也不自动执行。遇到旧状态疑问，重启会话并按顺序重新运行。
