# 字带：可读写、可扩容的字节容器

**字带是可读写、可扩容的字节容器。** 它是普通标准库模块和形，不是新语法或关键字。模块名为 `如:字带`，形名为 `字带`，通过 `新建` 工厂创建。

`如:字带` 在 `如:密` 的拥有内存上提供长度、容量和边界检查。内部每字节使用一个原生字节，不是普通如值阵；不返回地址、内部拥有者或借用视图。当前沿用密的能力边界：须显式 `--allow-native`，实际原生执行支持 Windows x64，Node.js／浏览器不支持。Linux 上的测试平台适配器仅验证内存机制，不代表正式支持。

```ru
库 取 外言 '如:字带'.
缓 取 库 其 新建 16.
缓 其 增 65.
缓 其 增 255.
显 (缓 其 量)().       # 2
显 (缓 其 容量)().     # 16
缓 其 扩容 64.
显 缓 其 读 1.        # 255
副本 取 缓 其 快照 0 2.
(缓 其 关闭)().
显 副本.              # [65, 255]
```

这是普通如闭包和函数字段对象，零参数函数字段用 `(缓 其 量)()`、`(缓 其 容量)()`、`(缓 其 关闭)()` 调用。只写 `缓 其 量` 得到函数值，不是长度。可以取出函数后调用；取出的函数仍持有同一缓冲状态。

- `新建 初始容量`：长度为零。容量可为零，此时不分配原生内存。
- `读 位`／`写 位 值`：只访问 `0 <= 位 < 长度`，不允许访问尚未使用的容量。字节值为 0 至 255 的整数。
- `增 值`：追加一个字节。容量不足时翻倍，首次至少分配 8 字节。
- `扩容 所需`：容量至少为所需，不缩容，不改变长度。新分配和复制成功之后才切换拥有者并关闭旧拥有者。
- `改长 新长`：按需扩容。增长部分为零；缩短时先将丢弃区清零，再增长不会恢复旧字节。容量不随缩短而降低。
- `快照 起 止`：复制半开区间 `[起, 止)` 为独立普通数阵。它不是紧凑视图，复制需要与区间长度成比例的时间和如值阵存储；修改快照不影响缓冲，关闭缓冲不影响快照。
- `关闭`：幂等。所有别名和此前取出的函数共享关闭状态。关闭后除重复关闭外所有操作都拒绝，包含查询和空快照。内存实际回收仍由既有 GC 管理，关闭不承诺立即归还系统。

容量和长度限制为 0 至 **16,777,216（16 MiB）** 的整数，与密的单块内存上限一致。索引、长度、容量、值均为普通如数，不接受事实、句或原生整数替代。非法边界／字节值在修改前失败；分配资源不足会按现有运行时报告错误，不承诺从进程级内存耗尽中恢复。

## 底层字节操作

`密 其 缓冲` 返回的拥有内存新增三个成员，供库层实现使用：

- `读字节 位`：返回普通数。
- `写字节 位 值`：写入 0 至 255，返回空。
- `复制到 目标 源位 目标位 个数`：源和目标范围均须界内；零个数允许两侧位置等于大小。使用重叠安全复制，同一拥有者的前移、后移均有效，返回空。

底层整数参数沿用密现有安全整数／精确整数句／原生整数规则，不做隐式截断。三个操作只接受**无结构、无父视图的拥有缓冲**，拒绝结构及嵌套视图，避免绕过类型字段和指针生命周期锚。两侧均检查关闭状态；写入及复制目标检查密只读借用，借用期间不得修改。复制源只读取，可处于只读借用状态。这里只在已拥有、已检查范围内操作，不解引用任意裸指针。

字带对象不暴露这三个底层入口或内部拥有者，因此扩容后没有用户可持有的旧地址／视图；普通对象别名仍共享新状态。调用方自行重绑对象的函数字段属于普通如对象行为，不会提供对闭包内部存储的直接访问。
