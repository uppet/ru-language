# 如观：在如书里画图与互动

如观是如书的二维绘图模块。当前版本提供原生弧／扇形、真实经过时间与帧间隔、文字对齐、透明叠色、原生三角形／多边形、仿射变换、矩形裁剪，以及形状、文字、颜色、逐帧动画和鼠标／键盘回调，便于把数据和算法变成可观察、可操作的画面。

它借鉴 Processing 的画图与事件模型，不执行 Processing.js 程序，也不承诺与其 API 完整兼容。默认实现使用浏览器 Canvas 和原有 Python 如言会话。显式勾选「JS 加速」可把如源码编译到独立浏览器 Worker；回调仍写如的算／作。详见 [两种执行方式、状态与保护边界](browser-js.md)。

## 从一幅柱状图开始

在如书的代码格中运行下例。普通命令行及 C／Node.js JavaScript 编译目标目前不提供画布；请不要把图形程序当成会自动弹窗的桌面程序。

```ru
观 取 外言 '如:观'.
图 取 观 其 画布 480 280.
图 其 背景 '#f4f6fb'.
图 其 描边 空.
图 其 填色 '#4677ff'.
图 其 矩形 60 160 80 60.
图 其 矩形 200 100 80 120.
图 其 矩形 340 40 80 180.
图 其 填色 '#202530'.
图 其 字号 18.
图 其 文字 '甲：10' 60 250.
图 其 文字 '乙：20' 200 250.
图 其 文字 '丙：30' 340 250.
```

坐标原点在画布左上角，横坐标向右增加，纵坐标向下增加。矩形／椭圆／弧／扇形使用外接框的左上角和宽高。文字位置是当前文字对齐方式的锚点，默认左／上。

颜色写成 `'#RRGGBB'` 或 `'#RRGGBBAA'`，例如不透明的 `'#ff8800'`、半透明的 `'#ff880080'`。八位写法的末尾 `AA` 是不透明度：`00` 全透明，`ff` 不透明。`填色 空` 表示不填充，`描边 空` 表示不描边；背景必须指定颜色。本版不提供图像、音视频、三维或外部资源加载。

## 弧与扇形（0.19.4／如书 0.8.4）

`图 其 弧 横 纵 宽 高 始角 转角` 与 `图 其 扇形 横 纵 宽 高 始角 转角` 是普通画布成员，返回空，不是新增保留字。六个参数均必需；一次调用全部使用位置实参，或全部使用命名实参。命名参数精确为 `横:`、`纵:`、`宽:`、`高:`、`始角:`、`转角:`，不得混用或省略。

外接框与 `椭圆` 相同：`横`／`纵` 是左上角，`宽`／`高` 是局部坐标中的宽高。六个参数均须为绝对值不超过 100000 的有限数，宽高还须非负；拒绝事实、空、句与其他类型。零宽或零高合法，按原生 Canvas 的退化椭圆路径处理，不改成另一个形状，也不因此拒绝调用。

`始角`／`转角` 均用弧度，零角在椭圆右侧；始角可为任意符合数值限额的正负角度。转角是带符号的扫过量，不是终止角：未镜像的局部屏幕坐标中，正转角顺时针，负转角逆时针。负倍率缩放会把视觉方向一并镜像，不改变转角的含义。非圆椭圆使用参数角：设中心为 `(cx, cy)`，半宽高为 `rx`、`ry`，参数角 `θ` 的端点为 `(cx + rx*cos(θ), cy + ry*sin(θ))`；它不是从中心看端点的几何极角。

- `转角 == 0` 不绘制像素，但仍保留并计数为一条绘制命令；在回调内单独提交它也形成新的完整命令帧，不保留旧画面。
- `abs(转角) >= 2π` 绘制一整圈椭圆，只绕一圈，不对转角取模归零；`2π`、`-2π` 和更多圈均不会变为空路径。整圈扇形与椭圆相同，没有中心径向辐条；整圈弧仅描边。
- `弧` 是开放弧线，只使用当前描边和线宽，忽略填色。`描边 空` 时不绘制弧，即使填色不为空也不会填充。
- 部分 `扇形` 从中心连到起点，沿椭圆弧到终点，再闭合到中心；按当前填色和描边绘制，描边包含两条半径边。填充采用 nonzero（非零环绕）规则；`填色 空`／`描边 空` 分别取消对应绘制，两者均空时没有像素。

```ru
观 取 外言 '如:观'.
数学 取 外言 '如:数学'.
图 取 观 其 画布 360 200.
图 其 背景 '#fff7e8'.
图 其 填色 '#eaa74c'.
图 其 描边 '#9b5d35'.
图 其 线宽 3.
图 其 扇形 30 40 120 120 (-数学 其 圆周率 / 2) (数学 其 圆周率 / 2).
图 其 描边 '#247b78'.
图 其 弧 横:205 纵:40 宽:120 高:120 始角:0 转角:(数学 其 圆周率 * 1.5).
```

两种形状在提交时快照样式、透明颜色、变换和裁剪，后续设置不会移动或改写已提交图形；背景、保存／恢复及每回调状态重置规则不变。每帧仍最多 2048 条／约 256 KiB，零转角和不可见样式也计入预算。保存及重新打开仅重放静态画面，不恢复回调；旧快照保持原有重放行为。Python 与 browser-js 使用相同契约，普通 CLI／C／Node.js 仍不提供画布。

本批不提供弦形、折线、贝塞尔曲线或路径构造器，不用细小线段或多边形近似原生弧。完整 [披萨分份示例书](../rushu/examples/pizza-portions.rushu.json) 与 [如源码](../rushu/examples/ruguan/pizza-portions.ru) 完全同源：点击增减按钮或按左右方向键选择八份中的几份，扇形表示份额，弧表示外圈进度；默认 Python 或显式「JS 加速」运行同一格，无持续动画。

## 真实时间（0.19.3／如书 0.8.3）

`图 其 经过秒` 与 `图 其 间隔秒` 是只读、零参、返回数的普通画布成员，不是新增保留字。不得赋值、传入参数或在成员名后加 `()`。数值单位都是秒，可以有小数；不是日期、时区或墙钟时间。

- 创建画布时两者均为 0；初始绘图期间不随读取而变化。宿主在每次有效回调开始时，用本机单调时钟采样一次。同一回调内反复读取均得到冻结的同一快照；回调结束后保留该快照，直到下一次有效回调开始。
- `经过秒` 是自本画布创建起的经过时间，包含显式 `停` 的暂停和标签页隐藏期间的间隔。它不会因为继续动画或重新注册回调而归零；新画布重新从 0 开始。输入回调也取得新的经过时间。
- `间隔秒` 在每帧回调中是本次与上次实际帧回调开始之间的原始真实间隔。首帧为 0；从 `停` 到 `继续` 后的第一帧也为 0。已经运行时重复 `继续`，或在运行中重新注册 `每帧`，均不重置上一帧基准。
- 输入回调的 `间隔秒` 为 0，而且不改写上一帧基准。无回调、无效或被拒绝的事件不推进时间快照；客户端传来的时间值不能覆盖宿主采样。`每帧` 仍只接收一个从 1 开始的帧序号，不增加时间参数。
- 标签页隐藏会暂停事件交付；恢复可见后的下一实际帧保留隐藏间隔，既不钳位也不补帧。它不等同于显式 `停`／`继续`。设备休眠是否计入单调时钟取决于宿主，不保证不同平台一致；不能用这些数值推断日期或跨设备绝对时刻。

动画位置可由 `经过秒 - 开始秒` 计算，速度积分可用 `间隔秒`。不要把“帧数／目标帧率”当真实时间；帧率只是请求上限。若物理积分不宜跨越很长一步，可在程序中显式把自己的积分步长限制为例如 0.05 秒，但这只影响应用自己的模拟，不能改写原始时间接口。若要暂停动画进度，程序须记录暂停时刻并在恢复时调整自己的开始秒；`经过秒` 本身继续计时。

反复读取冻结快照的忙循环不能等待时间变化，会占住回调并触发原有预算；请用下一次回调推进状态。时间接口不延长回调预算，不增加等待、定时器、墙钟或文字测量接口。保存书本只保存静态画面，不恢复时间基准或回调。默认 Python 与显式 browser-js 使用相同语义，精度与实际数值由各宿主决定。

完整 [星港航班示例](../rushu/examples/elapsed-time.rushu.json) 和 [如源码](../rushu/examples/ruguan/elapsed-time.ru) 使用同一份源码：用共享阵保存待发／航行／暂停／抵达状态，以相对经过时间决定航程，并单独限制装饰动画的积分步长。点击按钮或按空格切换，暂停时按 `r` 继续；暂停与完成时停止逐帧回调，输入仍然可用。

## 文字对齐（0.19.2／如书 0.8.2）

要让标题居中，把文字锚点放在画布中心，并设置对齐方式；无需估算字符宽度。下面的中英文混排同样使用原生文字对齐：

```ru
观 取 外言 '如:观'.
图 取 观 其 画布 480 240.
图 其 背景 '#f4f6fb'.
图 其 填色 '#25344a'.
图 其 字号 28.
图 其 文字对齐 横向:'中' 纵向:'中'.
图 其 文字 '如观 / Ru' 240 120.
```

`图 其 文字对齐 横向 纵向` 返回空。两个参数均必需，必须是精确的句值：横向只接受 `'左'`、`'中'`、`'右'`；纵向只接受 `'上'`、`'中'`、`'下'`、`'基线'`。不接受英文别名、前后空白、空或其他类型。位置调用如 `图 其 文字对齐 '右' '基线'.`；命名参数精确为 `横向:`、`纵向:`，同一次调用不能混用位置和命名实参。新画布默认横向 `'左'`、纵向 `'上'`；这是初始样式，不表示调用时可省略参数。成员名是普通名称，不是新增保留字。

`文字 文 横 纵` 的签名和单行绘制方式不变，坐标是当前局部坐标中的锚点。横向映射到 Canvas 原生 `textAlign` 的 `left`／`center`／`right`；纵向映射到 `textBaseline` 的 `top`／`middle`／`bottom`／`alphabetic`。`'基线'` 适合让字号不同的文字共享字母基线；纵向 `'中'` 使用字体 em 框的中线，不保证可见字形墨迹包围盒精确居中。中文、西文、字体回退与不同浏览器字体可能有视觉差异。

文字对齐与填色、描边、线宽、字号一样跨回调保留，也由 `保存`／`恢复` 一并保存和恢复。每条文字命令在提交时冻结样式，之后改变对齐不会移动已经绘制的文字；`背景` 保留当前对齐。变换、裁剪和透明颜色可与文字对齐组合，锚点也按当前矩阵变换。每次回调仍重置矩阵、裁剪及保存栈。旧书本中缺少对齐字段的静态文字按左／上重放，不恢复交互。

文字对齐小批（0.19.2）没有文字测量、自动换行、多行排版或字体选择接口；不要虚构 `文字宽度`、`测量文字` 等成员。需要居中或靠右时直接用对齐，不用字符数猜宽度。完整 [文字锚点示例](../rushu/examples/text-alignment.rushu.json) 同时展示横向三种、纵向四种锚点及局部保存／恢复；其 [如源码](../rushu/examples/ruguan/text-alignment.ru) 与书本代码格完全一致，默认 Python 或显式「JS 加速」均可运行。

## 透明度与颜色（0.19.1／如书 0.8.1）

颜色接受六位 `#RRGGBB` 或八位 `#RRGGBBAA` 十六进制句，字母大小写均可。旧六位写法保持完全不透明；八位的最后两位 `AA` 是不透明度：`00` 全透明，`ff` 完全不透明，`80` 为 128/255。不得使用三／四位缩写、颜色名称、`rgb()`／`rgba()` 或句前后的空白。`填色 空`、`描边 空` 仍表示跳过对应绘制；合法的零不透明度色值仍是颜色，不能当作 `空`。

`观 其 颜色 红 绿 蓝 不透明度` 是 `如:观` 模块导出的普通算，返回小写八位色值 `#rrggbbaa`，可保存、作为实参传递或取函数引用。四个参数均必需，全部为 0～255 的有限整数；拒绝越界、非整数小数、事实（真／假）、空和其他类型，不钳位、不舍入。`不透明度` 为 0 时全透明，为 255 时完全不透明。沿用普通调用规则：一次调用全部使用位置实参，或全部使用命名实参；命名参数精确为 `红:`、`绿:`、`蓝:`、`不透明度:`，不是画布成员，也不是新增保留字。Python 解释器中仅调用 `颜色` 不需要画布宿主；创建画布仍需如书宿主，C／Node.js 编译目标仍拒绝如观模块，构色函数不会绕过该能力边界。

```ru
观 取 外言 '如:观'.
半透明红 取 观 其 颜色 255 64 64 128.
半透明蓝 取 观 其 颜色 红:64 绿:112 蓝:255 不透明度:128.
图 取 观 其 画布 240 160.
图 其 背景 '#00000000'.
图 其 描边 空.
图 其 填色 半透明红.
图 其 椭圆 35 30 100 100.
图 其 填色 半透明蓝.
图 其 椭圆 95 30 100 100.
```

`背景` 必须提供颜色，不能为 `空`。它先清除此前的绘制命令与整幅画布像素，再在透明底上绘制指定背景色；零不透明度背景得到透明画布，半透明背景不会与此前图形或上一帧叠加。背景忽略当前变换与裁剪，保留变换、裁剪、样式和保存栈。

每个提交的命令帧都在透明底上完整重绘，不保留上一帧像素；同一帧中图形按提交顺序叠色。不调用 `背景` 也不会产生上一帧残留。若需要轨迹，应在程序中保存历史点并每帧重新画出；本版不承诺 p5／Processing 的半透明背景拖尾。透明度小批（0.19.1）未引入渐变、混合模式或 HSB；当前文字对齐与真实时间见前节，文字测量仍未提供。



## 动起来，再加入互动

在一个新代码格中完整运行下例。圆点随帧前进，鼠标点击会改变填色；聚焦画布后按空格暂停，按 `r` 继续。帧率是请求上限，回调较慢时实际速度会降低。

```ru
观 取 外言 '如:观'.
图 取 观 其 画布 480 240.
图 其 描边 空.
图 其 填色 '#4677ff'.
图 其 帧率 20.
图 其 每帧 (作 帧:
    图 其 背景 '#f4f6fb'.
    图 其 椭圆 (帧 % 440) 90 40 40.
为).
图 其 鼠标按下 (作 横 纵 键:
    图 其 填色 '#ef476f'.
为).
图 其 按键 (作 键:
    若 键 == ' ' 则 图 其 停. 然
    若 键 == 'r' 则 图 其 继续. 然
为).
```

`每帧` 收到从 1 开始的帧序号，不是秒数。上面的短例刻意按帧移动，负载变化会影响速度；基于时间的动画应使用 `经过秒`／`间隔秒`，不要把“帧数／目标帧率”误认为真实经过时间。

回调可用算或作，返回值被忽略。参数名字可自行取，数量必须匹配。例如鼠标按下的三个参数依次是横坐标、纵坐标、鼠标按钮编号。

## 接口速查

模块导入名是精确的 `'如:观'`；旧 `'如观'` 给出迁移错误，不保留别名，也没有 `'如:如观'` 别名。这里用 `观 取 外言 '如:观'.` 绑定模块，便于在同一会话反复运行；不要用重复 `尽` 导入来重建画布，以免触发已有名称冲突规则。

| 调用 | 用途 |
| --- | --- |
| `观 其 画布 宽 高` | 创建本次活动画布 |
| `观 其 颜色 红 绿 蓝 不透明度` | 四个 0～255 有限整数生成小写 `#rrggbbaa` |
| `图 其 背景 色` | 清除此前命令／像素，再在透明底绘背景色 |
| `图 其 填色 色` / `图 其 描边 色` | 设置后续图形样式，空取消 |
| `图 其 线宽 粗` / `图 其 字号 大小` | 设置线宽和文字大小 |
| `图 其 文字对齐 横向 纵向` | 横向左／中／右，纵向上／中／下／基线；两参必需，默认左／上 |
| `图 其 矩形 横 纵 宽 高` | 绘制矩形 |
| `图 其 三角形 横一 纵一 横二 纵二 横三 纵三` | 原生闭合路径三角形，按当前填色／描边绘制 |
| `图 其 多边形 点阵` | 3～256 个 `[横, 纵]` 组成的阵；原生闭合路径 |
| `图 其 平移 横 纵` / `图 其 旋转 弧度` | 累积平移／弧度旋转 |
| `图 其 缩放 横倍率 纵倍率` | 双轴缩放；零与负倍率合法 |
| `图 其 保存` / `图 其 恢复` | 保存／恢复变换、裁剪及全部样式 |
| `图 其 变换 a b c d e f` | 右乘 Canvas 六参数仿射矩阵 |
| `图 其 重置变换` | 仅将当前变换设为单位矩阵 |
| `图 其 裁剪 横 纵 宽 高` / `图 其 取消裁剪` | 增加相交的矩形裁剪／清空当前裁剪 |
| `图 其 椭圆 横 纵 宽 高` | 绘制椭圆；宽高相等时为圆 |
| `图 其 弧 横 纵 宽 高 始角 转角` | 六参必需，带符号弧度；只描边，不填充 |
| `图 其 扇形 横 纵 宽 高 始角 转角` | 六参必需；部分扇形含半径边，整圈无辐条 |
| `图 其 线 横一 纵一 横二 纵二` | 绘制线段 |
| `图 其 文字 文 横 纵` | 以当前对齐锚点绘制单行句内容，不解析 HTML |
| `图 其 宽` / `图 其 高` / `图 其 帧` | 读取画布大小／当前帧序号 |
| `图 其 经过秒` / `图 其 间隔秒` | 只读零参：自创建起的秒数／实际帧开始间隔；回调内冻结 |
| `图 其 帧率 率` | 设置整数帧率上限：Python 1～30，显式 JS 加速 1～60 |
| `图 其 每帧 回调` | 注册一参回调，并开始动画 |
| `图 其 鼠标按下 回调` / `图 其 鼠标松开 回调` | 注册三参回调：横、纵、按钮 |
| `图 其 鼠标移动 回调` | 注册二参回调：横、纵 |
| `图 其 按键 回调` / `图 其 松键 回调` | 注册一参回调：键名句 |
| `图 其 停` / `图 其 继续` | 暂停／继续逐帧动画；暂停时仍可响应输入 |
| `图 其 关闭` | 终止画布交互，释放回调 |

这些是普通成员调用，零参成员不要再加一组 `()`。同一种事件再次注册会替换之前的回调。

### 路径形状、变换与裁剪（0.19.0／如书 0.8.0）

Python 与 browser-js 使用同一公开接口。`三角形` 和 `多边形` 使用原生闭合路径，按当前填色、描边及线宽绘制；填充采用 Canvas nonzero（非零环绕）规则，不用重复线段或逐像素模拟。`多边形 点阵` 只接受如的阵，包含 3～256 个点；每个点也必须是阵且恰有两个有限数坐标。重复点、退化形状及自交路径允许，按相同填充规则处理；提交后修改点阵不会改写已经绘制的形状。本版不提供任意路径裁剪、渐变、图像或新的路径构造器。

矩阵为 Canvas 顺序 `[a,b,c,d,e,f]`，即 `x' = a*x + c*y + e`、`y' = b*x + d*y + f`。初始为 `[1,0,0,1,0,0]`。`平移`、`旋转`、`缩放`、`变换` 都将新矩阵右乘到当前矩阵；先平移再旋转，形状先在局部坐标旋转，再移到目标位置。旋转参数是弧度，正角在纵坐标向下的画布上呈顺时针；缩放的零倍率和负倍率合法。所有数字参数以及每次累积后的六个矩阵分量必须有限且绝对值不超过 100000；形状及裁剪的宽高还必须非负。非法参数或累积矩阵越界报错。

每个形状在提交时快照当前矩阵及裁剪集合，后续更改状态不会改写它。`裁剪` 在调用时快照矩形及当时的矩阵，之后的变换不会移动已有裁剪；连续裁剪取交集。零宽或零高裁剪为空区域。`取消裁剪` 清空当前集合；`重置变换` 仅重置当前矩阵，不影响已有裁剪。`背景` 清除整幅画布像素和此前绘制命令，再在透明底上绘制指定色；不受变换与裁剪限制，同时保留当前变换、裁剪、样式及保存栈。

`保存` 将变换、裁剪、填色、描边、线宽、字号和文字对齐一并压栈，`恢复` 恢复最近一项。最多 64 层保存、当前最多 32 个裁剪。空栈恢复或超限报错；初始绘图结束以及每次回调结束时，保存栈必须配平，否则报错并关闭交互。显式关闭画布或创建新画布可以丢弃旧画布保存栈，无需先调用恢复；关闭前已经绘制的图形仍可保留为静态画面。`段: … 落.` 和 `{ … }` 只是词法作用域，离开块不会自动恢复绘图状态，必须显式配对 `保存`／`恢复`。

每次回调开始，矩阵恢复为单位矩阵，裁剪集合与保存栈清空；填色、描边、线宽、字号和文字对齐仍按原有规则跨回调保留。鼠标回调的横纵始终是画布坐标，不逆变换为局部坐标。初始绘图与回调每帧仍最多 2048 条绘制命令、约 256 KiB，点阵、矩阵及裁剪快照都计入数据限额；新增状态接口不提高既有预算。旧版无矩阵或裁剪字段的静态画面按单位矩阵和无裁剪重放，不恢复交互。

## 一帧、一个会话的边界

- 每个绘图回调提交完整画面；每帧都在透明底重新绘制本帧需要的背景和图形，不保留上一帧的像素，半透明背景也不会产生 p5 式拖尾。
- 输入回调如果只修改数据或样式而不画图，会保留当前画面；如果画图，则应绘制想保留的整个场景。没有每帧回调的静态画布也可以响应已注册的输入事件。
- 本版每个会话只有一个活动画布。创建新画布、运行另一个代码格或停止／重启会话，会关闭旧交互；旧输出可继续作为静态画面展示。请把画布创建和回调注册放在同一个绘图格里。
- 可以先在前面的格中准备数据，再运行绘图格。之后重新运行代码格会关闭当前交互，需要重跑绘图格。
- 暂停动画不同于停止会话。`停` 保留鼠标／键盘回调；关闭后的画布不能再通过旧变量继续绘图，应重新创建。
- 书本、历史源码和图形运行状态不是同一件事。保存书本不保存闭包、正在运行的动画或会话变量；重新打开时不会自动执行图形代码。

## 限额与出错

- 画布宽高各为 1～2048 的整数；坐标须为 ±100000 内有限数，形状宽高为 0～100000，线宽和字号为 1～256。
- 每帧最多 2048 条绘制命令，数据大小不超过约 256 KiB；单条文字最多 4096 个 Unicode 码点。
- 浏览器按实际 canvas backing 宽高限制总计 16 Mi 像素（约 64 MiB RGBA 像素存储，不是浏览器总内存上限）；较旧画面暂存为命令，点「重新查看画面」仅恢复静态绘制，不执行回调，保存的数据不丢失。
- 0.13.3／如书 0.3.1 将时间、跟踪行与硬看门狗阈值都提高到原来的 10 倍，保留软／硬时间 1:10 比例；内存、帧率、绘制命令和输出容量限制不变。较长回调仍会降低实际帧率，不能保证任意机器或负载均不超时。
- Python 回调预算为 1 秒／500000 Python 跟踪行／64 MiB 新增分配（并非如源码行）；支持 RLIMIT_AS 的平台还在回调期间使用 512 MiB 地址空间上限。10 秒硬看门狗能终止阻塞进程并重启，会清空全部会话变量。若宿主恢复 `RLIMIT_AS` 失败，会报告友好错误、关闭交互并要求重启会话；这不表示未知操作系统问题已被彻底修复。预算触发会关闭交互并报告错误；请缩小数据、简化回调，再重跑绘图格。
- 鼠标移动及动画请求会节流，不保证交付每一个物理输入事件，也不保证每秒准确收到指定数量的帧。
- 不要在回调里等待终端输入或执行长时间任务。资源限制是本机运行保护，不是运行不可信代码的安全沙箱；如言程序仍可能使用文件等已有能力。

## 如竞迁移

如竞当前标准导入名为 `'如:竞'`，如观为 `'如:观'`。公开算法保持原义，例如 `读入`、`字列`、`合句`、`排序`；请更新导入字符串。旧 `'如竞'`、`'如观'`、`'如:竞赛'` 给出迁移错误，不保留兼容别名。已有书本不会被自动改写或执行，详见 [迁移指南](standard-module-imports-migration.md)。

如竞与如观的用途不同：如竞仍可用于命令行与竞赛程序；如观的画布交互仅在如书中运行。普通竞赛程序无需导入如观。

## 用标准库写自然的动画

圆周运动直接使用 `如:数学` 的 `圆周率`、`正弦`、`余弦`，三角函数输入是弧度；角度先用 `角度转弧度` 转换。参见 [圆周运动](../rushu/examples/ruguan/circle-motion.ru) 和 [九体太阳系](../rushu/examples/ruguan/solar-system-math.ru)。后者保留悬停暂停、介绍和移开恢复，使用自然循环与每帧三角函数，不需要自写 Taylor 级数、预制 720 帧坐标表或展开每颗行星代码。对应 `.rushu.json` 书本位于 `rushu/examples/`。

随机数据复用 `如:随机`：初始化时 `源 取 随 其 造源 种子:42.`，再调用 `源 其 整数 下:8 上:472`。不要为画星空另外实现 LCG，也不要每帧重新造源。参见 [可复现星空](../rushu/examples/ruguan/seeded-stars.ru)。同种子和调用顺序得到相同坐标；这不是安全随机数。

实践顺序：

1. 在初始化阶段准备静态数据、固定布局、角度常量和随机背景坐标；每帧复用这些数据。
2. 跨帧状态放入共享的形或阵并修改字段／元素。函数中的普通名称重新绑定遵守其作用域规则，不等同于修改外层标量。
3. 时间驱动动画使用 `经过秒`／`间隔秒`，不以帧数除目标帧率计时。每帧只推进变化的数据，但仍须提交完整画面；静态数据缓存不代表宿主会保留上一帧像素。
4. 使用合理的循环、函数和交互，不必为了预算把源码机械展开。先实测初始化、回调与端到端耗时，再选择优化；提高预算只改变可运行上限，不能算加速。

生成提示会优先引导复用当前随附规范中的接口；不会给不存在的 API 兜底，也不会禁止需求所需的复杂程序。本地 HTTP Responses mock 测试只验证提示传输、源码接收、检查与显式运行链路；返回代码由测试预先写定，不能据此证明真实模型的生成质量。

## 输入释放与失焦（0.18.1／如书 0.6.1）

画布按下后使用指针捕获，并用窗口松开事件兜底；拖到画布外继续拖动时，坐标限制在画布范围内。指针取消、捕获丢失、画布或窗口失焦、标签页隐藏时，对已经接收的按下状态通过现有 `鼠标松开`／`松键` 回调释放，每次按下最多释放一次。鼠标释放使用最后有效坐标；没有新增离开画布回调或成员。

触摸只跟踪主触点，额外手指不映射成独立指针。如观公开回调没有指针 ID，不用于多点触控。隐藏标签页暂停事件交付，保留有界且有序的按下／释放状态，回到可见时继续处理。队列拥塞可能忽略新的按下，但为已接收按下的释放保留位置；移动事件仍可合并，不能当作完整物理输入记录。

停止、重启、销毁旧图形运行时会丢弃待处理输入并移除全局监听器，不再向旧运行调用释放回调。保存的静态画面不会恢复按键或拖动状态。上述规则适用于如书 Python 与 browser-js 图形前端，均不改变语言回调签名。
