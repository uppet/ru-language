## 复跑与使用

```sh
python3 -m unittest discover -s tests -v
node --test rushu/tests/*.mjs
make examples examples-js
```

拉取 `wip` 后关闭旧如书服务，重新运行 `python3 -m rushu`（Windows：`py -3 -m rushu`），打开终端给出的本机地址，再运行原绘图格。仅刷新浏览器不会更新已有 Python 服务中的预算常量。
