# 入门小路：从一句话到一个小程序

先按[安装与启动](stable-entry.md#取得同一套工具链)打开如书，选择「空白如书」。把下面每段代码完整放进一个普通代码格，点击「运行」或按 Shift + Enter。先保持默认运行方式即可。

每一步只多学一点：**看结果 → 改一个地方 → 再运行**。这些例子不需要账号、生成服务或 API key；准备好工具链后可以离线做。

## 1. 让程序说句话

```ru
显 '你好，如'.
```

你会看到 `你好，如`。`显` 的意思是显示一行，引号围住的是文字，在如里叫作「句」。末尾的 `.` 表示这条语句结束，中文句号 `。` 也可以。

试试把文字换成自己的名字。再加一行 `显 '今天开始写程序。'.`，两行就会依次出现。

## 2. 给数值起个名字

```ru
苹果 取 3.
苹果 取 苹果 + 2.
显 苹果.
```

结果是 `5`。第一行让名字 `苹果` 记住 `3`；第二行先算 `3 + 2`，再让它记住新结果。`取` 用来建立或更新这样的名字。

把 `2` 改成 `4`，再猜一次结果。文字要加引号，数值不用：`'3'` 是文字，`3` 才是数。

## 3. 重复一件事

```ru
星星 取 '⭐'.
循 3 次
    显 星星.
    星星 取 星星 + '⭐'.
环.
```

```text
⭐
⭐⭐
⭐⭐⭐
```

`循 3 次` 到 `环` 之间的两行会重复三次。文字之间的 `+` 把它们接起来，所以每次都比上次多一颗星星。缩进让重复的部分更容易看清。

试试重复五次。如果把更新 `星星` 的那行删掉，结果会变成什么？

## 4. 根据情况选一句话

```ru
温度 取 30.
若 温度 >= 28 则
    显 '出门记得带水。'.
另
    显 '出去走走吧。'.
然.
```

`若 … 则` 后面写条件满足时做的事，`另` 后面写另一种情况，最后用 `然` 收尾。这里的 `>=` 表示“大于或等于”。

把温度改成 `20`，再改成 `28`。留意临界值会走哪一边。条件只需要一个分支时，可以省略 `另` 和它后面的内容。

## 5. 把计算起个名字

假设你常要算一个数的平方，可以先教程序这件事：

```ru
算 平方 数值:
    得 数值 * 数值.
法.

显 (平方 4).
显 (平方 9.9).
```

结果依次是 `16` 和 `98.01`。

- `算 平方 数值:` 定义一个名叫「平方」的函数，接收一个参数「数值」
- `得` 给出计算结果，`法` 结束定义
- `(平方 4)` 调用它，把 `4` 交给「数值」

先记住这个写法：**带参数调用时，把函数名和参数一起围进括号**。这里是 `(平方 4)`。更多调用方式，等用到时再查[速查页](calls-and-scope.md)。

试试把函数改成「翻倍」，返回 `数值 * 2`，也记得修改下面调用的名字。

## 6. 放好一组东西

```ru
水果 取 ['苹果', '梨', '桃'].
显 水果[0].
水果 其 增 '橘子'.
显 水果 其 量.
```

两行结果是 `苹果` 和 `4`。方括号创建一组值，在如里叫作「阵」。位置从 `0` 数起，`水果[0]` 就是第一项。

`其` 表示取用这个值的成员：`其 增` 往阵里追加一项，`其 量` 取得项数。

试试显示第二项，再追加一个自己喜欢的水果。想排序、把每一项变成新值时，再看[阵指南](array-sort-map.md)。

## 7. 做一个会问好的小程序

最后，把显示、名字和文字拼接放在一起：

```ru
名字 取 读 '你叫什么名字？'.
显 '你好，' + 名字 + '！'.
显 '欢迎来写你的第一个如程序。'.
```

如书会在格内等你输入。填入名字并提交，程序就会继续。这里的 `读` 读进一行文字；在命令行中则从终端输入。这个例子请保持如书默认 Python 模式，显式「JS 加速」暂不提供交互输入。

试试把最后一句换成自己的欢迎词。你的第一个小程序就有了自己的口气。

## 保存，然后再出发

点击如书的「保存」，下载 `.rushu.json` 书本。它保存文字、代码和输出快照。**保存不等于保存运行中的变量**；重新打开时没有自动运行，历史输出只是上一次留下的记录。

刚开始，把每个完整例子放在独立代码格里最容易理解。以后让多个 Python 格合作时，前一格运行过的变量会留在本书会话中；修改前面的格后，要重新运行相关代码。觉得结果不对劲时，可以重启会话，再按顺序运行。详情见[如书的操作与状态](../rushu/README.md#操作与状态)。
