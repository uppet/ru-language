# 七个离线小练习

已经走过[入门小路](first-steps.md)，再用这些练习研究调用、作用域与会话状态。每次只做一题，不必一口气记住所有规则。

先按 [稳定版安装与更新](stable-entry.md) 取得 `main` 上的稳定工具链（版本组合见入口页），再选一个入口，按顺序练习。需要本仓库和 Python 3.10+；本页不用生成服务、账号或 API key。离线前须已取得仓库和 Python。

- **如书**：仓库根目录运行 `python3 -m rushu`，打开终端完整地址（含启动令牌）；把每题放入普通代码格，按 Shift + Enter。不要添加「如是我言」生成标记。
- **VS Code**：打开仓库文件夹，保存 UTF-8 的 `first.ru`，在集成终端运行 `python3 ru run first.ru`。普通文本编辑即可；也可使用独立的如言扩展 0.8.4，但仍需配置本机如工具链。
- **CLI**：把题目存为 `first.ru` 后运行 `python3 ru run first.ru`；也可用 `python3 ru repl`。Windows 使用 `py -3` 替代 `python3`。

如书默认 Python 格共享本书会话。勾选「JS 加速」的 browser-js 格每次独立运行，不继承前格变量；本页每题本身完整，可放在一格中运行。CLI `--target js` 是 Node.js，不能用来启动如观画布。

每题先猜输出，再运行，最后做一次修改。下方答案用于核对；每段代码可独立执行。本页统一用 `取` 赋值和 `段: … 落.` 文字作用域块，不要求先记符号别名。句点结束简单语句；块结束词各有规则，照例子书写。

## 1. 名称保存什么

先猜：修改后的值是多少？运行后把加数改成 4，再运行。

```ru
数值 取 3.
数值 取 数值 + 2.
显 数值.
```

```output
5
```

改错：删掉第二行句点，观察语法错误，再补回去。保存 `.ru` 文件保存的是源码，不是变量当前的值。

## 2. 零不是假

先猜这五行结果，再运行。把第一行改成 `显 0 != 0.`，比较“真值”与“非零判断”。

```ru
显 0 为 事实.
显 '' 为 事实.
显 [] 为 事实.
显 空 为 事实.
显 假 为 事实.
```

```output
真
真
真
假
假
```

只有 `空` 和 `假` 为假；空句、空阵、空典都为真。检查是否非空，应明确写 `句值 != ''` 或 `阵值 其 量 > 0`。

## 3. 调用先围起来

先猜阵有几个元素，再运行。把 `2` 改成 `4`。

```ru
算 平方 值:
    得 值 * 值.
法.
显 [(平方 2), 3].
```

```output
[4, 3]
```

改错：去掉 `(平方 2)` 的括号，运行 `[平方 2, 3]` 会把两个值读成平方的实参，参数数量不对。容器元素、嵌套调用或与后续运算组合时，把带实参调用的整体放进括号。

## 4. 函数不改同名全局

先猜两行是否相同，再运行。把函数内加数改成 5。

```ru
计数 取 10.
算 下一:
    计数 取 计数 + 1.
    得 计数.
法.
显 下一().
显 计数.
```

```output
11
10
```

右侧可以读全局；函数里没有已有非模块捕获绑定时，`取` 建立函数局部。不是把模块的 `计数` 改成 11。

## 5. 闭包共同记住绑定

先猜第二次是否仍是 1，再运行。把起始值改成 10。

```ru
算 制作:
    计数 取 0.
    得 算:
        计数 取 计数 + 1.
        得 计数.
    法.
法.
下一 取 制作().
显 下一().
显 下一().
```

```output
1
2
```

闭包更新最近已有的非模块捕获绑定，保存的是共享绑定，不是创建时的数值快照。每次重新调用 `制作()` 则有独立状态。

## 6. 块里的名字与对象的内容

先猜外面的阵变没变，再运行。把块内最后一行改成 `列表[0] 取 9.`，比较“重新绑定”与“修改共享内容”。

```ru
列表 取 [1].
段:
    别名 取 列表.
    别名[0] 取 2.
    列表 取 [7].
    显 列表[0].
落.
显 列表[0].
```

```output
7
2
```

显式块正文的赋值只写当前块。最初两名字指向同一个阵，因此改元素可见；后来给块内 `列表` 绑定新阵，不改外部绑定。形对象字段与典内容也有共享引用，块不是副作用回滚或深复制。

## 7. 保存文件以后

先运行，猜再次运行同一段结果。然后保存、重启会话，再只运行最后一行，观察缺失名称；重新从第一行运行可恢复。

```ru
起点 取 40.
显 起点 + 2.
```

```output
42
```

每次完整运行都是 42。如书各格共享当前会话，乱序执行可能读到旧值；保存书本保留源码、输出快照和已有版本记录，不保存活的变量、闭包或输入等待。重新打开不会自动执行，历史输出不代表当前会话已算过。CLI 每次 `ru run` 是新进程；REPL 状态仅保留在本次会话。
