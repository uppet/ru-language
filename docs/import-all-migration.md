# 全量导入：`尽取` 连写

适用于如 0.20.0 开发版，尚未发布到 main。普通模块绑定仍写 `数学 取 外言 '如:数学'.`；把全部导出名引入当前模块时写：

```ru
尽取 外言 '如:数学'.
显 平方根 16.
```

`尽取` 是一个完整关键字，`外言` 保留原名。两者之间可用空白、换行或注释分隔，不能把 `尽取` 拆成两个词。

## 旧代码怎么改

旧式写法已经停用，不保留兼容分支；解释执行、检查与编译共享前端并给出迁移诊断：

```text
旧：尽 取 外言 '如:数学'.
新：尽取 外言 '如:数学'.
```

旧式 `尽` 与 `取` 之间即使有换行或注释，也同样需要迁移。请按源码词法位置修改，勿批量改动字符串、注释或历史记录中的文字。`尽取` 不是赋值，不能写 `尽 := 外言` 或 `尽取 := 外言`，也没有 `进取`、`言` 别名。

## 名称与原有规则

- `尽取` 现在是保留字，原来名为 `尽取` 的变量、函数、参数或成员需要改名。单字 `尽` 继续保留，仅用于明确诊断旧语法。
- 词法仍采用最长名称；`尽取值`、`尽取器`、`未尽取` 等完整名称不拆分，仍可使用。
- 全量导入仍只允许在模块顶层，不能置于条件、循环、函数、方法、救或显式作用域块内。
- 导入路径仍是 `外言` 后的字符串字面量，按原有静态解析、路径缓存、模块初始化和循环导入规则处理。
- 不覆盖同名定义；导入函数与形名仍受保护。普通值可重新绑定，阵或对象仍共享引用。跨模块类型导入、转导出和限定访问规则不变。
- Emacs、如书和 VS Code 的现行示例、语法高亮与提示同步连写；编辑器是词法辅助，真实合法性仍以工具链检查为准。

规范与提示词导出已经使用新写法。历史 CHANGELOG、验证报告和问题复现保留当时语法，不能据此推断旧式在本版仍可执行。
