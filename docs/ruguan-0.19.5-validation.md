## 本批契约

- 新增普通画布成员 `折线 点阵`，唯一参数必需，支持位置调用及 `点阵:` 命名调用，返回空，不新增保留字。
- 点阵含 2～256 个点，每点必须为恰含两坐标的阵；数字必须有限且绝对值不超过 100000。事实、空、句、非阵、错误维数、稀疏槽及超限点阵拒绝，不转换、不钳位。
- 一条路径以一次 moveTo 开始，随后 lineTo 到各点，最后至多一次 stroke；不自动连接末点到首点，不使用 closePath 或 fill。仅用当前描边／线宽，忽略但不修改当前填色；不能逐段画线而让半透明接点重复叠色。
- 重复点、相邻重合点及所有点相同均合法，按原生 Canvas 默认端帽／连接／退化路径处理，不额外补圆点。末点等于首点也不转换为闭合路径。
- 每次命令深复制外层点阵及各点坐标，快照既有矩阵、裁剪、描边及线宽。样式跨回调保留、几何在回调边界重置、背景／保存／恢复规则不变。
- 无描边和零长度折线仍计为一条命令、消耗字节预算，并可在输入回调替换旧场景。每帧 2048 条／256 KiB、256 点和既有执行预算均未放宽。
- Python 与 browser-js 使用同一 polyline 数据命令（fill 固定空串）；IPC、Worker／主线程及静态历史校验匹配。场景绘制前完整验证，历史不恢复交互。
- 同步唯一规范、两提示词×两目标、如书／Emacs 成员提示、一周气温同源例子。没有贝塞尔、路径构造器、任意路径裁剪或文字测量，没有修改或打包 VS Code 扩展。

## 本批修复的数据边界

- 共用 polygon／polyline 点阵验证显式要求外层每个索引、每个点的两个坐标槽为自有属性。browser runtime 不再用会跳过稀疏槽的 map；主线程同样拒绝稀疏或继承槽。正常多边形语义不变。
- 独立检查复现了既有 array-as-record 漏洞：附命名字段的数组经 structuredClone 可保留数据，但 JSON.stringify 忽略这些字段，100 条各含 256 点的伪指令输入仅 396 字节，却曾规范化成 417196 字节并被接受。
- 冻结前明确拒绝数组形状的 scene、command 与 clip record，并对规范化后的完整场景再次执行 256 KiB 门禁。原输入字节门禁仍保留。复现载荷现被拒绝，普通对象非枚举字段的规范化扩容也受门禁约束。
- 单元及独立检查确认非法 Worker 批次整体拒绝，前置合法事件不外露；drawScene 在改变画布尺寸或绘制任何命令前拒绝，保存／历史边界也拒绝。保留上一批 opcode 必须为字符串的防护。
