# 如书生成诊断与模型输出

如书 0.7.0 的生成诊断用于分辨本机准备、提供方请求、响应解析、源码提取及目标检查的位置。它不运行生成源码，也不会自动重试付费请求。

## 可观察到什么

- 准备：验证意图与草稿、读取配置和当前语言规范。
- 发起请求与等待：记录本机开始连接提供方的阶段、时间与已等待时长；发起请求不证明提供方已收到（DNS／连接仍可能失败），等待不表示模型的思考进度。
- HTTP 响应与解析：区分收到响应、解析响应和提供方返回的完成状态。拒绝、未完成、响应格式或通讯错误保持独立诊断。
- 模型文本：仅展示提供方完整响应中实际返回的、面向用户可见的文本。没有 token 流时不会伪造实时输出，不展示模型隐藏推理。
- 源码提取：可对照清理前的模型文本与提取后的如源码，定位代码围栏或意图结语等提取问题。
- 目标检查：默认 Python 仅检查语法／结构；显式 browser-js 复用浏览器编译器的能力与模块检查。成功不等于代码正确或安全。
- 最终结果：区分生成成功、失败和页面取消等待。取消等待不保证终止提供方处理或计费，不会启动自动重试。

诊断不包含请求正文、完整 system 提示、配置、认证头或原始 HTTP 响应体。当前凭据在展示前脱敏；模型正文仍可能包含你主动发送的私密信息，分享前请自行检查。失败的模型文本供诊断参考，不自动成为可执行源码。

## 保存与容量

诊断属于一次生成，不写入书本历史或自动保存文件；它不是持久审计日志。关闭本机服务后服务端日志丢失，刷新页面后浏览器中的诊断视图丢失。浏览器最多保留最近 8 个代码格的生成记录（合计最多 16 MiB），每格仅保留最近一次；页面记录可能少于服务端记录。每个服务最多保留 8 次生成，记录保留 1 小时；满额时先移除最旧的已结束记录，活动请求不会被替换。

单次记录最多 64 个事件，每个事件附带文本最多 1 MiB（UTF-8），每次文本合计 2 MiB；每条说明最多 1024 字符。超限明确标记截断。容量限制前先做凭据脱敏。「清除此格诊断」只清除日志，不取消模型请求或撤销费用；已清除的生成标识在一小时内不能重复用于新生成。若清除先于已发出的生成 POST 到达，首次延迟到达的请求仍可继续，但不再保留它的日志。如果服务端清除请求失败，页面仍可移除自己的记录，但会说明尚未确认服务端清除。

展开「生成诊断 · API过程与模型原文」查看追加的阶段记录；模型可见文本与提取源码分别折叠并分页展示。如需保留或交给别人排查，请使用「复制诊断JSON」或「下载诊断JSON」，并先检查其中的模型输出。不把下载的诊断误当作已运行或已验证安全的程序。

## 本机接口边界

生成请求使用独立 32 位小写十六进制 generation_id。受启动令牌与本机来源保护的 `/api/generation/trace/<id>` 接口读取诊断，可用 `after=<seq>` 只取新增事件；删除接口只清除该次日志。事件有单调递增序号、UTC 时间、耗时、阶段与安全说明，文本按实际返回附带。旧页面、已取消请求和其他生成标识的响应不得覆盖当前代码格。

所有提供方测试使用模拟 Responses 服务；日志不会为了演示而额外请求真实模型。
