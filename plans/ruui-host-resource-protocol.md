# 如UI 宿主资源协议设计：件目／图载／件载／文入

状态：已定稿（待实现）
关联：`rulang/thirdparty/如UI/如UI.ru`（词表 v2 之后的 Phase 3）、如观协议、
`rulang/graphics_runtime.py`（Python 宿主）、`rulang/browser_runtime.js`（浏览器宿主）、
`tests/test_ruui.py`（双后端 parity）

## 1. 背景与目标

如UI 现有 16 词全部只发如观绘图命令（矩形／文字／裁剪），宿主逐帧照画即可，
双方无资源往来。Phase 3 的四个词打破这一点：

- **件目**：图与数据的来源目录。宿主持有的可以是真实目录（Python），也可以是
  构建期内嵌的**虚拟目录**（浏览器 `--target ui` 自包含页面）。库只做相对解析。
- **图载**：图像装载与解码是宿主的资源。帧循环是同步的，不能等解码；
  需要「请求 → 异步就绪 → 句柄绘制 → 释放」的生命周期。
- **件载**：数据文件读取。浏览器没有 `件`，自包含页面读不了数据；件载走与
  图载同一套件目解析与生命周期，把数据送进学生格里。
- **文入**：画布没有原生文本框。焦点、光标、键盘事件、输入法组合串、剪贴板
  都不在库的控制内；如观事件流目前只有鼠标与帧，连键盘事件都没有。

设计目标（与如UI 既有教义一致）：

1. **语言零改动**：新消息全部是典里的数据，不碰语法、不碰编译器。
2. **库保持纯净如**：四个词用普通如函数与`形`方法写成，如见渠道分发。
3. **双后端 parity 不破**：同一源码产出逐命令一致的命令流；宿主事件
   （就绪、失败、键盘）可像鼠标事件一样在测试里确定性注入。
4. **资源诚实**：装不进、解码不了、超配额的明确失败；装载过程库不假装
   在画——状态与完成通知给学生，装载 UI 由应用自绘。
5. **沙箱**：源路径越出件目在库侧直接报用法错误，不发给宿主。

非目标：网络下载策略（缓存、重试）、如书终端的行编辑复刻。

## 2. 词面

```
新 应用 宽 … 高 … 构 … 件目: 基
    件目（可省，默认 空）：宿主侧的资产基址，运行前配置一次。
    Python 宿主：文件系统目录，如 './assets'（走 件 的授权边界）。
    浏览器宿主：构建期 --assets 内嵌资产表的键前缀（通常 空），
    或绝对 URL 前缀（如 'https://cdn.example.com/ui'，程序级显式选远程）。

图载 源 宽 高 完成 重: 假 → 器
    源：相对件目的图像路径（句）。绝对路径与 .. 逃逸在库侧报用法错误。
    宽、高：绘框（行为同「占」）。就绪后等比缩放居中绘入框内。支持 充。
    完成：完成通知回调，恰一次 —— (作 宽 高 错 为 数 数 句: … 为)。
        就绪：宽高为图像像素尺寸、错为 空；失败：宽高为 0、错为失败句。
    重：假（默认）= 幂等，同号同源不重演；真 = 清行重发（同路径内容会变的场景）。
    装载中/失败库什么都不画：学生用 叠 垫自己的占位 UI，完成回调到达后改格重绘。
    装载状态住在应用实例的图载表（键 = 控件号，跨帧稳定）。

机 其 件载 源 回调 式: '文' 重: 假
    源：相对件目的文件路径，解析与沙箱规则同图载。
    式：'文'（默认）回调得 UTF-8 文本串；'base64' 回调得 base64 串（二进制可读）。
    回调：(作 文 错 为 句 句: … 为)，就绪以文、失败以错，恰一侧非空，
        每次状态迁移至多调一次；学生把结果存进格里。
    重：假 = 幂等（装载中/已就绪/已失败均不重演）；真 = 清行重发。重试显式传 真。
    按「解析后源串 + 式」去重：构里每帧调用同一源是幂等的；按钮回调里即点即装。

文入 值 占位 遇改 多: 假 → 器
    值：当前文本（住在闭包格里，每帧重读，与其他控件一致）。
    占位：值为空串时显示的灰字提示。
    遇改：(作 新串 为 句: … 为)。内容实质变化一次、调用一次：
        定字上屏、粘贴、删除触发；IME 组合草稿、光标移动、
        内容未变的回车/失焦不触发。学生回调里把新串写回格里。
    多：假（默认）单行——回车 = 提交并失焦；真 多行——回车 = 换行，
        失焦 = 提交（内容有变先补调一次 遇改）。
```

## 3. 协议消息

如观现有通道是单向命令流：库 → 宿主（`graphics` 事件的 `commands` 数组），
宿主 → 库（`frame`／鼠标事件，`dispatch` 进画布）。本轮扩展双向都动，
但全部是**数据消息**，不动通道结构。

### 3.1 库 → 宿主（命令流新增 op）

| op | 字段 | 语义 |
| --- | --- | --- |
| `图请求` | `号` `源` | 源为**解析后**串（件目已并入）。号由库分配（正整数，递增不复用）。 |
| `绘图` | `号` `横` `纵` `宽` `高` ＋常规裁剪字段 | 按框绘制已就绪图像。未就绪／失败的号宿主**不得**绘制（库侧本就不发）。 |
| `图释放` | `号` | 库不再引用（换页、树中移除、换源、重载）。宿主丢像素。 |
| `件请求` | `号` `源` `式` | 解析后串；'文' 读文本、'base64' 读二进制转 base64。 |
| `入焦点` | `框`（横纵宽高）`文` `光标`（字符下标）`选`（恒空，留位） | 文入获得焦点：宿主把系统输入焦点放到该控件上。浏览器宿主据框定位隐藏 input。 |
| `入失焦` | — | 文入失焦，宿主收起输入法。 |
| `入更新` | `文` `光标` `选` | 库侧文本/光标变化（退格、方向键），宿主同步系统输入框，保持 IME 锚点。 |

### 3.2 宿主 → 库（事件新增 type，走现有 dispatch）

| type | 字段 | 语义 |
| --- | --- | --- |
| `图就绪` | `号` `宽` `高` | 图像就绪（宿主侧像素可绘）。库记尺寸，下帧起发`绘图`、调完成。 |
| `图失败` | `号` `错`（句） | 读不到/解码失败/超配额。库记失败、调完成。 |
| `件就绪` | `号` `文` | 文本内容（UTF-8）或 base64 串（式 为 'base64'）。 |
| `件失败` | `号` `错` | 读不到/超配额。 |
| `键按下` | `键`（规范键名，见附录 A） | 物理键。文入 v1 的输入源。 |
| `字符` | `文`（单字符句） | 可打印字符（已过节流/组合）。无 IME 宿主只发这个。 |
| `剪贴` | `文` | 粘贴内容。 |
| `组开始` | — | IME 组合开始（浏览器宿主）。 |
| `组更新` | `组`（组合串）`光标` | 组合串变更，库在编辑串后显示带下划线组合串。 |
| `组结束` | `文`（定字） | 组合提交；库把定字并入编辑串（触发 遇改）。 |

## 4. 源解析与件目（沙箱）

解析在库侧完成，宿主永远只见解析后串：

```
解析(基, 源):
    若 源 == 空 或 源 首字符 == '/' → 用法错误
    归一 = 化点段(源)              # 展开 ./ 与 ../，纯串操作
    若 归一 以 '..' 段逃逸 → 用法错误
    若 基 == 空 → 归一
    另 → 基 + '/' + 归一
```

- **库侧拦截**：逃逸与绝对路径是**编程错误**，库直接抛用法错误（不进协议）。
- **Python 宿主**：解析后串即文件路径，open 读取（仍受 件 的授权边界与配额约束，
  双重闸门不冲突）。
- **浏览器宿主**：先在构建期内嵌资产表按键查（键 = 构建时 `--assets 目录` 下
  文件的相对路径）；查不到再看是否为 http(s) URL 前缀（件目以协议头开头时），
  fetch 取回。都失败 → 件失败/图失败。
- **构建期内嵌**：`ru build --target ui --assets ./assets` 把目录内文件以
  「相对路径 → 内容」编入页面：图片转 data URL、文本内联、其余二进制以
  base64 内联（件载 式 'base64' 可读，式 '文' 对二进制键直接件失败）。
  键不含前缀，程序件目留空、源写相对路径即可。
- **远端资源**：程序把件目设为绝对 URL 前缀即显式选择远程——默认自包含
  承诺不破，也不需要构建器开关。

## 5. 图载生命周期

```
   图请求(号,源)                每帧重演同号同源 = 幂等
        │
        ▼
     装载中 ── 库不绘制；应用自绘占位（叠 + 完成回调改格）
        │
   图就绪      图失败 ──► 完成(宽,高,空) / 完成(0,0,错)，恰一次
        │
     就绪态：每帧绘图(等比缩放居中)
        │
     图释放(号) ◄── 换页/移除/换源/重: 真
```

要点：句柄模型（命令流只带号，像素不上流）；完成通知恰一次；
装载 UI 完全在应用侧（学生用叠垫底、完成回调驱动重绘），库不内置任何占位文案。

## 6. 件载生命周期

与图载共用「装载表」机制（去重键：解析后源串 + 式；记录：状态、号、回调）：

- 构里每帧调用：同键已就绪 → 不重演回调（学生早已把文存进格里）；
  装载中 → 等待；失败 → 不重演（重试显式 `重: 真`）。
- 回调里发新源请求 → 新行，正常推进。
- 换页**不清**件载表：数据装载与页面无关，学生的格里数据也不因换页消失。

## 7. 文入编辑模型

库侧编辑串即学生格里那个串（每帧重读）：

1. `键按下`（规范键名见附录 A）：退格删光标前字符、删除键删光标后字符、
   方向键移光标、家/终跳行首/尾；单行模式回车 = 提交并自失焦，
   多行模式回车 = 换行（失焦 = 提交）；其余键忽略（可打印字符走 `字符`）。
2. `字符`：光标处插入、光标进一、并入编辑串 → 调 `遇改`。
3. `组开始/更新/结束`：组合串作**未提交段**显示（下划线，主题键待定，
   暂取 选底）；组结束把定字并入编辑串 → 调 `遇改`；
   组合中 `键按下` 一律忽略（IME 已消费）。
4. 光标：竖线＋逐帧闪烁（帧号取模）；选区 v1 不做（`选` 恒空，字段留位）。

焦点：点中文入 → 库发 `入焦点` 进编辑态；点其他可聚焦控件或画布空白 →
`入失焦`。应用内至多一个文入持有焦点（实例级记号）。
提交语义：内容有变的失焦/回车先补调一次 `遇改`，再失焦。

## 附录 A：规范键名表（v1）

```
退格  删除  回车  空格  跳格  逃脱  左  右  上  下  家  终
```

归一规则：

1. 可打印字符一律走 `字符` 事件；`键按下` 只承载上表编辑键。
2. 上表名是双宿主**唯一合法值**：浏览器把 `event.key` 翻译进表
   （'Backspace'→'退格'、'ArrowLeft'→'左'、'Enter'→'回车'、'Tab'→'跳格'、
   'Escape'→'逃脱'、'Home'→'家'、'End'→'终'），表外键名宿主静默丢弃。
3. parity 测试注入事件一律用表内名。

## 8. 宿主实现要点

### 8.1 浏览器宿主（browser_runtime.js）

- **图载**：内嵌 data URL 键直接 `new Image()`；http(s) 键 fetch → blob → 同路。
  onload → 量尺寸 → `图就绪`；onerror/超时（提案 10 秒）→ `图失败`。
  绘制 `ctx.drawImage` 等比。不读回像素，无 CORS taint。
- **件载**：键查内嵌表（文本/base64 已按构建期形态存好）或 fetch；
  文本按 UTF-8 解码，'base64' 原样回串。
- **文入**：叠透明 `<input>`（多行模式 `<textarea>`），`入焦点` 时按画布缩放比
  映射框到 CSS 像素并定位；监听 keydown/beforeinput/paste/
  compositionstart/update/end 原样转事件（按键先过附录 A 翻译表）；
  `入更新` 反向同步 value；软键盘随 input focus 自然唤起；
  IME 候选窗由系统锚在 input 位置，无需库指定锚点。

### 8.2 Python 宿主（graphics_runtime.py，如书会话）

- **图载**：命令流只带句柄、宿主不绘制——**不需要完整解码**。纯 Python 解析
  文件头拿尺寸是底线（PNG IHDR、JPEG SOF，各几十字节）；检测到 Pillow
  可用时走 Pillow（结果相同，`图就绪` 宽高一致），双路无用户侧开关。
  文件头也解析不了 → `图失败`。
- **件载**：走 件 的读文件路径；'base64' 读二进制转 base64；配额同一套。
- **文入**：如书会话把终端按键按附录 A 翻译注入；无按键源时文入不可聚焦
  （绘制但点不中），不假装能用。
- parity 测试不需要真实装载：测试宿主像注入鼠标事件一样注入
  `图就绪`/`件就绪`/`键按下`/`字符`，两后端命令流逐命令比对。

## 9. 配额与安全（提案值，待实现期校准）

- 单图解码像素 ≤ 4096×4096、解码后字节 ≤ 64 MiB；单件 ≤ 4 MiB
  （'base64' 为编码后大小）。
- 同时存活图像 ≤ 64 张、件载同存 ≤ 64 条（防句柄/行泄漏）。
- 构建期 `--assets` 内嵌总量默认 ≤ 16 MiB（构建器旗标可调），超限即构建失败。
- 库侧逃逸检查（§4）在协议之前；宿主对未知号 `绘图` 静默忽略（防御）。
- 源串长度上限 512 字符（防命令流膨胀）。
