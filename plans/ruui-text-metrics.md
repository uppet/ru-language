# 如UI 文本度量接真实测文（测文协议）

日期：2026-10-22　分支：ui-prep　状态：已拍板，实施中

## 背景

如观协议一直没有测文能力，如UI 控件全部使用库侧近似度量：全角一字一号宽、
半角 0.56 号宽（`符 < '一'` 判半角）。字形是宿主画的（浏览器页主用
PingFang/YaHei/Noto 字体栈，Python 端命令流由下游渲染器消费），近似宽度与
真实进宽之间的漂移在文入光标、组合下划线、自动换行断点上肉眼可见。
Phase 2 遗留项「文本度量接真实测文」即指此。

## 决议

1. **如观画布新增两个只读成员**（不是如UI 词，词表维持 20 词不动）：
   - `机 其 字度` → 典 `{'全': 数, '半': 数, '行': 数}`，三个数都是「号的倍数」。
     缺省 `{'全': 1, '半': 0.56, '行': 1.5}`（与现行近似完全一致）。
   - `机 其 测文 串` → 数，当前画布字号下该串的像素宽。
2. **度量来源三档**，per-canvas，创建时盖章：
   宿主实测钩 `textMeasurer(串, 字号) → 像素宽` ＞ 注入字度表（影响回退算法）
   ＞ 内置缺省。渲染宿主（浏览器页主）两路都给；纯协议端（Python graphics
   宿主，无字形）缺省走内置值，将来如书前端接自己的实测。
3. **回退算法双端逐位一致**：逐码点，`码点 < 0x4E00`（`'一'`）计半角，
   否则全角，乘当前字号累加。与库现行 `_文宽` 数学等价 → 不注入时全部
   存量 parity 测试零改动通过。
4. **宿主接入面**：
   - JS runtime 工厂 `createRuntime({emit, nowSeconds?, textMetrics?, textMeasurer?})`；
   - Python `GraphicsHost` 属性 `text_metrics`（典）／`text_measurer`（可调用物），
     画布创建时读取并校验；
   - 浏览器页主（`app_builder.HOST_JS`）启动时用显示上下文实测：
     `ctx.measureText('字')/16` 得全、`measureText('a')/16` 得半、
     `actualBoundingBoxAscent+Descent` 得行（缺失回退 1.5），钳进合理域后注入；
     `textMeasurer` 闭包同一 ctx，每次测前重设 `font`。
5. **校验**：字度三键须为 0.1..10 有限数（否则用法错误）；测文串 ≤ 4096 码点；
   实测钩返回值须为 0..10⁷ 有限数（否则「如观测文宿主返回无效宽度」）。
6. **缓存录制器禁用** 两成员（同 3b 的入焦点等）：查询不进缓存配方。
7. **库侧改动**：删模块级 `_半宽`/`_文宽`，`形 应用` 内新增方法
   `算 _文宽 字: 画布 取 (其 图)[0]. 得 画布 其 测文 字.`，六处调用点改 `(其 _文宽 …)`。
   行高／衬保持 1.5／0.6 号不动（垂直节拍改动面大、收益低，列 3d 候选）。
8. **parity 不破**：双端同注入同结果；新测试注入 `{全:1, 半:0.5, 行:1.4}`
   验证光标 x 精确用注入值；不注入时行为与旧版逐位一致（存量 32 例兜底）。
   产物级（真浏览器引擎）差异不进 parity 面。

## 测试

- parity：`机 其 测文 'a一'` 读回宽度与 `机 其 字度` 读回注入值（双端相等 +
  精确值）；文入打字后光标矩形 x 随注入字度变；非法字度（负数／缺键）双端拒绝。
- 产物级（Node + DOM 桩）：桩 `measureText` 返回定值，验证页主真把实测字度
  注入 runtime，文入光标 x 用实测半角而非 0.56。
- 存量 32 例 + 3 例产物级不注入路径全绿。

## 兼容性

- 协议新增两名（只读查询），旧程序无感；默认行为与上一版逐位一致。
- C 后端无如观，不涉及。
