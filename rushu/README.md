# 如书 · 本地网页笔记本

如书包版本：0.3.0。

当前支持如语言 0.13.2。以如的解释器为运行核心，把 Markdown 与代码放在同一本书中。`rushu/` 是独立目录；现有 CLI、编译器与语言语法保持不变。

生成等待状态旁有固定尺寸 SVG 提示，文字不逐帧变化；完成、取消或失败后停止。系统开启减少动态效果时保留静态标记。

## 起始模板

打开如书先看到起始页，可选「基础入门」「文本处理」「如竞题解」「如观互动」「如是我言生成」或显眼的「空白如书」。前四类各含一两个短例；生成模板提供意图起点，空白模板只有一个空代码格。

起始页不创建后台运行会话。选择模板后才建立独立书本与会话，但不自动运行代码或请求模型。「新建」随时打开同一个模板选择器，关闭或按 Escape 保留当前内容；选择后才确认是否替换未保存的书本。每次新建都有独立格子和生成历史。

模板是普通如书，可直接修改、保存和重新打开。如竞示例用固定输入避免等待 EOF；如观创建画布与回调在同一格。生成模板需先配置提供方，明确点击生成并确认发送内容后才联网；先审阅生成的源码，再单独运行。

## 启动

从仓库根目录运行，需要 Python 3.10 或更新版本：

```sh
python3 -m rushu
```

Windows PowerShell / CMD：

```powershell
py -3 -m rushu
```

打开终端打印的完整地址（包括 `#token=...`）。页面、样式、编辑器全部由本机提供，普通编辑与执行不需要 npm、CDN、网络服务或 API key；可选学习生成模式需要单独配置提供方。服务器退出后页面不能执行代码。

书本示例：在页面选择“打开”，选取 `rushu/examples/first-book.rushu.json`。它包含共享变量、匿名闭包和 `examples/add.ru` 的交互输入。

编辑器同步如 0.13.2：参数可省略 `为 类型`，有名定义与匿名闭包都可混用有注解 / 无注解参数，以空白或逗号分隔。无注解参数接收包括 `空` 在内的任意值，显式类型仍检查。

`完.` / `完。` 高亮为关键字，在过程内提前返回 `空`，不关闭块或改变缩进；`完成` 等完整名称仍是普通名称。过程自然结束也返回 `空`。

页面标题旁显示当前运行包的如版本、随附规范版本和独立的如书版本。无法读取时明确显示未知或读取失败；不推测 Git 分支，也不代表编译器、Node.js 或其他环境检查已通过。新手可从[七个离线小练习](../docs/getting-started.md)开始。

## 操作与状态

- 文字格记录 Markdown，代码格使用现有如语言；代码格显示执行序号、输出和错误。
- 逐格运行时，变量、函数、闭包和可变对象留在这本书的会话内。执行顺序由实际点击次序决定，未必与页面排列一致。
- “全部运行”按页面顺序执行代码格。输入请求会等待本格的输入；错误停止后续格。
- 不同书本的会话独立。新建或打开一本书会建立空会话，不自动执行源码。
- “停止”会终止整个工作进程并清空本书所有运行状态，包括正在等待的输入；“重启”也清空状态。不能在无限循环中安全地保留部分状态。重启后请重新按顺序运行需要的格。
- 普通运行错误不具有事务回滚：出错前已经完成的赋值、可变对象修改或文件操作仍可能发生。语法错误通常在执行前报告。
- 保存的 JSON 包括文字、源码、输出及原执行序号，不包括运行中的变量、函数、闭包或输入等待。重新打开时已有结果标记为“历史输出”，不能说明本次会话已执行。
- 编辑已运行的代码不会自动重算依赖格；请手动重新运行，必要时重启再全部运行。

运行错误显示行、列；错误来自外言模块时还显示来源路径，避免把模块行号误认为本格行号。来源仅作纯文本显示，控制字符及方向控制符转义。生成源码未通过语法／结构检查时，学习格也显示检查器提供的行、列；不会为定位错误自动运行代码。

## 重复执行与声明

沿用当前 REPL / `Interpreter.execute` 语义。重复的顶层变量绑定更新该绑定；重复顶层函数声明会为该名称注册新函数；类型重新声明不会改变旧实例已有的类型身份。已保存到其他变量的旧函数值仍可能引用旧函数体，而共享捕获的变量仍按当前绑定读取。名称冲突、类型与重复声明检查由语言实现决定。需要干净、可复现的结果时，请重启会话并从头运行。

如书没有添加新的映射结构或更改现有 `阵`、匿名 `算` / `作` 语法。

## 安全边界

**只运行你信任的代码与书本。它是本地执行工具，不是操作系统沙箱。** 如代码中的 `件` / `录` 等文件操作具有启动 Python 用户的正常文件读写权限，路径按启动进程的工作目录解释。停止进程不会撤销已经完成的文件修改。

服务器仅监听 IPv4 回环地址 `127.0.0.1`。执行 API 使用随机令牌、严格 Host / Origin 检查和 JSON 请求验证；仅提供固定的前端静态资源，不提供通用文件浏览、任意路径读写或上传接口。书本由浏览器本地打开与下载。只有显式确认学习生成时，会把本格当前意图和源码发给已配置的提供方；不上传整本书。不要把启动地址或令牌分享给他人，不要通过反向代理将服务暴露到互联网。

Markdown 仅支持安全的基础子集，原始 HTML 不执行；代码输出作为纯文本显示。导入书本只恢复可显示数据，不执行其内容。即便如此，点击运行仍等价于主动执行书本中的程序。

输出默认折叠为前 8 行、至多 2,000 个 UTF-16 单元（不拆开 emoji）；展开后每页至多约 32 Ki UTF-16 单元及 128 个文本节点。折叠不会丢弃已保留原文，保存与重新打开保留相同内容。

保留与传输容量按 UTF-8 字节计算：内核每次运行最多 2 MiB 或 16,384 个合批事件；浏览器每格输出 2 MiB、全书输出 8 MiB（含图形快照），为截断提示和运行错误预留空间。持续写入时按约 8 KiB / 50 ms 合批，输入请求、错误、画布事件和完成前立即刷新。到达容量上限才明确提示后续内容已丢弃；程序可继续运行，必要时点击停止。服务端每会话历史最多 16 MiB / 20,000 事件，每次轮询事件约 1 MiB 并分页，不丢跳尚未读取的事件。书本 JSON 上限 64 MiB；导出不会静默再次裁剪。

## 文件格式（版本 1）

UTF-8 JSON：

```json
{
  "format": "rushu-notebook",
  "version": 1,
  "title": "我的如书",
  "cells": [
    {"id": "cell-1", "type": "code", "source": "显 '你好'.", "execution_count": null, "outputs": []}
  ]
}
```

`type` 为 `code` 或 `markdown`；图形输出可为 `{ "type": "graphics", "scene": { ... } }` 的只读命令快照（旧版如书不识别，新版打开绝不恢复交互）；文字输出项为 `{ "type": "stdout", "text": "你好\n" }`，也可为 `stderr`、`error` 或 `input`。未来不兼容格式使用新的版本号。

## 中文注释与赋值提示

- `批.` / `批。` 从标记起注释到行尾，可写在语句后；`#` 和 `//` 保留。
- `解.` / `解。` 开始块注释，首个 `释.` / `释。` 结束；不嵌套，注释内引号和代码块词均为普通文字。标记的字与句点必须相邻。
- 不拆开 `批评`、`解释`、`总批` 等完整名称，字符串内不识别注释。标记自带的句点属于注释，不能代替前一语句的句点。
- 注释里的伪代码块不参与缩进和结构导航；多行注释的内部空白保持原样。
- 悬停在代码中的 `取` 上可查看保守的词法赋值规则：函数内先更新当前局部，否则更新最近已有的非模块捕获绑定；没有则创建当前局部，不隐式改写模块变量。直接 `救` 正文写救局部，直接显式作用域块正文写块局部（包括其中的若、循、试），闭包共享并可更新捕获的块绑定，参数属于本次调用局部。`:=` 与 `取` 等价并显示相同提示。提示不推断具体名称在运行时绑定到何处。

## 0.10 事实与典

典的每个条目由**目（key）**与**相（value）**组成：目用于查找，相是该目对应的值。`目`、`相` 是教学术语，不是新增关键字；`值` 仍是语言的通用概念。典的成员命名实参统一使用 `目:`、`相:`：`查 目:`、`增 目: 相:`、`除 目:`；不再接受旧名 `键:`、`值:`。位置实参和 `列 回调:` 不变，回调内部参数名由用户自定。

`事实` 是内置类型，`真` / `假` 是完整保留词；含这些字的长名称仍是普通名称。`典` 在类型注解中按类型高亮，只有后接冒号的字面量开启 `典 … 成` 块。缩进、结构识别和悬停提示支持嵌套典、空典、匿名回调，以及半角 / 全角标点；字符串和注释中的伪结构不参与分析。`对` 在典中分隔目与相，原来的二元素对保持可用。

```ru
资料 取 典：
    ‘就绪’ 对 真。
    ‘设置’ 对 典：‘次数’ 对 3。成。
成。
显 （资料 其 查 目：‘就绪’）。
显 资料 其 量。
```

典可用 `资料['就绪']` 读取，与 `查` 等价，缺失返回 `空`；方括号赋值和切片仍不支持。典的成员包括 `查 目:`、`增 目: 相:`、`除 目:`、`列 回调:` 和 `量`；列回调接收目、相两个位置参数。`为 事实` 做真值转换；仅 `空` 和 `假` 为假，数值 0 与空句也为真。事实与数是不同类型。

位置参数、命名参数与分组表达式沿用普通调用规则，例如：

```ru
资料 其 增 目: (‘次’ + ‘数’) 相: (1 + 2).
显 (资料 其 查 ‘次数’).
资料 其 列 回调: 作 目, 相:
    显 目.
    显 相.
为.
资料 其 除 目: ‘次数’.
```

## 学习模式：如是我言

在文字格点击「如是我言」，会保留原文并另建一个学习格、开始确认生成；也可以点击底部「＋ 学习」，或把现有代码格切换为「学习模式」。学习格分别编辑意图与当前如源码草稿。普通代码格的末行若单独写了「如是我言」，点击运行或按运行快捷键会直接进入本页的生成流程，显示发送范围并确认，不把文档交给执行器。文字格末尾带标记时按 Shift + Enter，或直接点击文字格的「如是我言」按钮，同样开始生成。输入标记本身不会联网。

1. 写下程序需求，点击「如是我言 · 生成」。按钮会补上最后独占一行的标记，字符串／注释中的标记不算入口。
2. 页面显示服务端配置的提供方主机，以及将发送的范围；确认后，只发送本格当前意图、当前源码草稿和随附完整如语言规范。不会发送其他格、历史版本、输出、运行变量或本机文件。
3. 生成结果作为新的模型版本出现在源码区。只做语法／结构检查，不读取外言依赖，不运行程序、不执行导入。即使检查未通过，也保留返回的源码供学习修改。
4. 可以直接修改源码与意图，然后再次生成；也可在已生成的源码末尾单独补上「如是我言」再点运行，标记会从发送的源码草稿中移除，继续生成而不执行。「记下手动修改」保存人工版本；再次生成、恢复和保存书本也会记录当前修改。每个版本包含独立编号、时间、来源、完整意图及源码。
5. 展开「版本历史与变化」，浏览所有版本，任意选择两版对比意图与源码。恢复旧版会先记录当前修改，再添加一个恢复版本，旧版不会被覆盖。超大的差异预览会明确截断，完整源码仍可查看和随书导出。
6. 生成与恢复不会自动运行。审阅后单独点击本格「运行」；「运行全部」跳过所有学习格和意图文档。

### 配置、取消和保存

沿用 `ru generate` 的 `~/.ru-lang.json`、`RU_LANG_CONFIG`、`RU_LLM_API_KEY`／`RU_LLM_API_KEY_FILE`、`RU_LLM_BASE_URL` 和 `RU_LLM_MODEL`。在启动如书前设置，详见仓库 README 的生成配置。**不要把 API 密钥写在书本、意图或源码里。** 密钥只在 Python 服务端读取，不返回浏览器、不进入本地存储或版本文件；没有密钥时仍可离线编辑和查看历史。默认提供方与模型沿用语言生成模块。

生成请求默认超时为 1800 秒（30 分钟），可在启动时使用 `python3 -m rushu --generation-timeout 3600` 改为 3600 秒。该值须为有限正数，可使用小数，没有 300 秒上限。提供方请求与服务端等待使用同一超时配置；页面不会另设较短的生成截止时间，仍可随时点击「取消等待」。

学习格中可展开「生成诊断」，查看本机实际可观察到的配置读取、请求等待、结果接收阶段与请求耗时，以及最终语法／结构检查结果。提供方响应是非流式的，等待期间不显示虚构的 token 进度；诊断不记录意图、源码、密钥或原始响应。证书、TLS、HTTP、超时和连接错误会以脱敏分类说明，生成失败不覆盖当前草稿。

每次生成只发出一次请求，不自动重试，最多 16,384 输出 token，沿用现有 Responses 协议和完整规范 SHA-256。提供方可能收费。点击取消、切换书本或重启只丢弃结果，不能撤回已经发出的请求；超时也可能已经计费。在服务端请求真正结束前，其他生成请求会被拒绝。生成中可以继续编辑；只要当前意图或源码与发送时不同，返回的旧结果会被丢弃，不覆盖新编辑。

书本格式仍为版本 1；代码格可附加 `generation: {prompt, revisions}`。旧书本不受影响，旧版如书无法保留这些新历史字段，学习书本请用新版打开。单格最多 100 个历史版本，历史快照合计最多 2 MiB；当前意图与源码各最多 200,000 字符，整本文件最多 64 MiB。达到历史上限后，仍可导出当前草稿和已有历史；点击「另起学习格」复制当前意图与源码继续，原格完整历史保留。不静默删除旧版。

浏览器没有自动保存。关闭或刷新前点击「保存」下载 `.rushu.json`；取消、错误及失败响应不会替换当前编辑，只有下载后的文件能跨浏览器重启保存。不要在书本中记录不希望随下载文件保存的敏感信息。

示例：打开 `rushu/examples/learning-mode.rushu.json`。内含明确标为人工示例的历史、意图和源码，不需要密钥即可练习查看变化与恢复。


## 0.10.1 符号典与编辑提示

典可写成 `{目: 相, 目: 相}`，空典为 `{}`；支持全角 `｛｝`、`：`、`，`，和阵一样允许末尾逗号。目与相的表达式可跨行，典、阵和匿名算 / 作可嵌套。`典: 目 对 相. 成` 保留，`成` 仍是保留词；0.11.0 起表达式位置的花括号表示典，语句位置的花括号表示显式作用域块。

```ru
资料 取 {
    ‘就绪’: 真,
    ‘设置’: ｛‘次数’：3｝,
    ‘回调’: 算 值:
        得 值.
    法,
}.
显 资料[‘设置’][‘次数’].
```

编辑器识别半角 / 全角花括号，按嵌套结构显示缩进线；开括号后按 Enter 缩进，行首输入 `}` / `｝` 自动回退到对应层级。字符串和注释中的花括号不参与结构分析，原有高亮和中文典提示继续可用。编辑提示容忍尚未闭合的输入，不代替语法检查。


## 0.11 作用域块和 `:=`

支持 `段: … 落.` 及语句位置的 `{ … }`，两者可混合嵌套并使用全角标点。`段` / `落` 只在对应块边界高亮，普通名称、`其 段`、命名实参和长名称不变；`落 取 值.` / `落 := 值.` 不会关闭块。表达式位置的 `{}` 仍是空典；裸语句 `{}` 是空块。块头 Enter 后缩进，结束行与块头对齐；未完整的块和每个输入前缀保持容错。

```ru
段：
    名字 := '局部'。
    ｛
        资料 ：= {'名字': 名字}。
        显 资料。
    ｝
落。
```

赋值高亮与悬停支持连续的 `:=` / `：=`，不把 `: =` 当成一个符号。它们只是赋值语句中 `取` 的别名；典、命名参数和块头仍用单独冒号。每次进入显式块创建新局部环境，直接绑定不泄露；闭包可保留并更新块绑定。`得` / `完` / `破` 不因包一层块而改变目标，形与 `尽` 仍限模块顶层。编辑器是词法辅助，不执行这些语义检查；完整规则与例子见[作用域块指南](../docs/scoped-blocks.md)。

0.12实用标准库可直接在代码格导入文本／数学／随机，阵提供删／弹／查。随机源与其他变量一样保留在同一笔记本会话；重跑造源会创建同种子的新序列，单独重跑抽取则继续旧源。见[实用库指南](../docs/practical-libraries.md)。

## 如观交互画布（0.2.0）

打开 `rushu/examples/ruguan.rushu.json`，先运行数据格和柱图格：点击柱子所在列更新共享阵数据，聚焦后按 r 重置。再运行动画格可试空格暂停／r 继续。每个会话一个活动图形；运行新格关闭旧交互，已有静态输出保留。重复运行图形格使用模块绑定，不重复尽导入。

绘图接口、颜色／坐标、回调参数及限额见 [如观指南](../docs/ruguan-guide.md)。回调仍在本书 Python 解释器执行，没有浏览器任意脚本入口；不提供完整 Processing.js 兼容、3D、外部资源或图形编译后端。保存后的画面是静态历史，打开不自动执行。CLI check 会报告图形后端能力边界。真实浏览器可选验证：安装本机 Playwright/Chromium 后设置 `RUN_RUSHU_BROWSER_TESTS=1` 运行 `node --test rushu/tests/scene-browser.test.mjs`；普通 Node 套件默认跳过该可选项。
