# ru-lang-mode：Emacs 基础语言支持

`ru-lang-mode.el` 用于查看和编辑如语言 0.10.0 的 `.ru` 源码。只使用 Emacs 自带的库，编辑功能不需要安装其他包、Python 进程、LSP 或 tree-sitter；快捷运行需要 Python 3 和如 CLI。

0.6 的 JavaScript 后端与生成目标不改变 `.ru` 语法；匿名算 / 作字面量更新已同步高亮、缩进、定义和结构导航。

默认运行时 / 随附标准库裁剪和 `build --full-runtime` 也只是编译选项，不新增关键词或语法，高亮、缩进、Imenu 和导航无需改动。此模式不封装构建命令；可在仓库根目录用 Emacs 自带的 `M-x compile` 执行 `python3 ru build 文件.ru -o 程序 --emit-c 程序.c`。要诊断裁剪前后的差异，在命令末尾加 `--full-runtime` 并使用另一组输出路径；JavaScript 同样可用 `python3 ru build 文件.ru --target js -o 程序.js --full-runtime`。编译不会自动运行生成程序。

目标版本为 Emacs 28.1+；先前本地实测 GNU Emacs 30.1（Linux）。仓库 CI 另用 Ubuntu 24.04 提供的 `emacs-nox` 运行相同测试。macOS / Windows 的图形界面未实测。

0.9.0 支持省略参数的 `为 类型`；空白和逗号可分隔混合注解参数，无注解参数也接受 `空`。声明位置的 `算 名 参数:` 是有名定义，表达式位置的 `回调 取 算 参数:` 是匿名字面量。高亮、缩进、Imenu 和结构导航沿用此区分。

0.8.0 的 `完.` / `完。` 按完整保留字高亮，`完成` 等名称不受影响。`完` 是过程内提前返回 `空` 的简单语句，不关闭块、不改变缩进或导航边界；过程仍由 `为` 关闭。

## 加载

把下面两行加入 `~/.emacs.d/init.el`，将路径改成自己的仓库路径：

```elisp
(add-to-list 'load-path (expand-file-name "~/src/ru-language/emacs"))
(require 'ru-lang-mode)
```

重新打开 `.ru` 文件就会自动进入 `如` 模式。已经打开的文件可执行 `M-x ru-lang-mode`。

临时试用，无需修改配置：

```sh
emacs -Q -L ./emacs -l ru-lang-mode examples/objects.ru
```

## 常用操作

| 按键 / 命令 | 用途 |
| --- | --- |
| `C-c C-r` / `M-x ru-lang-run-file` | 保存后异步解释执行当前文件 |
| `TAB` | 缩进当前行 |
| `C-M-\` | 缩进选中的区域；整份文件可先按 `C-x h` |
| `C-M-a` / `C-M-e` | 跳到前一个定义开头 / 当前或下一个定义末尾，包括形与方法 |
| `C-M-h` | 使用 Emacs 标准的定义选区命令 |
| `C-M-n`（Ctrl+Alt+n） | 成对跳过同层的下一个代码块或括号；在开头时跳过整个结构 |
| `C-M-p`（Ctrl+Alt+p） | 成对跳到同层上一个结构的开头，不落入其嵌套子块 |
| `C-M-u`（Ctrl+Alt+u） | 回到包围当前位置的最内层结构开头，再按回到外层 |
| `C-c C-p` | 跳到前一个代码块开头 |
| `C-c C-n` | 跳过当前最内层代码块；在块外时跳过下一个块 |
| `C-c C-u` | 回到当前最内层块的开头；再次按可回到外层 |
| `M-{` / `M-}` | 按空行分隔的段落前后移动 |
| `C-M-b` / `C-M-f` | 使用标准括号 / 字符串移动 |
| `M-;` | 使用标准注释命令，新增注释采用 `#` |
| `M-x imenu` | 按名称选择形、算、作或方法，如 `算 人@姓名` |

`C-M-n` / `C-M-p` / `C-M-u` 和旧 `C-c C-p` / `C-c C-n` 接受数字前缀，例如 `C-u 3 C-M-n`。新按键的 `n` / `p` 使用负前缀时反向移动，`u` 使用负前缀时跳到包围结构末尾；前缀为 0 时不移动。`C-M-a` 使用负前缀时向后面的定义开头移动，例如 `M-- C-M-a`。`M` 是 Meta，通常对应 Alt；若终端拦截组合键，可先按 `Esc`，再按 `Ctrl+n` / `Ctrl+p` / `Ctrl+u`。

“代码块”包括 `算 … 法`、`作 … 为`、`形 … 象`、`若 … 则 … 另 … 然`、`循 … 环` 、`试 … 救 原因 … 终` 和 `典 … 成`。新 `C-M-n` / `C-M-p` / `C-M-u` 同时识别 `()` / `[]` 与全角括号，也能处理它们与代码块的交错嵌套；字符串和注释里的伪结构不参与跳转。`C-M-b` / `C-M-f` 仍是 Emacs 自带的表达式移动。

新按键按同层完整结构移动：光标在外层块开头时，`C-M-n` 跳过整个外层，紧接 `C-M-p` 返回该开头；在块内时跳过其下一 / 上一个子结构。没有同层目标或目标未闭合时给出提示，光标不动（多次前缀中途失败也不移动），向外请用 `C-M-u`。位于内层开头或其完整末尾之后时，`C-M-u` 回到父结构；在结束词 / 括号前则仍属于内层。声明和控制流块末尾包含紧随的可选句点；匿名字面量只到 `法` / `为` 之后，其后的句点属于外层语句。括号末尾只到右括号之后，不吞句点。未闭合结构仍可从内部或文件末尾用 `C-M-u` 回到开头。

旧 `C-c` 按键保留原有行为：`C-c C-p` 按词法顺序找前一个块开头，可能进入已经结束的嵌套子块；`C-c C-n` 跳过当前最内层块或下一个块；`C-c C-u` 包含块末尾边界。这些旧命令只处理语言块，不处理括号。

## 快捷运行当前文件

在 `.ru` 源码缓冲区按 `C-c C-r`，使用随扩展所在仓库的 `ru` 执行 `python3 -u /仓库/ru run /当前文件.ru`，不需要 C 编译器。运行工作目录是源码所在目录，外言模块按 CLI 原有规则解析；运行整个文件，不受选区或 narrowing 影响。

- 文件有修改时先询问是否保存；拒绝或保存失败就取消运行，不执行磁盘上的旧内容。未关联文件的缓冲区须先用 `C-x C-s` 保存
- 异步显示 `*Ru: /完整文件路径*` Comint 缓冲区，包含标准输出、错误和进程结束状态；Emacs 不会等待程序结束
- 在输出缓冲区用 `RET` 输入一行、`C-c C-d` 发送 EOF、`C-c C-c` 中断。正在运行时重复按键只提示并显示已有输出，不会杀掉或启动第二份同文件程序；退出后可再次运行，保留先前输出。不同路径的同名文件各有输出缓冲区
- 文件名和命令参数直接传递，不经过 shell，支持空格、中文和 shell 特殊字符。只支持本地文件；不自动保存其他缓冲区，修改过的依赖模块请先自行保存

默认从所加载的 `emacs/ru-lang-mode.el`（或 `.elc`）旁定位 `../ru`。如果单独安装扩展、使用虚拟环境或 Windows 的 Python，可配置参数列表：

```elisp
(setq ru-lang-run-command
      '("/path/to/python3" "-u" "/path/to/ru-language/ru"))
;; Windows 示例：
;; (setq ru-lang-run-command '("py" "-3" "-u" "C:/src/ru-language/ru"))
```

也可 `M-x customize-variable RET ru-lang-run-command`。列表的第一项是可执行程序，其余项是各个参数；扩展追加 `run` 和当前文件绝对路径，不要额外加 shell 引号。相对路径以源码目录为基准；`nil` 恢复默认。只运行自己信任的源码和 CLI，模式不会在打开文件时执行代码。

## 缩进与高亮

- 默认每层 4 个空格，不插入 Tab 字符
- 按块与括号 / 方括号层数缩进；结束词、`则`、`另` 和 `救` 与对应开头对齐
- 可识别同行紧凑块、形内方法、跨行参数 / 条件、中文全角标点
- `为 数` / `为 句` / `为 阵` 转换、参数 / 字段注解以及完整名称 `为乐` 不会被误当成过程结束
- 支持 `'…'`、`"…"`、`‘…’`、`“…”` 及转义。多行字符串的内容行和结束引号所在行保持原样，避免缩进改动字符串的值
- 支持 `#`、`//`、`批.` / `批。` 行注释和非嵌套 `解.` / `解。` 至 `释.` / `释。` 块注释；字符串与注释中的块关键词不参与缩进和跳转
- 关键词、内置名称、类型以及定义名按完整词法名称高亮，不会把 `算法`、`为乐`、`若²` 等名称拆开
- 支持 `卒`、`试`、`救` 和作为块结束词的 `终`；`救` 后的局部原因名称使用变量定义高亮，即使名称与 `救` 之间有换行或注释
- `终` 按上下文识别，不会把 `文 其 段 始:1 终:3` 的命名实参、函数参数或表达式中的名称误判为块结束
- 内置类型 `件`、`录`、`件作成果` 与标准流对象 `读取`、`显出`、`错误` 均有高亮；`读`、`写`、`在`、`除`、`列` 在 `@` 或 `其` 后按成员名称高亮，其中原有全局函数 `读` 继续保留高亮。`写信`、`读取器` 等完整名称不会被拆开
- 0.5 的内部桥接名 `__竞赛` 有内置高亮；读流的 `词` / `数` / `行` 和出流的 `写` / `行` / `清` 在 `@` 或 `其` 后按成员高亮。`数` 在类型注解位置仍为类型高亮
- `读入`、`扫句`、`拆词`、`拆行`、`字列`、`合句`、`排序`、`取整`、`小`、`大`、`绝对`、`整除`、`蓄出` 是普通库函数名，不做全局内置或保留词高亮；用户同名定义、引用和闭包比较器仍按普通函数处理。标准库用法见 [竞赛指南](../docs/contest-library.md)
- `算 名` / `作 名` 引用和 `为 算` / `为 作` 类型注解不会被误当成定义块；名称后的冒号或命名参数声明头开启有名定义
- 表达式位置的 `算 参数:` / `作 参数 为 类型:` 以及零参 `算:` / `作:` 开启匿名字面量块；裸参数不会被当成函数名高亮，参数类型仍有类型高亮
- 匿名字面量可与括号、阵、声明、条件、循环、恢复块交错嵌套，参与 `C-M-a` / `C-M-e` 和结构跳转；未命名字面量不出现在 Imenu，内部有名定义仍显示其可见的有名词法路径
- 支持函数 / 方法 / 救内的嵌套定义，`imenu` 显示完整词法路径，如 `算 工厂@创建@内层`；函数引用不产生伪定义条目
- `回调()`、`回调们[0]()` 的空括号仍参与成对结构跳转，引用/类型不影响所在块的缩进和结束词配对

例如，闭包的声明与引用具有不同结构：

```ru
算 工厂 初值 为 数:
    数值 取 初值.
    算 加 步 为 数:
        数值 取 数值+步.
        得 数值.
    法
    得 算 加.
法
```

Imenu 包含 `算 工厂` 和 `算 工厂@加`，最后的 `算 加` 是引用，不额外创建一个未结束的函数块。算 / 作参数注解使用类型高亮，声明或引用前缀仍按关键字高亮。

匿名字面量省略定义名，参数不使用括号；下面的冒号是必需的：

```ru
平方 取 算 值 为 数:
    得 值 * 值.
法.
报到 取 作:
    显 '到了'.
为.
报到().
```

字面量的结束词只关闭表达式，所以从 `算` / `作` 执行 `C-M-n` 停在外层句点之前。传参写 `(算 值 为 数: 得 值 * 值. 法)`，立即带参调用写 `(算 值 为 数: 得 值 * 值. 法) 3`；括号仍是表达式分组。`算 (回调)` 仍为原有引用形式，不会被误判为匿名参数表。完整的参数头（类型注解可省略）与冒号开启有参匿名块，`算 回调 为 句` 等原有引用转换也不会开启块。完整程序见 [`examples/anonymous.ru`](../examples/anonymous.ru)。

恢复块的两个分支采用相同缩进：

```ru
试
    卒 '演示错误'.
救 原因
    显 原因.
终.
```

语言要求 `试` 必须包含 `救 名称`，`卒` 后应为句表达式。编辑模式仍容忍正在输入的残缺块；它不会代替编译器检查这些要求。

改成两个空格：

```elisp
(setq ru-lang-indent-offset 2)
```

也可以只为如文件设置其他编辑偏好：

```elisp
(add-hook 'ru-lang-mode-hook
          (lambda ()
            (setq-local ru-lang-indent-offset 2)
            (display-line-numbers-mode 1)))
```

这是容错的轻量编辑模式，不做语义检查或补全；仅在主动调用运行命令时执行代码。未完成的定义尽量延伸到文件末尾，残缺括号或错误源码可能影响后续缩进；请使用 `python3 ru check 文件.ru` 检查真实语言错误。在缩小范围（narrowing）的缓冲区中，仅分析可见范围。

## 中文注释与赋值提示

- `批.` / `批。` 从标记起注释到行尾，可写在语句后；`#` 和 `//` 保留。
- `解.` / `解。` 开始块注释，首个 `释.` / `释。` 结束；不嵌套，注释内引号和代码块词均为普通文字。标记的字与句点必须相邻。
- 不拆开 `批评`、`解释`、`总批` 等完整名称，字符串内不识别注释。标记自带的句点属于注释，不能代替前一语句的句点。
- 注释里的伪代码块不参与缩进和结构导航；多行注释的内部空白保持原样。
- 悬停在代码中的 `取` 上可查看保守的词法赋值规则：函数内先更新当前局部，否则更新最近已有的非模块捕获绑定；没有则创建当前局部，不隐式改写模块变量。直接 `救` 正文写救局部，闭包共享捕获绑定，参数属于本次调用局部。提示不推断具体名称在运行时绑定到何处。

## 0.10 事实与典

`事实` 是内置类型，`真` / `假` 是完整保留词；含这些字的长名称仍是普通名称。`典` 在类型注解中按类型高亮，只有后接冒号的字面量开启 `典 … 成` 块。缩进、结构识别和悬停提示支持嵌套典、空典、匿名回调，以及半角 / 全角标点；字符串和注释中的伪结构不参与分析。`对` 在典中分隔键值，原来的二元素对保持可用。

```ru
资料 取 典：
    ‘就绪’ 对 真。
    ‘设置’ 对 典：‘次数’ 对 3。成。
成。
显 （资料 其 查 键：‘就绪’）。
显 资料 其 量。
```

典的成员包括 `查 键:`、`增 键: 值:`、`除 键:`、`列 回调:` 和 `量`；列回调接收键、值两个位置参数。`为 事实` 做真值转换；仅 `空` 和 `假` 为假，数值 0 与空句也为真。事实与数是不同类型。

位置参数、命名参数与分组表达式沿用普通调用规则，例如：

```ru
资料 其 增 键: (‘次’ + ‘数’) 值: (1 + 2).
显 (资料 其 查 ‘次数’).
资料 其 列 回调: 作 键, 值:
    显 键.
    显 值.
为.
资料 其 除 键: ‘次数’.
```
